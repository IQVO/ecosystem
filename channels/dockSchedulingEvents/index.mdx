## Overview
  This service's integration topic. Written by the outbox relay; key = appointment id (site id for the door calendar events);
the only Kafka header on every message is the CloudEvents `content-type`. Rows the relay can never encode are parked raw on
`warehouse.dock-scheduling.events.dlq`. Dispatch on the full `type`, ignore unknown types, dedupe on `id`.
