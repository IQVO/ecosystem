## Overview
  This service's integration topic. Written by the outbox relay; every
message carries the CloudEvents content-type header (plus the optional
W3C `traceparent` of the writing request). Key = `asn_number`
for ASN and receipt events, `appointment_id` for the legacy appointment
events. Dispatch on the full `type`, ignore unknown types, dedupe on
`id`. The first consumer is inventory-storage (`ReceiptLineReceived`).
The `DockAppointment*` messages are LEGACY (ADR 0019): only the
one-shot `republish-appointments` command writes them now.
