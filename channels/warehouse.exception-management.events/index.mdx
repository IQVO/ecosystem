## Overview
  This service's integration topic. Written by the outbox relay; key = case
id (source type for the policy event); every message carries the
CloudEvents content-type header (plus the optional W3C `traceparent` of
the writing request). Dispatch on the full `type`, ignore unknown types,
dedupe on `id`.
