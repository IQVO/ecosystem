## Overview
  This service's integration topic. Written by the outbox relay; every
message carries the CloudEvents content-type header (plus the optional
W3C `traceparent` of the writing request). Key = `asn_number`
for ASN and receipt events, `appointment_id` for appointment events.
Dispatch on the full `type`, ignore unknown types, dedupe on `id`. The
first consumer is inventory-storage (`ReceiptLineReceived`).
