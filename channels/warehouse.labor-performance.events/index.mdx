## Overview
  The dedicated INTEGRATION topic this service owns and publishes to (ADR 0013) — its first Open-Host-Service Published Language for OTHER bounded contexts to consume. Separate from the analytics topic above (which feeds only this repo's own projector) so the two streams evolve independently. Before this topic existed, labor-performance was the fleet's only pure event sink: it consumed `TaskCompleted` from fulfillment-execution but published nothing any sibling service could subscribe to. Publishing is opt-in via `EVENT_PUBLISHER=kafka`; the default remains the log publisher. The first consumer is workforce-management, whose event-fed local cache (`laborperformancecache`) already consumes this topic in place of a synchronous HTTP call.
