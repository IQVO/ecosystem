## Overview
  The integration topic (the `Topic` constant in
`internal/adapters/outbound/kafka/publisher.go`). Every domain event
the `NetworkOrder` aggregate raises is published here, via the
transactional outbox when `DATABASE_URL` is configured (ADR 0003).
dataschema: `urn:warehouse:network-fulfillment:events:<EventName>:v<N>`
(v1, except `NetworkOrderAcknowledged` which is v2 — ADR 0016).
