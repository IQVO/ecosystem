## Overview
  The outbound integration topic owned by the Order Management bounded context (`kafka.Topic` in the code). `OrderAllocated`/ `OrderPartiallyAllocated` and — since ADR 0018 — `OrderRepromised` are forwarded here; since ADR 0035 the additive, PII-free `SiteSkuDemandChanged` projection is too (keyed by the line-scoped `<order_id>/line/<line_no>`, not the bare order id). Every other domain event is a local concern. wes-work-planning's Kafka consumer derives each line's work unit id from the frozen formula `{orderID}-line-{lineNo}`.
