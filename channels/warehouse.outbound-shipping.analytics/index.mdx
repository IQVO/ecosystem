## Overview
  This service's own analytics stream, written by the SAME transactional
outbox as the integration topic: every published event appears here
too, under the SAME CloudEvents id and `type`, with only the
`dataschema` stream segment different
(`urn:warehouse:outbound-shipping:analytics:<EventName>:v1`). It is
NOT an integration contract: the only consumer is this service's own
projector. Other contexts keep reading
`warehouse.outbound-shipping.events`.
