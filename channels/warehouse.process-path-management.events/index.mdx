## Overview
  This service's own integration topic (its `kafka.Topic` constant). Carries all three ProcessPath* event types plus CPTScheduleChanged (ADR 0010) as CloudEvents 1.0 (ADR 0016), dispatched by consumers on the full `type`. Only published when EVENT_PUBLISHER=kafka; the default is a local log publisher (no Kafka required for local dev).
