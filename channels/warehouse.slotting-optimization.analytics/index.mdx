## Overview
  This service's own analytics stream (ADR 0006), written by the SAME
transactional outbox as the integration topic: every published event
appears here too, under the SAME CloudEvents id and `type`, with only
the `dataschema` stream segment different
(urn:warehouse:slotting-optimization:analytics:\<EventName>:v1). It is
NOT an integration contract: the only consumer is this service's
cmd/slotting-projector (fixed group from ANALYTICS_CONSUMER_GROUP),
which folds the events into the analytical database; its deterministic
poison goes to warehouse.slotting-optimization.analytics.dlq. Other
contexts keep reading warehouse.slotting-optimization.events.
