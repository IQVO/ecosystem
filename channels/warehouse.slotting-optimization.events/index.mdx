## Overview
  This service's integration topic. Written by the outbox relay; key = plan
id; every message carries the CloudEvents content-type header (plus the
optional W3C `traceparent` of the writing request, ADR 0009). Dispatch on
the full `type`, ignore unknown types, dedupe on `id`. A row the relay
excluded after `OUTBOX_MAX_ATTEMPTS` failures (ADR 0008) is overtaken by
later events of the same plan.
