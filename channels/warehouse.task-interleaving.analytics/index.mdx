## Overview
  This service's analytics topic. Written by the SAME outbox relay, from rows
inserted in the same transaction as the integration row, with the SAME `type`
and `id` per occurrence and `dataschema` =
`urn:warehouse:task-interleaving:analytics:<EventName>:v1`; key = station id
(hint events) or site id (policy event). `InterleavingHintConsumed`,
`InterleavingHintExpired` and `InterleavingPolicyDeclared` exist ONLY here.
Not an integration contract: other contexts consume the integration topic.
