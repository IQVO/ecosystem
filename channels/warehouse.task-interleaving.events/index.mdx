## Overview
  This service's integration topic. Written by the outbox relay; key = station
id; every message carries the CloudEvents content-type header (plus the
optional W3C `traceparent` of the writing request). Only
`InterleavingHintIssued` is published here: the hint table of
fulfillment-execution is its consumer. Dispatch on the full `type`, ignore
unknown types, dedupe on `id`.
