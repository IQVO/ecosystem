## Overview
  This service's integration topic (`Topic` in
`internal/adapters/outbound/kafka/encoder.go`). Written by the outbox
relay; key = capacity plan id; every message carries the
`content-type: application/cloudevents+json; charset=UTF-8` header
(plus the optional W3C `traceparent` of the writing request, ADR 0014).
Dispatch on the full `type`, ignore unknown types, dedupe on `id`.
