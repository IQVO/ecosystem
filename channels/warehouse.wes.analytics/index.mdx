## Overview
  The internal analytics topic (ADR-0011) feeding this service's own throughput data product (`cmd/wes-projector`). Same occurrences, same CloudEvents `type` per occurrence as the integration topic, but the analytics payload shape, identified by `dataschema` `urn:warehouse:wes-work-planning:analytics:<EventName>:v1` (this replaces the retired `schema_version` field). Keyed by the aggregate id (work unit id or path id), which is also the CloudEvents `subject`.
