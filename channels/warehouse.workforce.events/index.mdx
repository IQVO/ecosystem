## Overview
  The single outbound topic for this bounded context, matching the
`Topic` constant in `internal/adapters/outbound/kafka/publisher.go`
(`warehouse.workforce.events`). Messages are CloudEvents 1.0
structured-mode JSON with the `content-type:
application/cloudevents+json; charset=UTF-8` Kafka header. Consumers
must dispatch on the full `type`, ignore unknown `type` values, and
dedupe on `id`.
