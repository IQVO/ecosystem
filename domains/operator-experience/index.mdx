## Overview
Operator-facing software that **reads** the bounded contexts and never changes them. It is deliberately not a domain: it has no aggregate, no database and no Kafka traffic, so it appears in the catalog through the REST and MCP calls it makes rather than through events.

- [warehouse-ops-agent](/docs/services/warehouse-ops-agent): decision support and the console-bff fan-out host.
- [warehouse-console](/docs/services/warehouse-console): the React SPA operators use.
