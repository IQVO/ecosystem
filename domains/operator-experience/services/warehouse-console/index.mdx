## Purpose
The browser entry point for operators. A React single-page application that hosts the micro-frontend shell (Module Federation host and routing) and renders the cross-service screens: **Floor** (daily brief, polled every 15 s), **Order Lifecycle** and **Operations Overview** (WMS and WES report dashboards).

| | |
|---|---|
| Repository | [IQVO/warehouse-console](https://github.com/IQVO/warehouse-console) |
| Design system | [IQVO/warehouse-ui-kit](https://github.com/IQVO/warehouse-ui-kit) (tokens and React components) |
| Backend | only [warehouse-ops-agent](/docs/services/warehouse-ops-agent) (console-bff), REST through Kong at `/api/warehouse-ops-agent` or `http://localhost:8096` in development |
| Kafka | none |

The browser never calls a bounded context directly: every cross-service read goes through the ops-agent's console-bff routes, which keeps fan-out, timeouts and partial-failure handling server side. DTOs are kept in sync by hand with the agent's responses (the console's `types.ts` files), and the agent must allow the console origin through CORS.
