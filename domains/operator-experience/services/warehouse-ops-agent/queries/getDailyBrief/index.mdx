## Overview
Aggregates read-only MCP calls to wes-work-planning, fulfillment-execution, workforce-management and facility-layout (and, when configured, warehouse-planning) at request time. A failing upstream appears in the path's `unavailable` list; the brief itself still answers `200`. Polled every 15 s by the console Floor screen.

Served by warehouse-ops-agent. Read-only; the agent never writes to another context. The agent's routes are documented in its repository under `docs/docs/api/http-routes.md`; this catalog does not carry an OpenAPI file for it.
