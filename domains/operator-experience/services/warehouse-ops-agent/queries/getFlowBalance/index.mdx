## Overview
Reads wes-work-planning backlog telemetry and rebalance recommendation, fulfillment-execution queue status and workforce-management staffing gap over MCP. With `LLM_MODE` of `shadow` or `on` the Anthropic Messages API proposes a plan that a deterministic policy layer validates; on failure the deterministic decision is returned.

Served by warehouse-ops-agent. Read-only; the agent never writes to another context. The agent's routes are documented in its repository under `docs/docs/api/http-routes.md`; this catalog does not carry an OpenAPI file for it.
