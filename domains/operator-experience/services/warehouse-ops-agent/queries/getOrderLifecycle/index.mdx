## Overview
console-bff fan-out: order-management `GET /orders/{id}`, then inventory-storage `GET /reservations?demandRef=`, wes-work-planning `GET /work-units?reference=` and fulfillment-execution `GET /tasks?orderRef=` per work unit. A `404` from order-management passes through; any other failing section is returned as `null`.

Served by warehouse-ops-agent. Read-only; the agent never writes to another context. The agent's routes are documented in its repository under `docs/docs/api/http-routes.md`; this catalog does not carry an OpenAPI file for it.
