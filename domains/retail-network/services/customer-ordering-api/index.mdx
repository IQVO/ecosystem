## Purpose
Turns a shopper's cart into a customer order: obtains a promise for every shipment group at checkout, records the order with the shopper and ship-to address (synthetic PII, held only here), shows status and tracking, and handles customer cancellation.

| | |
|---|---|
| Bounded context | `customer-ordering` |
| Domain | Retail Network (`retail-network`) |
| DDD classification | Generic |
| Tier | Retail Network, commerce tier |
| Repository | [IQVO/customer-ordering](https://github.com/IQVO/customer-ordering) |
| Events | [customer-ordering](/docs/services/customer-ordering) |

This service groups the context's synchronous surface: the OLTP REST API (`openapi.yaml`) and, where the
context has one, the separate read-only reports API (`openapi-reports.yaml`) served by its `*-reports`
binary from an isolated analytical database. Endpoints are unauthenticated fleet-wide.


REST contract of the customer-ordering bounded context of the retail network, derived from retail-network-docs model/model.yaml (contexts[customer-ordering].rest) and adjusted by the final cross-context decisions (contracts-delta E7, E9, E11 and Gap Register G7, G10, G12, G25). It turns a shopper's cart into a customer order: checkout promises and confirms every shipment group at delivery-promise before the order is placed, the order carries the ship-to address (synthetic PII, held only here), the tracking view is fed by events, and a customer cancellation is a request that order-sourcing decides. One restricted in-organization route, GET /orders/\{orderId\}/ship-to, is called only by shipping-and-tracking to print a label and is the only route that returns the address. There is no authentication anywhere in the network; "restricted" means the route is not exposed through the storefront edge. Errors are RFC 9457 problem details (application/problem+json) whose type is /problems/&lt;slug>. The shared problem types are not-found (404), illegal-transition (409), concurrent-update (409) and validation-failed (422). Optional fields are omitted when absent, never null.
