## Overview
AddSavedAddress. The addressId derives from the Idempotency-Key, so a replay (even after the idempotency record expired) returns the same address. A shopper holds at most 20 saved addresses; the twenty-first is 422 too-many-addresses (ErrTooManyAddresses). A checkout can then name the address by its id (CheckoutRequest.shipToAddressId) and the address is copied into the order at placement.




## POST `(/shoppers/{shopperId}/addresses)`

### Parameters
- **shopperId** (path) (required): The shopper id (aggregate root id).
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit, 1 to 128 printable ASCII characters (missing is 400 idempotency-key-required, malformed is 400 idempotency-key-invalid). A key is global and kept for 24 hours; the same key with the same method, path and body replays the stored answer with Idempotency-Replayed: true; the same key with anything else is 409 idempotency-key-reused.
