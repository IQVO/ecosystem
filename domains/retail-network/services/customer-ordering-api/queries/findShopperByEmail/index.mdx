## Overview
FindShopperByEmail. The match is trimmed and lower-cased, like the uniqueness of the registration (case-insensitive). No shopper with that e-mail is 404 not-found; an absent or empty e-mail matches nothing and is 404 too. The e-mail is unique, so this is a lookup of one shopper (a single resource that merely contains its saved addresses), not a collection.




## GET `(/shoppers)`

### Parameters
- **email** (query) (required): The e-mail to find; the match is trimmed and lower-cased.
