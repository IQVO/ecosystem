## Overview
Served from the event-fed read model OrderTrackingView (delivery-promise, order-sourcing and shipping-and-tracking events) joined with the order's groups. A package scanned before its label or shipment event arrived is listed once the order is known.




## GET `(/orders/{orderId}/tracking)`

### Parameters
- **orderId** (path) (required): The customer order id (aggregate root id, CloudEvents subject).
