## Overview
In-organization, restricted route for shipping-and-tracking (GetShipTo), called when it issues a label. The only route that returns ship-to PII (synthetic). Not exposed through the storefront edge.




## GET `(/orders/{orderId}/ship-to)`

### Parameters
- **orderId** (path) (required): The customer order id (aggregate root id, CloudEvents subject).




### Responses

#### <span className="text-green-500">200 OK</span>
Synthetic PII. Returned only by GET /orders/\{orderId\}/ship-to; accepted on checkout and shopper registration.
