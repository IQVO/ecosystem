## Overview
ListOrdersByShopper. Keyset pagination: the page is ordered placedAt descending with the orderId as the ascending tiebreak, `limit` defaults to 100 and is at most 500, and `cursor` is the nextCursor of the previous page (opaque). A bad limit is 400 invalid-limit, an undecodable cursor is 400 invalid-cursor and any other query parameter is 400 unknown-query-parameter. An unknown shopper is 404 not-found; a shopper without orders is an empty page. The items never carry the ship-to address.




## GET `(/orders)`

### Parameters
- **shopperId** (query) (required): The shopper whose order history is listed.
- **cursor** (query): The nextCursor of the previous page (opaque; anything that does not decode is 400 invalid-cursor).
- **limit** (query): Page size, default 100, at most 500 (anything else is 400 invalid-limit).
