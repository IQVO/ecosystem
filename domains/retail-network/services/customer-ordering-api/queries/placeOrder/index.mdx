## Overview
PlaceOrder. For each shipment group the service calls delivery-promise MakePromise (POST /promises) with the offer the shopper saw and then ConfirmPromise (POST /promises/\{promiseId\}:confirm) before anything is stored. If an offer expired or was consumed, or a confirm fails, it re-quotes (QuoteDeliveryOffers, POST /delivery-offers:quote) and answers 409 offer-not-quotable with the new offers; no order is placed. On success the order is PLACED and CustomerOrderPlaced is published through the outbox in the same transaction. The order id is derived from the Idempotency-Key, so a retry after a timeout reuses the same promises.




## POST `(/checkout)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key (route, key; 24 hour TTL); a replay with the same body returns the stored response.
