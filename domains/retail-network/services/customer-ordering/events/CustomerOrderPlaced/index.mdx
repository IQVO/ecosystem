## Description
`type` = `com.retailnetwork.commerce.customer-ordering.customerorder.CustomerOrderPlaced`; subject and key = the orderId. Raised by PlaceOrder when the order is saved in state PLACED, in the same transaction as the outbox row. Consumed by order-sourcing (creates one assignment per group) and delivery-promise (a repeated confirm is a no-op, ADR 0003). Carries the destination postal prefix only: the ship-to address never leaves customer-ordering except through GET /orders/\{orderId\}/ship-to. Also carries the optional consolidationKey (ADR 0012): an opaque keyed hash of shopper and ship-to that lets order-sourcing merge the groups of one shopper and one address; an absent consolidationKey means the order never merges. Each group carries its REAL tier, which may be CONSOLIDATED (ADR 0013), with the optional chosenDeliveryDay and consolidationEligible of that choice.
