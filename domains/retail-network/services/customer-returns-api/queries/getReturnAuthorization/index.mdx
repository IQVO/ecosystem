## Overview
The authorization with its lines, disposition, labels and state. A pure read (ADR 0002 A11) that never writes; an authorization past its `expiresAt` that no command has touched yet is answered in its stored state (still `AUTHORIZED`) until the next label, cancellation or outcome expires it. The MCP tool `get_return_authorization` and the A2A skill of the same name answer the same query.




## GET `(/return-authorizations/{authorizationId})`

### Parameters
- **authorizationId** (path) (required): The return authorization id (`ret-<uuid>`).
