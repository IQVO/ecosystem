## Overview
Keyset-paged, newest first. `orderId` is required; `cursor` is the previous page's `nextCursor`; `limit` is 1..100 (default 20). The MCP tool `list_return_authorizations` answers the same query.




## GET `(/return-authorizations)`

### Parameters
- **orderId** (query) (required): The customer order whose authorizations to list.
- **cursor** (query): The keyset cursor from the previous page's nextCursor; omitted means the first page.
- **limit** (query): Page size, 1..100; omitted means 20.
