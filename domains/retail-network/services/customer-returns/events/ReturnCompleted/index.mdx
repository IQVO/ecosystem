## Description
`type` = `com.retailnetwork.commerce.customer-returns.returnauthorization.ReturnCompleted`; subject and key = the `authorizationId`; raised by the first graded outcome that fits an open authorization. Lines beyond the authorization are NEVER published (they stay on the local outcome facts, flagged unexpected). offer-availability consumes this to raise the owner listings' availability at the node by `qtyRestockable`; unsellable units never touch a listing.
