## Description
`type` = `com.retailnetwork.commerce.customer-returns.returnauthorization.ReturnAuthorized`; subject and key = the `authorizationId`; raised by POST /return-authorizations for every disposition. `destinationNodeId` is omitted for KEEP (no destination); the pickup window is present only for PICKUP; no line carries a unit price (the price is the storefront's fact and never leaves the context). vendor-connectivity consumes it into its return advices.
