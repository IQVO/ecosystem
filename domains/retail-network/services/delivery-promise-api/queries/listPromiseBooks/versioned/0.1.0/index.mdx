## Overview
One book per pickup cutoff of the node whose cutoff falls on the date (node local time).




## GET `(/promise-books)`

### Parameters
- **nodeId** (query) (required): The fulfillment node id.
- **date** (query) (required): The cutoff date, YYYY-MM-DD, in the node's time zone.
