## Overview
Stores the next policy version (strictly increasing) and publishes PromisePolicyPublished on the analytics topic. Offers and promises made afterwards record the new policyVersion.




## POST `(/promise-policies)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key; a repeat with the same key and body returns the first result.
