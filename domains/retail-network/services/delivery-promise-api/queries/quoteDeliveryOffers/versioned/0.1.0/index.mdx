## Overview
Runs the PromisePolicy search over local read models. The cart is first split into shipment groups (ShipmentGrouping: one node for the whole cart when one can cover every line, otherwise the fewest groups). Returns one QUOTED offer per (group, requested tier) that has a feasible witness path, and an OfferConstraint for every (group, tier) that has none. "No offer" is a normal 200 answer. A tier whose order deadline in the destination region has passed is reported PAST_ORDER_DEADLINE. Each offer is persisted with a TTL so checkout can honour it. With an Idempotency-Key, a repeat inside the offers' TTL returns the same offers. Makes no synchronous call.




## POST `(/delivery-offers:quote)`

### Parameters
- **Idempotency-Key** (header): Client-chosen key; a repeat with the same key returns the first result.
