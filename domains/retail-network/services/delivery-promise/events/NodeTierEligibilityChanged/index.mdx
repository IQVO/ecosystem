## Description
Consumed from `retailnetwork.node-performance.events`; `type` = `com.retailnetwork.partner.node-performance.scorecard.NodeTierEligibilityChanged` (dispatch on the full type); subject and Kafka key = the scorecardId (`<nodeId>:7d`). Tolerant local copy: only the fields delivery-promise relies on are listed and unknown fields are ignored (the producer also sends `metric`, `value`, `threshold` and `window`). Raised by node-performance only when the node's eligibility flips, as one event per tier with the same `changedAt`. Use: upserts NodeTierEligibility (`rm_node_tier_eligibility`) when `changedAt` is not older than the stored one; a missing row means ELIGIBLE. An ineligible node is removed from the SAME_DAY or NEXT_DAY candidates of future quotes and estimates (ADR 0022); existing promises are never touched. An event with a `tier` other than SAME_DAY or NEXT_DAY, or with a missing `nodeId`, `tier`, `eligible` or `changedAt`, is ignored and counted (`deliverypromise_tier_eligibility_events_ignored_total`), never dead-lettered.
