## Description
`type` = `com.retailnetwork.commerce.delivery-promise.promise.PromiseBroken`; `dataschema` = `urn:retailnetwork:delivery-promise:events:PromiseBroken:v1`; subject and key = the promiseId. Topic: retailnetwork.delivery-promise.events. Raised by JudgePromise. `cause` is LATE (delivered after deliverByLatest), LOST (first package lost, E6) or RETURNED (first package returned before delivery, E6). For LOST and RETURNED `deliveredAt` is omitted and `lateByMinutes` is the whole minutes from deliverByLatest to the loss/return instant, 0 when that instant is not later. Consumed by node-performance and customer-ordering.
