## Overview
OPEN to CANCELLED, publishes DeliveryWaveCancelled (an integration event, Gap Register G5). Every package inducted in the wave is re-inducted onto the next eligible wave in the same transaction (Gap Register G17); a package with no eligible wave is deferred (PackageInductionDeferred).




## POST `(/waves/{waveId}:cancel)`

### Parameters
- **waveId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
