## Overview
Creates an ACTIVE partner. Van capacity must be greater than zero (ErrInvalidVanCapacity, 422 invalid-van-capacity) and stationNodeId a known DELIVERY_STATION (ErrUnknownStation, 422 unknown-station).




## POST `(/partners)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
