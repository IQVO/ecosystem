## Overview
ACTIVE to INACTIVE (Gap Register G34). An inactive partner can be given no new route; routes already planned are unaffected.




## POST `(/partners/{dspId}:deactivate)`

### Parameters
- **dspId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
