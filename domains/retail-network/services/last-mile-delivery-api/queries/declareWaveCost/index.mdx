## Overview
Records the planner's declared marginal cost of ONE delivery stop on the wave (driver time plus mileage share), integer cents, single-currency study (roadmap feature F7, provider B; ADR 0011), and publishes WaveCostDeclared for order-sourcing's money-denominated AssignmentCost. The cost is per stop (the G11 stopKey grouping), never per package. 0 is a legal declared zero marginal cost; a wave with no declaration reports 0 and leaves a consumer's estimate incomplete. Allowed while the wave still runs (OPEN, INDUCTION_CLOSED or DISPATCHED, illegal-transition once CANCELLED or COMPLETED); a later declaration overwrites the earlier one and publishes again.




## POST `(/waves/{waveId}/cost-declarations)`

### Parameters
- **waveId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated key (a UUID) per logical submit, 1 to 128 printable ASCII characters. A retry with the same method, path and body replays the stored answer with `Idempotency-Replayed: true` and changes nothing; the same key with another method, path or body is 409 `idempotency-key-reused`. Keys are global and kept 24 hours.
