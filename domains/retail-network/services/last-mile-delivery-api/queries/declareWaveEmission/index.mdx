## Overview
Records the planner's declared marginal greenhouse emission of ONE delivery stop on the wave (the stop's share of the route's driving), in grams of CO2 equivalent (roadmap feature C9; ADR 0016), and publishes WaveEmissionDeclared for order-sourcing's estimatedCo2eGrams. The emission is per stop (the G11 stopKey grouping), never per package. 0 is a legal declared zero marginal emission; a wave with no declaration reports 0 and leaves a consumer's estimate incomplete. Allowed while the wave still runs (OPEN, INDUCTION_CLOSED or DISPATCHED, illegal-transition once CANCELLED or COMPLETED); a later declaration overwrites the earlier one and publishes again. Ranking is untouched by this fact: carbon is recorded, not optimised, in this slice.




## POST `(/waves/{waveId}/emission-declarations)`

### Parameters
- **waveId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated key (a UUID) per logical submit, 1 to 128 printable
ASCII characters. A retry with the same method, path and body replays
the stored answer with `Idempotency-Replayed: true` and changes
nothing; the same key with another method, path or body is 409
`idempotency-key-reused`. Keys are global.

What is stored. A 2xx is stored. A 5xx is never stored. A refusal is
stored (and replayed) only when it is final for the request:
`validation-failed`, `invalid-wave-times`, `invalid-van-capacity`,
`already-delivered`, `attempt-already-recorded`,
`package-already-routed`, `induction-closed` and `already-inducted`.
A refusal that depends on state that can change is NOT stored: its key
is released, a retry with the same key and request executes again (it
can succeed once the state allows), and a different request under the
released key is a new request, not `idempotency-key-reused`. These are
`concurrent-update` (re-read, then retry), `not-found`,
`unknown-station`, `package-not-on-route`, `package-not-inducted`,
`stop-key-mismatch`, `route-over-capacity`, `partner-inactive`,
`partner-station-mismatch`, `route-not-started`, `route-incomplete`,
`wave-full` and `illegal-transition`; the 409 `idempotency-key-reused`
is itself never stored. Rows are kept 24 hours.
