## Overview
INDUCTION_CLOSED to DISPATCHED. No event is published for the wave itself. Packages inducted in the wave that no route holds are re-inducted onto the next wave (Gap Register G17 mechanism). A wave with no route left to run completes at once (policy CompleteWaveOnLastRoute), so the response may show COMPLETED.




## POST `(/waves/{waveId}:dispatch)`

### Parameters
- **waveId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
