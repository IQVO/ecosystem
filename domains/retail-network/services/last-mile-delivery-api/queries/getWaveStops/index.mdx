## Overview
Returns the packages inducted into the wave grouped into stops by the opaque stopKey (Gap Register G11), ordered by the first induction of each stop. A package with no label data is its own stop. The planner builds PlanRoute from this list. No address is ever returned.




## GET `(/waves/{waveId}/stops)`

### Parameters
- **waveId** (path) (required)
