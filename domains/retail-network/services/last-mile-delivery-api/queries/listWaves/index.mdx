## Overview
Returns the waves of the station on the service date ordered by inductCutoffAt then waveId. A station or date with no wave is an empty list.




## GET `(/waves)`

### Parameters
- **stationNodeId** (query) (required): The delivery station (node-topology nodeId).
- **serviceDate** (query) (required): The station's local service date.
