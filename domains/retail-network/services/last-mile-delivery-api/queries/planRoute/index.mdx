## Overview
Creates a PLANNED route and publishes RoutePlanned (analytics stream only). The wave must be INDUCTION_CLOSED (illegal-transition), the partner ACTIVE, of the wave's station and the stops at most the partner's van capacity (ErrRouteOverCapacity, 409 route-over-capacity). Every package must be inducted in the wave and not on another route, and the packages of one stop must share one stopKey (G34).




## POST `(/routes)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
