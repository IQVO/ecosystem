## Overview
Records DELIVERED or FAILED for one package on an OUT_FOR_DELIVERY route and publishes DeliveryAttempted. Errors: ErrRouteNotStarted (409 route-not-started), ErrAlreadyDelivered (409 already-delivered). A FAILED attempt counts in the package's attempt history and re-inducts the package onto the next wave (policy RetryNextWave); the third failure publishes PackageReturnInitiated instead. The attempt that records the last outstanding package completes the route, and the last completed route completes the wave.




## POST `(/routes/{routeId}/attempts)`

### Parameters
- **routeId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
