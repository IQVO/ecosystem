## Overview
Creates an OPEN wave and publishes DeliveryWaveScheduled. Enforces inductCutoffAt &lt; windowStart &lt; windowEnd (ErrInvalidWaveTimes, 422 invalid-wave-times) and that stationNodeId is a DELIVERY_STATION known from node-topology (ErrUnknownStation, 422 unknown-station). Packages that arrived while no wave was eligible are inducted into the new wave in arrival order (policy InductDeferredOnSchedule).




## POST `(/waves)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
