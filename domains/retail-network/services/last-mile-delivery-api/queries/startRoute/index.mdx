## Overview
PLANNED to OUT_FOR_DELIVERY; the route's wave must be DISPATCHED (illegal-transition otherwise). Publishes one PackageOutForDelivery per tracking number on the route.




## POST `(/routes/{routeId}:start)`

### Parameters
- **routeId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key; a repeated request with the same key on the same route returns the stored response and changes nothing. Keys are kept 24 hours.
