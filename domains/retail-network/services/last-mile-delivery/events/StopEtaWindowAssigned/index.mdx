## Description
`type` = `com.retailnetwork.logistics.last-mile-delivery.route.StopEtaWindowAssigned`; subject = the routeId, key = the routeId (the key of PackageOutForDelivery, so the two stay ordered). Raised by StartRoute in the same transaction, AFTER every PackageOutForDelivery, one per stop in stop order (ADR 0013). The CloudEvents `time` is the route start instant (the assignment time). The window is a deterministic spread of the route's stops over what is left of the wave's delivery window, at most two hours wide; it is not a prediction. No event is raised when less than 30 minutes of the wave window is left at the start instant. An ETA is never retracted and never re-raised for the same start; a re-inducted package gets a new one from its next StartRoute. `stopKey` is the opaque stop key (`pkg:<trackingNumber>` when the package has no label data); no address, name or phone is carried. A window may fall after the promised delivery window; it is published as computed.
