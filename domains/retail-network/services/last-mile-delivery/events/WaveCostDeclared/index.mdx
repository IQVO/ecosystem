## Description
`type` = `com.retailnetwork.logistics.last-mile-delivery.wave.WaveCostDeclared`, from last-mile-delivery. Fields relied on are required; every other field is ignored. `costPerStopCents` is an integer 0 to 10000000 (0 is a legal declared zero); a later declaration supersedes the earlier one, so the consumer keeps the newer `declaredAt`. A wave the view does not know is stored keyed by `waveId` anyway: `DeliveryWaveScheduled` later completes the row without losing the cost. Use: NetworkGraphView, the per-stop wave term of the money-denominated AssignmentCost (ADR 0011).
