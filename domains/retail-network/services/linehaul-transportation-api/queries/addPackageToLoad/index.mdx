## Overview
Refused with 409 package-already-loaded (ErrPackageAlreadyLoaded) if the tracking number is on another OPEN or CLOSED load, and with 409 load-over-capacity (ErrLoadOverCapacity) if the load would exceed its capacity snapshot. On a LINEHAUL or AIR departure the package is also booked on the departure (gap G15): 409 departure-full or departure-closed when it cannot be. On a PICKUP departure the booking was made at FulfillmentLocked and booked does not change. Adding a tracking number that is already on this load changes nothing.




## POST `(/loads/{loadId}/packages)`

### Parameters
- **loadId** (path) (required): Load id.
- **Idempotency-Key** (header) (required): Client-chosen key (1 to 200 printable characters). A repeat of the same request on the same route with the same key within 24 hours returns the first response (status and body, header Idempotency-Replayed: true); a refusal (4xx) is replayed too, a server failure (5xx) is not stored. The same key with another request is 422 idempotency-key-reused.
