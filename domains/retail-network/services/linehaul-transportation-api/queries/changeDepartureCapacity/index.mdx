## Overview
Planner command added by gap G28. Allowed on a SCHEDULED departure; the new capacity may not be below the packages already booked (departure-full). Publishes DepartureCapacityChanged. A capacity equal to the current one changes nothing and publishes nothing. A load that is already open keeps the capacity snapshot it took at OpenLoad.




## POST `(/departures/{departureId}:change-capacity)`

### Parameters
- **departureId** (path) (required): Departure id.
- **Idempotency-Key** (header) (required): Client-chosen key (1 to 200 printable characters). A repeat of the same request on the same route with the same key within 24 hours returns the first response (status and body, header Idempotency-Replayed: true); a refusal (4xx) is replayed too, a server failure (5xx) is not stored. The same key with another request is 422 idempotency-key-reused.
