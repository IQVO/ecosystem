## Overview
Creates the ACTIVE weekly template of one lane, or replaces the slots of an ACTIVE template (201 on creation, 200 on replacement; a redefinition takes effect from the next horizon roll, departures that were already generated stay). The lane must be known (LaneView). Slots must not overlap on the same weekday (overlapping-slots). A RETIRED schedule cannot be redefined (illegal-transition). Raises no event. Departures are generated by GenerateDepartures (policy HorizonRoll).




## POST `(/lane-schedules)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key (1 to 200 printable characters). A repeat of the same request on the same route with the same key within 24 hours returns the first response (status and body, header Idempotency-Replayed: true); a refusal (4xx) is replayed too, a server failure (5xx) is not stored. The same key with another request is 422 idempotency-key-reused.
