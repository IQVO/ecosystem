## Overview
Open Host Service read for any context. Filters are ANDed; from and to bound cutoffAt (from inclusive, to exclusive). Ordered by cutoffAt then departureId, at most limit rows (default 500, maximum 1000).




## GET `(/departures)`

### Parameters
- **origin** (query): Origin node id.
- **destination** (query): Destination node id.
- **from** (query): Earliest cutoffAt, inclusive.
- **to** (query): Latest cutoffAt, exclusive.
- **limit** (query): Maximum number of departures returned.
