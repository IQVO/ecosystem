## Description
`type` = `com.retailnetwork.logistics.linehaul-transportation.load.LoadArrived`; stream `events`; subject and key = loadId. Raised by ReceiveLoad. `departureKind` (gap G3) and `nodeType`, the type of the node where the load arrived (the destination), let shipping-and-tracking tell an arrival at a station from one at a sort centre. Consumers: shipping-and-tracking, last-mile-delivery.
