## Description
`type` = `com.retailnetwork.logistics.linehaul-transportation.load.LoadDeparted`; stream `events`; subject and key = loadId. Raised by DispatchLoad. `departureKind` (PICKUP, LINEHAUL or AIR, gap G3) lets shipping-and-tracking recognise the pickup load whose first scan is the handover; `nodeType` is the type of the node where the load departed (the origin). Consumer: shipping-and-tracking.
