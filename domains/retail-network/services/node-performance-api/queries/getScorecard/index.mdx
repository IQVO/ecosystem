## Overview
Returns the 7d and the 30d scorecard of the node, in that order. A scorecard exists from the first observation recorded for the node, so a node nothing was observed about answers not-found.




## GET `(/scorecards/{nodeId})`

### Parameters
- **nodeId** (path) (required): The node id minted by node-topology.
