## Overview
Lists every scorecard whose current grade is the one given, ordered by scorecardId ascending, one page at a time. The model names no window filter and no caller; the optional window filter and the keyset pagination (limit, after) are additive (ADR 0002, A18).




## GET `(/scorecards)`

### Parameters
- **grade** (query) (required): A, B, C, D, or PROVISIONAL below the observation minimum.
- **window** (query): Restrict the list to one window.
- **limit** (query): Page size, 1 to 500; 100 when absent.
- **after** (query): The nextCursor of the previous page (the last scorecardId returned).
