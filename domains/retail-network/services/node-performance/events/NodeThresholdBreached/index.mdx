## Description
`type` = `com.retailnetwork.partner.node-performance.scorecard.NodeThresholdBreached`; subject and key = the scorecardId. Analytics only: published ONLY to `retailnetwork.node-performance.analytics`, dataschema stream `analytics`. Raised by Recompute (policy ThresholdAlert), one event per metric that moved from the healthy side of its threshold to the unhealthy side between two GRADED recomputes. `value` is the metric's new value, `threshold` the bound it crossed (ADR 0002, A11).
