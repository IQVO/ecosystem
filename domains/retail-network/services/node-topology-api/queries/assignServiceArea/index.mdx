## Overview
Creates or reassigns the prefix under a strictly higher assignmentVersion (ASSIGNED to ASSIGNED). The region is taken from the station and must be a defined Region. Publishes ServiceAreaAssigned.




## PUT `(/service-areas/{postalPrefix})`

### Parameters
- **postalPrefix** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and request replays the first response. Keys are kept for 24 hours. vendor-connectivity sends its transactionId.
