## Overview
Records the planner's declared marginal cost of moving ONE package-unit across the lane on one departure, integer cents (0..10000000). Valid on an OPEN lane only; every declaration supersedes the previous value and publishes LaneCostDeclared.




## POST `(/lanes/{laneId}/cost-declarations)`

### Parameters
- **laneId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated key (1-128 printable ASCII characters), one per logical submit; a retry reuses it. A repeat of the same request replays the first response with the header Idempotency-Replayed: true; the same key with another method, path or body is 409 idempotency-key-reused. A missing key is 400 idempotency-key-required, a malformed one 400 idempotency-key-invalid. Keys are kept for 24 hours. vendor-connectivity sends its transactionId.
