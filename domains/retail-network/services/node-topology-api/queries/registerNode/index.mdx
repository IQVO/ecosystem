## Overview
Creates a node in state PROPOSED and publishes NodeRegistered. Capabilities are derived from the node type (DefaultCapabilitiesByType). Parcel nodes (SORTATION_CENTER, DELIVERY_STATION, AIR_HUB) must have operator NETWORK.




## POST `(/nodes)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and request replays the first response. Keys are kept for 24 hours. vendor-connectivity sends its transactionId.
