## Overview
ACTIVE or SUSPENDED to RETIRED, which is terminal. Publishes NodeRetired.




## POST `(/nodes/{nodeId}:retire)`

### Parameters
- **nodeId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and request replays the first response. Keys are kept for 24 hours. vendor-connectivity sends its transactionId.
