## Description
`type` = `com.retailnetwork.logistics.node-topology.lane.LaneCostDeclared`; subject and key = the laneId. Raised by DeclareLaneCost, on every declaration (a newer declaration supersedes the previous value). `costPerUnitCents` is the declared marginal cost of moving ONE package-unit across the lane on one departure, integer cents, 0 to 10000000; 0 is legal (zero declared marginal cost). A lane with no declaration publishes nothing. Consumed by order-sourcing, which keeps the latest declaration per laneId and folds it into its money-denominated AssignmentCost (roadmap F7, order-sourcing ADR 0011).
