## Description
`type` = `com.retailnetwork.logistics.node-topology.node.NodeOperationalProfileDeclared`; subject and key = the nodeId. Raised by DeclareOperationalProfile. `profileRevision` strictly increases per node; consumers keep the highest. Local times are `HH:mm` in `timezone`; a weekday missing from `operatingHoursByDay` is closed; `holidays` are ISO dates closed all day. A cutoff without `days` applies to every operating day. `sortDwellMinutes` is present only for SORTATION_CENTER and AIR_HUB nodes. `inbound` is present only when the revision declares inbound limits (absent = none declared, consumers treat them as unchecked); every limit inside it is optional, weight is in grams and dimensions in millimetres.
