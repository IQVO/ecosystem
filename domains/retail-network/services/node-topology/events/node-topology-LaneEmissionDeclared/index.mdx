## Description
`type` = `com.retailnetwork.logistics.node-topology.lane.LaneEmissionDeclared`; subject and key = the laneId. Raised by DeclareLaneEmission, on every declaration (a newer declaration supersedes the previous value). `gCo2ePerUnit` is the declared carbon emission of moving ONE package-unit across the lane on one departure, grams of CO2-equivalent, 0 to 10000000; 0 is legal (zero declared emission). A lane with no declaration publishes nothing. Consumed by order-sourcing, which keeps the latest declaration per laneId and records it beside the declared cents in its estimate (roadmap C9, ADR 0018); ranking is unchanged.
