## Overview
Open Host Service read. Items ordered by catalogItemId ascending, keyset paginated: pass the previous page's nextCursor as `after`. An empty result is 200 with an empty list.




## GET `(/catalog)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100).
- **after** (query): Keyset cursor, the nextCursor of the previous page.
