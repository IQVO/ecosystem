## Overview
Creates an ACTIVE catalogue item under a new catalogItemId and publishes CatalogItemCreated (with identifiers.gtin when given). Dimensions and weight must be positive. identifiers.gtin is optional and checked (GS1 mod-10); a GTIN another item or pack level holds is 409 gtin-already-assigned.




## POST `(/catalog-items)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and the same request replays the first response; the same key with another body is 422 idempotency-key-reused. Keys are kept for 24 hours.
