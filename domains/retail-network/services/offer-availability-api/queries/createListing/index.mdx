## Overview
Creates the listing of one catalogue item on one node and publishes ListingCreated. The listing starts LIVE when the node is ACTIVE in the local node status view. Otherwise (node proposed, suspended, retired or not yet known) it starts SUPPRESSED with reason NODE_NOT_SELLABLE; for a DISCONTINUED item it starts SUPPRESSED with reason DISCONTINUED (Gap Register G24). Its availability starts at 0, basis UNKNOWN, with no asOf.




## POST `(/listings)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and the same request replays the first response; the same key with another body is 422 idempotency-key-reused. Keys are kept for 24 hours.
