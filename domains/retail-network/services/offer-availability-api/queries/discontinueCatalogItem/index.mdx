## Overview
Moves the item from ACTIVE to DISCONTINUED, publishes CatalogItemDiscontinued and, in the same transaction, suppresses every LIVE or node-suppressed listing of the item with reason DISCONTINUED (one ListingSuppressed each; Gap Register G24). Discontinuing a DISCONTINUED item returns it unchanged and publishes nothing.




## POST `(/catalog-items/{catalogItemId}:discontinue)`

### Parameters
- **catalogItemId** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and the same request replays the first response; the same key with another body is 422 idempotency-key-reused. Keys are kept for 24 hours.
