## Overview
Both filters are optional and combine with AND. Ordered by listingId ascending, keyset paginated like GET /catalog. An empty result is 200 with an empty list.




## GET `(/listings)`

### Parameters
- **nodeId** (query)
- **catalogItemId** (query)
- **limit** (query): Page size, 1 to 500 (default 100).
- **after** (query): Keyset cursor, the nextCursor of the previous page.
