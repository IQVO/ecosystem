## Overview
Retires the active definition at the level and publishes CatalogItemPackLevelRetired. The definition is kept (active false), its GTIN is never reusable. A level that only has retired history is returned unchanged and publishes nothing; a level never declared is 404 pack-level-not-found. Takes no body.




## POST `(/catalog-items/{catalogItemId}/packaging/{level}:retire)`

### Parameters
- **catalogItemId** (path) (required)
- **level** (path) (required): The packaging level, lowest first EACH \< INNER \< CASE \< PALLET.
- **Idempotency-Key** (header) (required): Client-chosen key. A repeat on the same route with the same key and the same request replays the first response; the same key with another body is 422 idempotency-key-reused. Keys are kept for 24 hours.
