## Description
`type` = `com.retailnetwork.commerce.offer-availability.catalogitem.CatalogItemPackLevelRetired`; subject and key = the catalogItemId. Raised by RetirePackLevel, or by DeclarePackLevel when a new GTIN supersedes the level (then it precedes the CatalogItemPackagingDeclared of the new GTIN). The retired GTIN stays resolvable and is never reused.

> **No consumer by design:** pending: pack-level fact (offer-availability ADR 0006); no consumer declared in any retail spec yet
