## Description
`type` = `com.retailnetwork.commerce.offer-availability.catalogitem.CatalogItemPackagingDeclared`; subject and key = the catalogItemId. Raised by DeclarePackLevel (ADR 0006). `unitsPerPack` is in eaches (1 for EACH); `childGtin` names the active lower level and is omitted for EACH. The unitsPerPack of a GTIN never changes: a new count arrives as a new `gtin` at the level, preceded in the same transaction by CatalogItemPackLevelRetired for the old one.

> **No consumer by design:** pending: pack-level fact (offer-availability ADR 0006); no consumer declared in any retail spec yet
