## Description
`type` = `com.retailnetwork.commerce.offer-availability.listing.ListingAvailabilityChanged`; subject and key = the listingId. Raised once per feed line that was applied and once per listing zeroed by FullFeedZeroing (a zeroed listing keeps its basis and gets the feed's asOf). `asOf` is strictly increasing per listing, so a consumer keeps the highest. Raised for a SUPPRESSED listing too: the state is carried by ListingSuppressed/ListingRestored, not here.
