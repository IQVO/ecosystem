## Description
`type` = `com.retailnetwork.commerce.offer-availability.listing.ListingCreated`; subject and key = the listingId. Raised by CreateListing. The event does not say whether the listing starts LIVE: a listing created on a node that is not sellable, or for a discontinued item, is followed in the same transaction by a ListingSuppressed. Availability starts at 0 with basis UNKNOWN until the first feed.
