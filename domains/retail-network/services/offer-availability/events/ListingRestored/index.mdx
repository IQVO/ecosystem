## Description
`type` = `com.retailnetwork.commerce.offer-availability.listing.ListingRestored`; subject and key = the listingId. Raised by RestoreListing when the node became ACTIVE again and the listing had been suppressed for NODE_NOT_SELLABLE. A listing suppressed for DISCONTINUED is never restored.
