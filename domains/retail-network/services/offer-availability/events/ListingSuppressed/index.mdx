## Description
`type` = `com.retailnetwork.commerce.offer-availability.listing.ListingSuppressed`; subject and key = the listingId. Raised by SuppressListing: on NodeSuspended/NodeRetired (reason NODE_NOT_SELLABLE), on creation for a node that is not sellable (NODE_NOT_SELLABLE) or a discontinued item (DISCONTINUED), and on DiscontinueItem (DISCONTINUED). A listing suppressed for NODE_NOT_SELLABLE that is then suppressed for DISCONTINUED raises a second ListingSuppressed with the new reason. DISCONTINUED is final.
