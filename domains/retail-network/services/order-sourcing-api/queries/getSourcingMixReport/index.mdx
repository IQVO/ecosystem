## Overview
Per UTC day of release (decidedAt of FulfillmentSourcingDecided): groupsReleased = the releases of that day; inRegionShare = releases whose node is in the destination's region / releases with both regions known, with unknownRegionCount = releases with an unknown region; meanLegs = the departures after the pickup per release; reassignmentRate = releases with releaseNo > 1 / groupsReleased; unsourceableCount = the FulfillmentUnsourceable events of that day. A day appears when it has a release or an unsourceable declaration.




## GET `(/reports/sourcing-mix)`

### Parameters
- **from** (query): First UTC day of the range, inclusive. Omitted = 29 days before `to` (a 30-day range).
- **to** (query): Last UTC day of the range, inclusive. Omitted = today. At most 366 days from `from`.
