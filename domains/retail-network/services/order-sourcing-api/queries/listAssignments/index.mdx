## Overview
Filters combine with AND; an empty result is 200 with an empty list. nodeId matches the current candidate node (QUEUED), or the node of the latest release (RELEASED and later). Results are ordered by assignmentId ascending and capped by limit.




## GET `(/assignments)`

### Parameters
- **state** (query)
- **nodeId** (query)
- **orderId** (query)
- **limit** (query): Maximum number of assignments returned. Defaults to 100.
