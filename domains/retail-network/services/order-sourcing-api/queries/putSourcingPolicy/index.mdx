## Overview
Replaces the whole policy document: validates both ranges, stores version n+1 (n is the highest stored version, 0 when none) and raises the analytics-only SourcingPolicyPublished event in the same transaction. An omitted field takes its default, 0 (the lever is off); an empty body is 400. Every call publishes a NEW version, so it takes an Idempotency-Key like a POST: the same key with the same body replays the first answer for 24 hours instead of publishing twice; the same key with another request is 409 idempotency-key-reused. Searches that started before the publish keep the version they read.




## PUT `(/sourcing-policy)`

### Parameters
- **Idempotency-Key** (header) (required): 1 to 128 printable ASCII characters, one per logical submit. A repeated key with the same request returns the stored response of the first call (24 hours, header Idempotency-Replayed: true); with another request it is 409 idempotency-key-reused.
