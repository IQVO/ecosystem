## Overview
Re-runs the candidate search (AssignmentCost = legs + crossRegionPenalty + scorecardPenalty + bookPressurePenalty, ties to the witness node) over the current read models, skipping excluded nodes and any candidate whose eta is after deliverByLatest. Allowed only while QUEUED. If the best node changes the assignment moves (FulfillmentReassigned is published) and releaseAt follows the new candidate (VirtualQueue); if no candidate is left the assignment becomes UNSOURCEABLE at once (FulfillmentUnsourceable, gap G26). A repeat on unchanged read models changes nothing. The Idempotency-Key replays the first response for 24 hours.




## POST `(/assignments/{assignmentId}:reoptimise)`

### Parameters
- **assignmentId** (path) (required)
- **Idempotency-Key** (header) (required): A repeated key returns the stored response of the first call (24 hours).
