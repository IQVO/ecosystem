## Description
`type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentLocked`; subject and key = the assignmentId; stream `events` (topic `retailnetwork.order-sourcing.events`). Raised by LockAssignment (RELEASED to LOCKED) on PurchaseOrderAccepted. Adds promiseId, groupNo and orderId (contracts-delta E1) so delivery-promise can keep its assignmentId map. `lockReason` is PURCHASE_ORDER_ACCEPTED. In a MERGED release (ADR 0015) the carrier's acceptance locks every member: each raises its own FulfillmentLocked with the carrier's `nodeId` and `pickupDepartureId`; `mergedAssignmentIds` lists every merged assignment id, carrier included, ascending, and a follower also carries `consolidatedInto` (the carrier). Both are omitted when the assignment is not merged. Linehaul books ONE package, on the carrier's lock. Consumers: delivery-promise, customer-ordering, linehaul-transportation.
