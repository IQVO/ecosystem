## Description
`type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentReassigned`; subject and key = the assignmentId; stream `events` (topic `retailnetwork.order-sourcing.events`). Raised when the candidate NODE changes: ReoptimiseAssignment, the release re-check, HandleNodeRefusal on another node, or ApplyRevisedPromise. `reason` is one of REOPTIMISED, RELEASE_RECHECK, PURCHASE_ORDER_REJECTED, PURCHASE_ORDER_EXPIRED, PROMISE_REVISED. `assignmentVersion` is the version after the change, so consumers can drop stale copies. Consumer: linehaul-transportation.
