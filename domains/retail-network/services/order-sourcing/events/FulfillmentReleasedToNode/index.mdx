## Description
`type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentReleasedToNode`; subject and key = the assignmentId; stream `events` (topic `retailnetwork.order-sourcing.events`). Raised by ReleaseToNode (QUEUED to RELEASED). `releaseNo` is 1 for the first release and +1 for each later one; with `assignmentId` it is the purchase order's idempotency key. `lines` is the whole group (fill-or-kill) with this node's listingId. No ship-to data: the release carries no PII. Consumers: vendor-connectivity, linehaul-transportation.
