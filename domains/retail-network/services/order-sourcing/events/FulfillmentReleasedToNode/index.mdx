## Description
`type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentReleasedToNode`; subject and key = the assignmentId; stream `events` (topic `retailnetwork.order-sourcing.events`). Raised by ReleaseToNode (QUEUED to RELEASED). `releaseNo` is 1 for the first release and +1 for each later one; with `assignmentId` it is the purchase order's idempotency key. `lines` is the whole group (fill-or-kill) with this node's listingId. `estimatedCostCents` is the money-denominated AssignmentCost estimate of the released path in planner-declared cents (ADR 0011); it is omitted when the estimate is incomplete (a lane or the wave had no declared cost), so consumers must decode it tolerantly — the field is additive and optional. `policyVersion` is the sourcing policy version the search read (ADR 0014); it is omitted when no policy was published. `effectiveCostCents` is the estimate plus the policy's cross-region surcharge; it is omitted unless a surcharge changed the cost (both fields additive and optional, decoded tolerantly). Each line's optional `ownerRef` is the seller whose stock the line takes, as the OwnerChoice rule picked it at this node (ADR 0012: operator-owned first if it covers the line, else the covering seller with the highest availableQty, ties to the lowest ownerRef in byte order; a line never spans owners); it is omitted when the line is operator-owned. No ship-to data: the release carries no PII. Consumers: vendor-connectivity, linehaul-transportation. Consumers: vendor-connectivity (lines[].ownerRef). A MERGED release (ADR 0015) is the carrier's: `assignmentId`, `orderId` and `groupNo` stay the carrier's, `members` lists every merged group (carrier first, then ascending assignmentId) and is omitted when the release is not merged, `lines` is the union in member order with listing and owner chosen on the summed quantity, each line's optional `assignmentId` names its member, `promisedDeliverByLatest` is the minimum over the members and `tier` is the fulfilment class (a CONSOLIDATED group is released as STANDARD: the fifth tier never leaves this service on a release). One purchase order covers the union.
