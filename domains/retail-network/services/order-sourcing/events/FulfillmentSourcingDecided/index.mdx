## Description
`type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentSourcingDecided`; subject and key = the assignmentId; stream `analytics` (topic `retailnetwork.order-sourcing.analytics`). Raised by ReleaseToNode in the SAME transaction as each FulfillmentReleasedToNode (same aggregate version, its own CloudEvents id), ADR 0013. `nodeRegionId` and `destinationRegionId` are the regions of the released node and of the destination's service area from the local NetworkGraphView, each omitted when unknown; `inRegion` is omitted when either is unknown. `legs` counts the departures after the pickup (0 = straight to the station). `estimatedCostCents` follows ADR 0011 and is present exactly when `costComplete` is true. `units` is the sum of the line quantities; `candidateCount` the size of the ranked candidate set the release chose from. `policyVersion` and `effectiveCostCents` are those of the FulfillmentReleasedToNode of the same release (ADR 0014; omitted when no policy was published / no surcharge applied). In a MERGED release (ADR 0015) every member raises its own fact: `units` stays the member's own, `consolidatedCount` is the number of merged groups and a follower also carries `carrierAssignmentId`; both are omitted when the release is not merged. One package costs once: the analytics projection books the follower's `estimatedCostCents` as 0 (the carrier holds it). Analytics only: published ONLY to retailnetwork.order-sourcing.analytics.
