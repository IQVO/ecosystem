## Description
`type` = `com.retailnetwork.commerce.order-sourcing.policy.SourcingPolicyPublished`; subject and key = `policy` (the policy is one versioned document); stream `analytics` (topic `retailnetwork.order-sourcing.analytics`). Raised by `PUT /sourcing-policy` in the SAME transaction as the new version row (ADR 0014). `version` is the new version number (1 for the first publish, then +1); `crossRegionSurchargeCents` (0..100000) is added to the effective cost of a candidate whose node region differs from the delivery area region; `maxCostDeviationPercent` (0..200) is the regional budget over the cheapest effective cost, 0 = off; `consolidationMaxAssignments` (0..10) is the most groups one merged release holds, 0 and 1 = off (ADR 0015). Analytics only: published ONLY to retailnetwork.order-sourcing.analytics.
