## Overview
Adds one carton to a `DRAFT` shipment. `sscc` is optional: a supplied SSCC must be valid and unique network-wide, otherwise the network issues one and returns it. `kind` is `HOMOGENEOUS_CASE` (one item at one quantity, matching the case GTIN) or `MIXED`. `parentSscc` names the pallet SSCC when the node accepts pallets. The carton is checked against the node's inbound limits. The response carries the carton and its label data.




## POST `(/inbound-shipments/{shipmentId}/cartons)`

### Parameters
- **shipmentId** (path) (required): The inbound shipment id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
