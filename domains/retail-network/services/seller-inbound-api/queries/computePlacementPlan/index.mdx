## Overview
Roadmap feature F6 (ADR 0012): reads the DemandHeatView (fulfilments locked per (item, region) over the observation window and current listing availability per node) and records a deterministic placement advisory. For each region with demand, suggested units per node = max(0, ceil(demand x coverDays / windowDays) - region availability) split across the region's ACTIVE vendor fulfilment centres proportionally to their availability (evenly when all zero). An item with no demand anywhere yields an EMPTY plan, which is legal. A new plan for the same (sellerId, catalogItemId) supersedes the previous one. Publishes PlacementPlanSuggested (analytics-only consumer in v1).




## POST `(/placement-plans)`

### Parameters
- **Idempotency-Key** (header) (required): Client-generated key, 1 to 128 printable ASCII characters (a UUID per logical submit). A retry with the same key and the same request replays the first response with `Idempotency-Replayed true`; the same key on a different method, path or body is `409 idempotency-key-reused`.
