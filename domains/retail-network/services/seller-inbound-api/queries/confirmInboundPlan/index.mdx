## Overview
Moves a `DRAFT` plan to `CONFIRMED` and publishes `InboundPlanConfirmed`. Shipments are opened only against a confirmed plan. Confirming a confirmed or cancelled plan is `illegal-transition`.




## POST `(/inbound-plans/{planId}:confirm)`

### Parameters
- **planId** (path) (required): The inbound plan id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
