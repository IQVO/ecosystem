## Overview
Declares what the seller will send to one destination node. The plan starts `DRAFT`. The seller must be `ACTIVE`; the node must be `ACTIVE` with the INBOUND capability (`node-cannot-receive`). Every line is in eaches; for `CASE_PACKED` each line's quantity must be a whole number of the case GTIN's units per pack.




## POST `(/inbound-plans)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
