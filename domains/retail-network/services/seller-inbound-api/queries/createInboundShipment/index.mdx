## Overview
Opens a `DRAFT` shipment against a `CONFIRMED` plan of an `ACTIVE` seller. The shipment inherits the plan's destination node.




## POST `(/inbound-plans/{planId}/shipments)`

### Parameters
- **planId** (path) (required): The inbound plan id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
