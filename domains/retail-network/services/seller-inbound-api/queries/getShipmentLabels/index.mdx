## Overview
Returns the label DATA of every carton: SSCC, the GS1-128 element string `(00)<sscc>`, the human readable line, the contents summary in eaches and the destination node.




## GET `(/inbound-shipments/{shipmentId}/labels)`

### Parameters
- **shipmentId** (path) (required): The inbound shipment id.
