## Overview
Moves a `DRAFT` shipment to `LABELLED`: the cartons must add up to the confirmed plan (`carton-contents-mismatch-plan`) and the manifest is frozen. Publishes `InboundShipmentLabelled`. Only a `DRAFT` shipment can be labelled (`illegal-transition` otherwise).




## POST `(/inbound-shipments/{shipmentId}:label)`

### Parameters
- **shipmentId** (path) (required): The inbound shipment id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
