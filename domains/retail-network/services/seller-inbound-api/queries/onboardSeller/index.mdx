## Overview
Used by network partner managers. Creates the account `ACTIVE` and publishes `SellerOnboarded`. A `sellerId` that already exists is `seller-exists`.




## POST `(/sellers)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
