## Overview
Moves the account `SUSPENDED` to `ACTIVE` and publishes `SellerReinstated`. A seller already `ACTIVE` gets the account back unchanged with `200` and no event.




## POST `(/sellers/{sellerId}:reinstate)`

### Parameters
- **sellerId** (path) (required): The seller id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
