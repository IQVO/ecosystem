## Overview
Moves a `LABELLED` shipment to `SHIPPED` and publishes `InboundShipmentShipped`. A shipment that is not labelled is `shipment-not-labelled`; a suspended seller ships nothing (`seller-suspended`). Only a `LABELLED` shipment ships.




## POST `(/inbound-shipments/{shipmentId}:ship)`

### Parameters
- **shipmentId** (path) (required): The inbound shipment id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
