## Overview
Moves the account `ACTIVE` to `SUSPENDED` and publishes `SellerSuspended`. A seller already `SUSPENDED` gets the account back unchanged with `200` and no event. While suspended, the seller creates no plan, shipment or carton and ships nothing.




## POST `(/sellers/{sellerId}:suspend)`

### Parameters
- **sellerId** (path) (required): The seller id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response.
