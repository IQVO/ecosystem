## Overview
In-org route called by vendor-connectivity (contracts-delta E2). Reads the ship-to from customer-ordering (GET /orders/\{orderId\}/ship-to) BEFORE the transaction opens, stores it encrypted, starts the package journey (LABELLED) and publishes LabelIssued. The response never contains the address. A replay of the same Idempotency-Key returns the first response.




## POST `(/labels)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key (at most 128 characters); a repeat with the same key replays the first response (24 hours).
