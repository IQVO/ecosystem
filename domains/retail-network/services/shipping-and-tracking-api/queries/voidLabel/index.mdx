## Overview
Moves the label ISSUED to VOIDED, closes the LABELLED journey of the same tracking number as VOIDED and publishes LabelVoided (contracts-delta E16). Refused once the package has been handed over (void-after-handover). Voiding a VOIDED label returns it unchanged and publishes nothing.




## POST `(/labels/{labelRef}:void)`

### Parameters
- **labelRef** (path) (required)
- **Idempotency-Key** (header) (required): Client-chosen key (at most 128 characters); a repeat with the same key replays the first response (24 hours).
