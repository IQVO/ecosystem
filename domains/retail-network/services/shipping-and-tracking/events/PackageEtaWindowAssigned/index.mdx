## Description
`type` = `com.retailnetwork.logistics.shipping-and-tracking.journey.PackageEtaWindowAssigned` produced by shipping-and-tracking on `retailnetwork.shipping-and-tracking.events` (subject and key = the tracking number). The window is stored on the package row (the latest `assignedAt` wins) and the tracking view shows it only while the package is OUT_FOR_DELIVERY and the window is not older than the last scan (ADR 0014). A blank trackingNumber, or an etaStart that is not before etaEnd, is a payload that can never be applied and is dead-lettered. A missing assignedAt falls back to the event time. The group promise is never read or written. Dispatch on the full type; unknown fields are ignored.
