## Overview
Asynchronous (`SubmissionKind` `NODE_PROFILE`). On processing, the profile is
relayed to node-topology (`PUT /nodes/{nodeId}/operational-profile`,
`DeclareOperationalProfile`). A profile is versioned: `profileRevision` must
strictly increase. Downstream refusals (`ErrStaleProfileRevision`,
`ErrIncompleteOperationalProfile`, `ErrCutoffOutsideOperatingHours`) appear
as `errors` on the transaction.





## PUT `(/vendor/nodes/{nodeId}/profile)`

### Parameters
- **nodeId** (path) (required): The network's id of the vendor node.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
