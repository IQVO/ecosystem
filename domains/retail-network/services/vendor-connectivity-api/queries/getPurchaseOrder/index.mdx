## Overview
One purchase order of the calling vendor, with its acknowledgement (once its transaction succeeded), labels and shipment. A purchase order of another vendor is `node-not-owned-by-vendor`.




## GET `(/vendor/purchase-orders/{poNumber})`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **poNumber** (path) (required): The purchase order number. Idempotent on the release it was issued for.




### Responses

#### <span className="text-green-500">200 OK</span>
The network's instruction to one vendor node to ship one shipment group in
full by `requiredShipBy`. Carries no ship-to PII.
