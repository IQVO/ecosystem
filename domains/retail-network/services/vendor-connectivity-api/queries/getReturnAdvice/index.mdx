## Overview
One return advice. Unlike the poll, this read also answers for a closed advice
(`state` `CANCELLED` or `OUTCOME_RECORDED`); an advice that is unknown, or is
addressed to another vendor's node, is `not-found`.





## GET `(/vendor/return-advices/{authorizationId})`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **authorizationId** (path) (required): The customer-returns return authorization id.
