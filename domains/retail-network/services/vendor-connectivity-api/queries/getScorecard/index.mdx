## Overview
Relayed synchronously from node-performance (`GET /scorecards/{nodeId}`). A node without observations has no scorecard: `404` `not-found`.




## GET `(/vendor/nodes/{nodeId}/scorecard)`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **nodeId** (path) (required): The network's id of the vendor node.




### Responses

#### <span className="text-green-500">200 OK</span>
node-performance's scorecards of the node, one entry per rolling window (7d feeds alerts; 30d is the grade consumers use).
