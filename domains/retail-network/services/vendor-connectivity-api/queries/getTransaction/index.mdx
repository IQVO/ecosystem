## Overview
The outcome of any asynchronous write of the calling vendor. A transaction of another vendor is `not-found`. A processed `NODE_REGISTRATION` transaction carries the new `nodeId`.




## GET `(/vendor/transactions/{transactionId})`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **transactionId** (path) (required): The id returned by the `202` of the write.
