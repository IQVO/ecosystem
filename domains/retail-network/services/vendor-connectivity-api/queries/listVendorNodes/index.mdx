## Overview
Served from the local VendorNodeView, fed by node-topology events. Returns the nodes whose owner is `vendorId`, ordered by `nodeId` (G30).




## GET `(/vendor/nodes)`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
