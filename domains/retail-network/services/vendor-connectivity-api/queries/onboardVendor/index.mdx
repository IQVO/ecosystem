## Overview
Used by network partner managers. Publishes `VendorOnboarded`. Onboarding an existing `vendorId` with a new Idempotency-Key returns the existing account unchanged with `200` (assumption A8).




## POST `(/vendors)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
