## Overview
Returns the `SHIPPED` inbound shipments bound for the vendor's nodes after
`createdAfter`, oldest first, in pages. Every shipment is the pallet-and-carton
tree shipment > pallet > carton > item. `createdAfter` compares with `shippedAt`,
the instant the seller handed the shipment over. Pass the returned `nextToken`
for the next page; an absent `nextToken` means the last page. A shipment
leaves the poll once the network records its receipt.





## GET `(/vendor/inbound-shipments)`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **createdAfter** (query): Only shipments with `shippedAt` strictly after this instant.
- **nodeId** (query): Only shipments bound for this node.
- **nextToken** (query): Opaque continuation token from the previous page. When present, the other filters are ignored.
- **limit** (query): Page size, 1 to 200 (default 50).
