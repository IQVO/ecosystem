## Overview
Returns purchase orders issued to the vendor's nodes after `createdAfter`,
oldest first, in pages. Pass the returned `nextToken` to fetch the next
page; an absent `nextToken` means the last page. A purchase order can be
returned again (`PO_REDELIVERY_RATE`); the vendor deduplicates on `poNumber`.





## GET `(/vendor/purchase-orders)`

### Parameters
- **vendorId** (query) (required): The calling vendor (G32). Ownership of the addressed resource is checked against it.
- **createdAfter** (query): Only purchase orders with `issuedAt` strictly after this instant.
- **nodeId** (query): Only purchase orders for this node.
- **nextToken** (query): Opaque continuation token from the previous page. When present, the other filters are ignored.
- **limit** (query): Page size, 1 to 200 (default 50).
