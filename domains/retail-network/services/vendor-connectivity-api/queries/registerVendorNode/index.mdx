## Overview
Asynchronous (`SubmissionKind` `NODE_REGISTRATION`). On processing, the node
is registered with node-topology (`POST /nodes`, `RegisterNode`, operator `VENDOR`). A vendor
may register only `FULFILLMENT_CENTER`, `INBOUND_CROSS_DOCK` or
`RETURNS_CENTER` nodes. The processed transaction carries the new `nodeId` (G30).
Downstream refusals (for example `ErrOperatorNotAllowedForNodeType`,
`ErrVendorNodeCodeTaken`) appear as `errors` on the transaction.





## POST `(/vendor/nodes)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
