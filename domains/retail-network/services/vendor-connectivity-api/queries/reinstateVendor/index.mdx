## Overview
Used by network partner managers. Moves the account `SUSPENDED` to `ACTIVE` and publishes `VendorReinstated` (G30). A vendor already `ACTIVE` gets the account back unchanged with `200` and no event (assumption A8). 




## POST `(/vendors/{vendorId}:reinstate)`

### Parameters
- **vendorId** (path) (required): The vendor account id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
