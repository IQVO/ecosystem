## Overview
Accepts or rejects the whole purchase order with one decision. The request
must echo every line with its ordered quantity; anything else is a partial
acknowledgement and is refused (`ErrPartialAcknowledgement`). A purchase
order is acknowledged at most once (`ErrAlreadyAcknowledged`, which also
covers an acknowledgement still processing) and never after `ackBy`
(`ErrAckWindowClosed`, judged on the receipt instant). On `202` the order
moves to `ACK_PROCESSING`; it becomes `ACCEPTED` or `REJECTED` when the
transaction succeeds, and returns to `ISSUED` if it fails.





## POST `(/vendor/acknowledgements)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
