## Overview
Asynchronous (`SubmissionKind` `INBOUND_RECEIPT`). The shipment must be known
and `SHIPPED`, `nodeId` must be its destination and belong to the vendor, and
every carton `sscc` must be on the shipment, except a carton reported
`UNEXPECTED`. A `MISSING` carton has no items; the GTINs counted in a
carton must be GTINs of that carton on the manifest. Counting more or fewer
eaches than the manifest says is a discrepancy to report, never a refusal.
On `202` the network publishes `InboundReceiptSubmitted`.





## POST `(/vendor/inbound-receipts)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
