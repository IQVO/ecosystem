## Overview
Asynchronous (`SubmissionKind` `INVENTORY`). On processing, the feed is
relayed to offer-availability (`POST /inventory-feeds`, `ApplyInventoryFeed`).
A full feed zeroes every listing of the node it omits. Downstream refusals
(for example `ErrListingNotOnNode`, `ErrFeedAlreadyApplied`) appear as
`errors` on the transaction.





## POST `(/vendor/inventory)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
