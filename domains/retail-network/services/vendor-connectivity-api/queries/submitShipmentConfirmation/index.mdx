## Overview
Asynchronous (`SubmissionKind` `SHIPMENT_CONFIRMATION`). Allowed only for an
`ACCEPTED` purchase order with a label for every package
(`ErrConfirmWithoutLabel`). On `202` the order moves to `SHIPMENT_PROCESSING`;
it becomes `SHIPPED` when the transaction succeeds and returns to `ACCEPTED`
if it fails.





## POST `(/vendor/shipment-confirmations)`

### Parameters
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
