## Overview
Used by network partner managers. Moves the account `ACTIVE` to `SUSPENDED` and publishes `VendorSuspended` (G30). A vendor already `SUSPENDED` gets the account back unchanged with `200` and no event (assumption A8). While suspended, every write of the vendor is refused with `vendor-suspended`; reads and the polling of purchase orders continue.




## POST `(/vendors/{vendorId}:suspend)`

### Parameters
- **vendorId** (path) (required): The vendor account id.
- **Idempotency-Key** (header) (required): Client-chosen key. A retry with the same key returns the first response (for an asynchronous write, the same `transactionId`).
