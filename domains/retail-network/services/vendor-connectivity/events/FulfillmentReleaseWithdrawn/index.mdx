## Description
Consumed from order-sourcing. `type` = `com.retailnetwork.commerce.order-sourcing.assignment.FulfillmentReleaseWithdrawn`; subject and key = the carrier's `assignmentId`. The order is found by (`assignmentId`, `releaseNo`), never as "the latest"; an unknown release is a no-op; an order past ISSUED stays as it is (logged). The cancel reason is `release withdrawn: <reason>` (ADR 0013). Only the listed `data` fields are relied on; unknown fields are ignored.
