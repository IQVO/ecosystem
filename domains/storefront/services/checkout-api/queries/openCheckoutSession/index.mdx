## Overview
OpenSession. Reads the cart snapshot (shopping-cart GET /carts/\{cartId\}), checks every selected offer is still QUOTED with margin (delivery-promise GET /delivery-offers/\{offerId\}), issues the binding PriceQuote (pricing POST /price-quotes) and opens the session. The BFF then shows the review page with the binding total. shipToAddressId references a saved address held by customer-ordering (NG1); the address itself never enters the storefront.




## POST `(/checkout-sessions)`

### Parameters
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit, 1-128 printable ASCII characters. A repeat of the same method, path and body replays the stored answer (response header Idempotency-Replayed: true); the same key on a different request is 409 idempotency-key-reused.
