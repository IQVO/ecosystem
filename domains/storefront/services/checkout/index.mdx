## Purpose
The purchase saga: one transaction across price, payment and the network's promise confirmation. Authorize before placing the order (compensatable: void), place the order (pivot), then retriable steps via events. PLACING is the semantic lock: while the place-order outcome is unknown there is no void and no new attempt. Holds shopperId and shipToAddressId references, never PII; the stored placement request is PII-free so it can be replayed byte for byte.

context's own reports and are never consumed by another context.

## Contract


Event catalog for the **checkout** bounded context of the storefront (Supporting subdomain): the purchase saga from review to placed order (ADR 0001, ADR 0002).

**Published.** Seven events. `CheckoutCompleted` is the one integration event: it goes to `retailnetwork.checkout.events` and is consumed by shopping-cart (CloseOnCheckoutCompleted) and customer-payments (BindOrderOnCheckoutCompleted). `CheckoutOpened`, `CheckoutDeclined`, `CheckoutRequoteRequired`, `CheckoutFailed`, `CheckoutSessionExpired` and `CheckoutPlacementInDoubt` are analytics-only and go to `retailnetwork.checkout.analytics` (decision H7). ConfirmSession and RecordAuthorization raise nothing. Every event goes through a **transactional outbox**; an always-on relay drains them to Kafka, at-least-once. The types are catalogued in ADR 0004.

**Consumed.** Nothing: the saga is driven by REST calls and policies; sibling data is read synchronously (ADR 0003).

**Envelope (mandatory).** CloudEvents 1.0, structured content mode, Kafka header `content-type: application/cloudevents+json; charset=UTF-8`. `specversion`, `id`, `source` (`/retailnetwork/checkout`), `type`, `subject` (the sessionId), `time`, `datacontenttype` (`application/json`) and `dataschema` (`urn:retailnetwork:checkout:<events|analytics>:<EventName>:v1`) are all required. Kafka key = the subject. Type = `com.retailnetwork.storefront.checkout.checkoutsession.<EventName>`. A breaking payload change is a new `.v2` type, never a mutation.

**Conventions.** `data` is camelCase; instants are RFC 3339 UTC; money is integer minor units; enums are UPPER_SNAKE.
