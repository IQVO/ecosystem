## Overview
ListAuthorizations. Exactly one of orderId or checkoutSessionId is required. Keyset-paged, oldest first (createdAt, authorizationId): follow nextCursor until it is absent and repeat the filter on every page request.




## GET `(/payment-authorizations)`

### Parameters
- **orderId** (query)
- **checkoutSessionId** (query)
- **limit** (query): Page size, 1 to 500 (default 100). Anything else is 400 invalid-limit.
- **cursor** (query): Opaque token copied from the previous page's nextCursor; absent on the first page. One that does not decode is 400 invalid-cursor.
