## Overview
ListRefunds. Keyset-paged, oldest first (createdAt, refundId): follow nextCursor until it is absent and repeat orderId on every page request.




## GET `(/refunds)`

### Parameters
- **orderId** (query) (required)
- **limit** (query): Page size, 1 to 500 (default 100). Anything else is 400 invalid-limit.
- **cursor** (query): Opaque token copied from the previous page's nextCursor; absent on the first page. One that does not decode is 400 invalid-cursor.
