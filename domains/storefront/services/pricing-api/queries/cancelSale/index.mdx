## Overview
CancelSale. Transition resource: answers 200 with the updated item price. Cancelling a live sale emits ItemPriceChanged at the boundary.




## POST `(/item-prices/{catalogItemId}/sales/{saleId}/cancellations)`

### Parameters
- **catalogItemId** (path) (required)
- **saleId** (path) (required)
- **Idempotency-Key** (header) (required): 1-128 printable ASCII characters, a client-generated UUID per logical submit (a retry reuses it). A repeated key with the same method, path and body returns the stored response with Idempotency-Replayed: true; with a different method, path or body it is 409 idempotency-key-reused. Missing is 400 idempotency-key-required; malformed is 400 idempotency-key-invalid.
