## Overview
Keyset-paged list of item prices ordered by (catalogItemId). Used by product-discovery's projection rebuild (snapshot + catch-up); not part of a user request path. Follow nextCursor until it is absent. Any query parameter other than limit and cursor is answered 400 unknown-query-parameter.




## GET `(/item-prices)`

### Parameters
- **limit** (query): Page size, 1-500 (default 100). Out of range is 400 invalid-limit.
- **cursor** (query): Opaque keyset cursor taken from the previous page's nextCursor; an undecodable cursor is 400 invalid-cursor.
