## Overview
CreateProductContent. The item must exist in the local CatalogItemView (fed by offer-availability events) and must not be discontinued. The content starts DRAFT at revision 1; the body may be incomplete (the publish gate is checked by POST /product-contents/\{catalogItemId\}/publications). A second create for the same item is a 409 concurrent-update.




## POST `(/product-contents)`

### Parameters
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit (1 to 128 printable ASCII characters); a retry reuses it. The same key with the same request (method, path, body) replays the stored answer with Idempotency-Replayed: true; the same key with another request is 409 idempotency-key-reused. Missing is 400 idempotency-key-required, malformed is 400 idempotency-key-invalid.
