## Overview
DiscardDraft. DRAFT to RETIRED with retiredReason DISCARDED. Nothing was ever published, so no event is raised. DELETE is idempotent by method and takes no Idempotency-Key; a repeat finds the content already RETIRED and answers 409 illegal-transition.
