## Overview
Returns the categories of the current CategoryTree version, ordered by path (parents before children). Before the first category the tree is version 0 and empty. Not paged (x-pagination-exempt: view): the tree is ONE versioned aggregate, so one response is one consistent snapshot of one version; the tree is at most four levels deep.
