## Overview
Keyset-paged list of product contents of every state, ordered by catalogItemId. Used by product-discovery's projection rebuild (snapshot + catch-up); not part of a user request path. Follow nextCursor until it is absent. Any query parameter other than limit and cursor is a 400 unknown-query-parameter.




## GET `(/product-contents)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100). Anything else is 400 invalid-limit.
- **cursor** (query): Opaque token copied from the previous page's nextCursor; absent on the first page. One that does not decode is 400 invalid-cursor.
