## Overview
PublishContent. DRAFT to PUBLISHED, or PUBLISHED to PUBLISHED when a revision is waiting. Publish needs a description, exactly one PRIMARY medium and a category (ErrIncompleteContent) and a catalogue item that is not discontinued. Publishes ProductContentPublished with the current revision. PUBLISHED content whose current revision is already published is returned unchanged and publishes nothing.




## POST `(/product-contents/{catalogItemId}/publications)`

### Parameters
- **catalogItemId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit (1 to 128 printable ASCII characters); a retry reuses it. The same key with the same request (method, path, body) replays the stored answer with Idempotency-Replayed: true; the same key with another request is 409 idempotency-key-reused. Missing is 400 idempotency-key-required, malformed is 400 idempotency-key-invalid.
