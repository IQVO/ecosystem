## Overview
ReviseDraft (DRAFT to DRAFT) or ReviseContent (PUBLISHED to PUBLISHED), chosen by the state. The body replaces the whole editable content and takes a new revision. PUBLISHED content must stay complete (incomplete-content otherwise) and shoppers see the revision only after POST /product-contents/\{catalogItemId\}/publications publishes it. Revising RETIRED content is a 409 content-retired.




## POST `(/product-contents/{catalogItemId}/revisions)`

### Parameters
- **catalogItemId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit (1 to 128 printable ASCII characters); a retry reuses it. The same key with the same request (method, path, body) replays the stored answer with Idempotency-Replayed: true; the same key with another request is 409 idempotency-key-reused. Missing is 400 idempotency-key-required, malformed is 400 idempotency-key-invalid.
