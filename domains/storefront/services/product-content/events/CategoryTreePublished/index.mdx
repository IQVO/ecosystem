## Description
`type` = `com.retailnetwork.storefront.product-content.categorytree.CategoryTreePublished`; subject and key = the categoryTreeId (`main`). Raised by every CreateCategory, MoveCategory, RenameCategory and PublishCategoryTree, in the same transaction as the tree row: the tree is one live aggregate with no draft state, so every command publishes a new version. Carries the WHOLE tree ordered by path, so a consumer replaces its tree when `version` is above the last applied one.
