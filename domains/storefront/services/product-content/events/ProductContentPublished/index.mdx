## Description
`type` = `com.retailnetwork.storefront.product-content.productcontent.ProductContentPublished`; subject and key = the catalogItemId. Raised by PublishContent (DRAFT to PUBLISHED, or PUBLISHED to PUBLISHED when a revision is waiting) in the same transaction as the outbox row. Carries the full content, so product-discovery never calls back; `revision` orders it (apply only above the last applied revision). No title, price or stock: those belong to other contexts.
