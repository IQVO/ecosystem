## Overview
SearchProducts over the ProductView projection. q runs full-text search (tsvector weights title A, category names A, attributes B, description C) with a pg_trgm similarity fallback for typos; filters combine with AND. Product-type queries also return category suggestions. Keyset pagination: limit (1-500, default 100) and the opaque cursor taken from the previous page's nextCursor; filters are repeated on every page. A query parameter the operation does not declare (for example the retired after) is a 400 unknown-query-parameter.




## GET `(/products)`

### Parameters
- **q** (query)
- **categoryId** (query)
- **inStock** (query)
- **priceMin** (query): Effective price lower bound in minor units.
- **priceMax** (query): Effective price upper bound in minor units.
- **sort** (query)
- **limit** (query)
- **cursor** (query): Opaque keyset cursor; pass the nextCursor of the previous page unchanged, with the same filters and sort.
