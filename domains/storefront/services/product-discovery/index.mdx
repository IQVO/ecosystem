## Purpose
The read side of browsing and search: one ProductView per catalogue item (title, flags, content, categoryId, list and effective price, inStock, purchasable; the category path is joined from CategoryView at query time) and one CategoryView (tree plus purchasable counts), fed by events from offer-availability, product-content and pricing, searched with PostgreSQL full-text search and pg_trgm (D9), behind a port so a dedicated engine is a later adapter swap.

`<ctx>.events` topics carry the integration contract; `<ctx>.analytics` topics carry projector input for the
context's own reports and are never consumed by another context.

## Contract


Consumed-event notes for the **product-discovery** bounded context (read side, no aggregate, ADR 0001, ADR 0003). The service **publishes nothing**: `publishes: []` in the model, so there is no outbox, no relay and no `retailnetwork.product-discovery.events` topic. This file records the shape of the eleven events it consumes; each producer's own AsyncAPI is authoritative, unknown fields are ignored (tolerant decoding), and only the fields this service reads are listed.

**Consumed.** From offer-availability (`com.retailnetwork.commerce.offer-availability.<entity>.<Event>`): CatalogItemCreated, CatalogItemDiscontinued, ListingCreated, ListingAvailabilityChanged, ListingSuppressed, ListingRestored. From product-content (`com.retailnetwork.storefront.product-content.<entity>.<Event>`): ProductContentPublished, ProductContentRetired, CategoryTreePublished. From pricing (`com.retailnetwork.storefront.pricing.itemprice.<Event>`): ItemPriceChanged, ItemPriceWithdrawn. Three consumer groups, one per topic, each named by a mandatory environment variable.

**Processing.** CloudEvents 1.0 structured mode. Idempotent on the CloudEvents `id` (inbox table written in the same transaction as the projection), dispatch on the full `type` string, unknown types ignored, undecodable or unfoldable messages dead-lettered. Per-key monotonic guards on top of the inbox: listing `asOf`, content `revision`, price `version`, category tree `version`. A fact for an item the item master has not announced yet creates an invisible stub row that CatalogItemCreated completes (ADR 0002).
