## Purpose
Holds a shopper's intent: cart lines, the destination postal prefix, the delivery quote delivery-promise returned for the cart (per shipment group, with its offers and expiry), the shopper's tier selection per group, and a labelled, non-binding estimate (effective prices + selected tier charges + tax band) so the total cost is visible up front.

This service groups the context's synchronous surface: the OLTP REST API (`openapi.yaml`) and, where the
context has one, the separate read-only reports API (`openapi-reports.yaml`) served by its `*-reports`
binary from an isolated analytical database. Endpoints are unauthenticated fleet-wide.


REST contract of the shopping-cart bounded context of the digital storefront, derived from storefront/model/model.yaml (contexts[shopping-cart].rest) and the FINAL model-gap decisions (H1-H6 and checkout H10). The cart holds a shopper's intent: lines, destination postal prefix, the delivery quote delivery-promise returned for the cart (per shipment group, with offers and expiry), the shopper's tier selection per group, and a labelled, non-binding estimate (effective prices + selected tier charges + tax band) so the total cost is visible up front. Without a destination the estimate shows the item subtotal only and estimateComplete is false. One line per item; adding an existing item merges quantities. Any line or destination change clears the quote and the selections. Errors are RFC 9457 problem details (application/problem+json) whose type is /problems/&lt;slug>; shared types are not-found (404), illegal-transition (409), concurrent-update (409) and validation-failed (422), plus one kebab-case slug per Err of the model, and the idempotency problems idempotency-key-required and idempotency-key-invalid (400) and idempotency-key-reused (409). Every POST takes an Idempotency-Key header: a retry with the same key and the same request replays the first answer (Idempotency-Replayed: true), the same key with another request is 409 idempotency-key-reused. PUT and DELETE are idempotent by method. GET /carts is keyset-paged (\{items, nextCursor\}; invalid-limit, invalid-cursor and unknown-query-parameter are 400). No authentication; shopperId is optional (guest-first).
