## Overview
AcceptRequotedOffers. Checkout reports REQUOTE_REQUIRED with the requotedOffers it obtained for the groups it had selected; the BFF writes them here. The supplied set REPLACES the cart's delivery quote (one offer per group) and each offer is the selection of its group, WITHOUT calling delivery-promise. A group keeps the lineNos of the previous quote's group of the same number (a single-group quote spans every line). Lines and destination are untouched. Checkout re-verifies every offer with its pre-authorize check, so nothing is trusted here. Publishes nothing.




## POST `(/carts/{cartId}/delivery-requote-acceptances)`

### Parameters
- **cartId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit (1 to 128 printable ASCII characters); a retry reuses it. The same key with the same request (method, path, body) replays the stored answer with Idempotency-Replayed: true; the same key with another request is 409 idempotency-key-reused. Missing is 400 idempotency-key-required.
