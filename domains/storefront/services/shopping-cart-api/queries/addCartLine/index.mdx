## Overview
AddLine. One line per item: adding an item already in the cart merges quantities; nothing is ever rejected as a duplicate. Clears the current delivery quote and selections. Publishes CartLineAdded (analytics).




## POST `(/carts/{cartId}/lines)`

### Parameters
- **cartId** (path) (required)
- **Idempotency-Key** (header) (required): Client-generated UUID per logical submit (1 to 128 printable ASCII characters); a retry reuses it. The same key with the same request (method, path, body) replays the stored answer with Idempotency-Replayed: true; the same key with another request is 409 idempotency-key-reused. Missing is 400 idempotency-key-required.
