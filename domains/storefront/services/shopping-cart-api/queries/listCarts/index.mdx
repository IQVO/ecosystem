## Overview
ListCarts, filtered by shopperId and optionally state, newest first (createdAt, cartId descending). Keyset-paged: follow nextCursor until it is absent and repeat the filters on every page request.




## GET `(/carts)`

### Parameters
- **shopperId** (query) (required)
- **state** (query)
- **limit** (query): Page size, 1 to 500 (default 100). Anything else is 400 invalid-limit.
- **cursor** (query): Opaque token copied from the previous page's nextCursor; absent on the first page. One that does not decode is 400 invalid-cursor.
