## Overview
A QUEUED leg is cancelled at once (`200`, `LegFailed` reason CANCELLED). An ASSIGNED leg gets a VDA 5050 cancelOrder (`202`, CANCEL_REQUESTED) and ends CANCELLED when the robot confirms. A PICKED_UP leg is `409 leg-not-cancellable` (the container is on the robot); an ended leg is `409 leg-ended`.





## POST `(/fleets/{fleetId}/legs/{legId}/cancellation)`

### Parameters
- **fleetId** (path) (required): The fleet id (the map file's `fleetId`, e.g. AMR1).
- **legId** (path) (required): The leg id (`leg-<uuid>`).
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 characters (fleet guideline R3-R5); a missing or longer one is `400 idempotency-key-required`.
