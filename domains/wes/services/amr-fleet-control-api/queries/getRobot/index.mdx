## Overview
One robot of the registry, with its factsheet once the robot published one.




## GET `(/fleets/{fleetId}/robots/{manufacturer}/{serialNumber})`

### Parameters
- **fleetId** (path) (required): The fleet id (the map file's `fleetId`, e.g. AMR1).
- **manufacturer** (path) (required): The robot's VDA 5050 manufacturer.
- **serialNumber** (path) (required): The robot's VDA 5050 serial number.
