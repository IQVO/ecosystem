## Description
`type` = `com.warehouse.wes.amr-fleet-control.mission.LegFailed`; subject = the leg id. material-flow-control retries or fails the transport with it; exception-management (WCS plan 05, not built yet) is intended to open a case for reason ROBOT_BLOCKED. `container_on_robot` is true when the leg failed after the pickup.
