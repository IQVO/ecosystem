## Overview
A queued job is cancelled at once (`200`, status CANCELLED, `StorageJobFailed` reason CANCELLED). A job
already with the PLC gets a CANCEL telegram (`202`, status CANCEL_REQUESTED): the PLC's answer decides,
and a refused cancellation lets the job run to its outcome. A retrieve on its way to the port is
`409 job-not-cancellable`.





## POST `(/asrs/{asrsId}/storage-jobs/{storageJobId}/cancellation)`

### Parameters
- **asrsId** (path) (required): The AS/RS id of the layout file.
- **storageJobId** (path) (required): The storage job id (`sj-<uuid>`).
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 characters (fleet guideline R3-R5); a missing or longer one is `400 idempotency-key-required`.
