## Overview
material-flow-control confirms the handoff; the next retrieve to the port can then be presented. The PLC reports no removal, so this call is the only signal.




## POST `(/asrs/{asrsId}/ports/{portId}/pickups)`

### Parameters
- **asrsId** (path) (required): The AS/RS id of the layout file.
- **portId** (path) (required): An output port of the AS/RS.
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 characters (fleet guideline R3-R5); a missing or longer one is `400 idempotency-key-required`.
