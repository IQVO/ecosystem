## Overview
`kind` STORE stores the container waiting on input port `port_id`; its rack position is reserved now
(a full aisle is `422 storage-full`). `kind` RETRIEVE presents a stored container at `port_id`, or at
the first output port of its aisle when `port_id` is omitted; retrieves to one port are presented in
the order they are accepted. `reference` is echoed in every event of the job.





## POST `(/asrs/{asrsId}/storage-jobs)`

### Parameters
- **asrsId** (path) (required): The AS/RS id of the layout file.
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 characters (fleet guideline R3-R5); a missing or longer one is `400 idempotency-key-required`.
