## Description
`type` = `com.warehouse.wes.asrs-control.storagejob.ContainerPresentedAtPort`; subject = the storage job id. `scan_result` NO_READ or MISMATCH sends the container to clarification (material-flow-control).
> **No consumer by design:** pending: material-flow-control (plan WCS-04, designed in warehouse-docs wcs/, not built yet) is the intended consumer (WCS context map relationship 5, ADR 0003 type catalogue); no fleet context declares or handles this type yet.
