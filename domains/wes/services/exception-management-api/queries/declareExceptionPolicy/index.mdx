## Overview
Declares the handling policy of a source type at the next version
(versions are append-only: the first declaration is version 1, every
accepted declaration after that is +1). `sourceType` is the full
CloudEvents type of the governed source fact and must match a source
this service consumes. The new version governs cases opened after the
declaration; open cases keep the severity, queue and SLA they were
opened with. `autoResolve` is omitted or null when the source type has
no auto-resolve rule. Requires an `Idempotency-Key`. Publishes
`ExceptionPolicyDeclared`.





## PUT `(/exception-policies/{sourceType})`

### Parameters
- **sourceType** (path) (required): The full CloudEvents type of the governed source fact, URL-encoded
(its dots and colons are significant), e.g.
`com.warehouse.wes.fulfillment-execution.task.TaskCPTMissed`.

- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. Required on every POST and PUT; answered with
400 `idempotency-key-required` when absent. A replay with the same
key and the same body returns the stored response; the same key with
a different body is a 409 `idempotency-key-reused`.
