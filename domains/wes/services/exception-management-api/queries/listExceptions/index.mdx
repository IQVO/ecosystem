## Overview
Lists cases, newest first. An empty result is `200` with `[]`, never
a 404. `status`, `queue`, `site` and `sourceType` narrow the list;
`sourceType` is the full CloudEvents type of the source fact. Without
a `status` filter the list returns every open AND resolved case
matching the other filters (resolve activity is part of the record).





## GET `(/exceptions)`

### Parameters
- **status** (query): Only cases in this status.
- **queue** (query): Only cases in this problem-solve queue.
- **site** (query): Only cases of this site.
- **sourceType** (query): The full CloudEvents type of the source fact.
