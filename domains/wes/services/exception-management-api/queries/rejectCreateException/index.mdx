## Overview
There is deliberately **no `POST /exceptions`**: every case opens
from a consumed fact (ADR 0001), and a repeated fact touches the open
case (occurrence count, `lastSeenAt`) instead of opening another.
The router answers `405 method-not-allowed` naming `GET` as the
allowed method, and no `Idempotency-Key` is demanded first.
