## Overview
Sets or changes the severity and queue of a case that is not yet
resolved, and moves an `OPEN` case to `TRIAGED`. Requires an
`Idempotency-Key`; replaying the same key and body returns the stored
response. Publishes `ExceptionTriaged`.





## POST `(/exceptions/{caseId}/triage)`

### Parameters
- **caseId** (path) (required): The case id (`case-` followed by a unique suffix, at most 64 characters).
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. Required on every POST and PUT; answered with
400 `idempotency-key-required` when absent. A replay with the same
key and the same body returns the stored response; the same key with
a different body is a 409 `idempotency-key-reused`.
