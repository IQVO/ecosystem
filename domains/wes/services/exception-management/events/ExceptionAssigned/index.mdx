## Description
`type` = `com.warehouse.wes.exception-management.exceptioncase.ExceptionAssigned`;
subject and key = the case id. `assignee` is the operator id now
owning the case; `actor` is who performed the assignment.

> **No consumer by design:** case lifecycle fact; console and ops-agent read cases via REST; no event consumer in v1
