## Description
`type` = `com.warehouse.wes.exception-management.exceptioncase.ExceptionAutoResolved`;
subject and key = the case id. `rule_id` names the policy's
auto-resolve rule that fired; `correlated_type` and
`correlated_event_id` are the full CloudEvents type and id of the
correlated fact that satisfied the rule (for example an
`OrderRepromised` for the same work unit within the window).

> **No consumer by design:** case lifecycle fact; console and ops-agent read cases via REST; no event consumer in v1
