## Description
`type` = `com.warehouse.wes.exception-management.exceptioncase.ExceptionEscalated`;
subject and key = the case id. Raised once by the bounded SLA sweeper
when `now` passes `sla_due_at` while the case is not resolved. The
flag never blocks a transition and is not a state (ADR 0002).

> **No consumer by design:** case lifecycle fact; console and ops-agent read cases via REST; no event consumer in v1
