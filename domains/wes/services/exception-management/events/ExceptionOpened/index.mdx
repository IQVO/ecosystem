## Description
`type` = `com.warehouse.wes.exception-management.exceptioncase.ExceptionOpened`;
subject and key = the case id. `sla_due_at` is `opened_at` plus the
policy's `sla_minutes` for the source type. `source_payload` is the
frozen copy of the producer's `data` exactly as consumed: it never
changes after open and is never re-fetched. `site_id` is null when the
source event carries no site.

> **No consumer by design:** case lifecycle fact; console and ops-agent read cases via REST; no event consumer in v1
