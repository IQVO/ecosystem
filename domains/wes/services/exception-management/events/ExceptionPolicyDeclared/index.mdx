## Description
`type` = `com.warehouse.wes.exception-management.exceptionpolicy.ExceptionPolicyDeclared`;
subject and key = the source type (the full CloudEvents type string of
the consumed source event the policy governs). Policies are
append-only versions; the new version governs cases opened afterwards.
`auto_resolve` is null when the source type has no auto-resolve rule.

> **No consumer by design:** policy declaration fact (append-only versions); no event consumer in v1
