## Description
`type` = `com.warehouse.wes.exception-management.exceptioncase.ExceptionResolved`;
subject and key = the case id. `resolution_code` and `root_cause` are
mandatory; `note` is a free-form nullable remark. `actor` is the
operator id. After this the case accepts no command (409-class error).

> **No consumer by design:** case lifecycle fact; console and ops-agent read cases via REST; no event consumer in v1
