## Overview
Assigns an occupant to a station — the Station aggregate's `CheckIn` invariant enforced through the application layer: one occupant at a time. This is operational state, not a labor-performance domain event in its own right (see [ADR-0014](/docs/adr/0014-labor-performance-integration-hooks)): no domain event is published by this endpoint. The checked-in occupant is instead surfaced, best-effort, as `associateId` on the `TaskCompleted` Kafka event when a task claimed by this station is later completed.





## POST `(/stations/{stationId}/check-in)`

### Parameters
- **stationId** (path) (required): The station id, as returned by `POST /stations`.
