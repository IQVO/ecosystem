## Overview
Clears a station's occupant — the Station aggregate's `CheckOut` invariant enforced through the application layer. Takes no request body. Like check-in, this publishes no domain event (see [ADR-0014](/docs/adr/0014-labor-performance-integration-hooks)).





## POST `(/stations/{stationId}/check-out)`

### Parameters
- **stationId** (path) (required): The station id.
