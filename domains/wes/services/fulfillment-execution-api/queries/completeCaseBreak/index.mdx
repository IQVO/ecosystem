## Overview
A BREAK_CASE task (ADR 0054) is created when an each pick finds only a sealed case at its source. Completing it asks inventory-storage to break the container (`POST /containers/{lpn}:break`) into the loose bin, with an Idempotency-Key stable per task, and only then completes the task and publishes `TaskCompleted`. If inventory-storage cannot be reached the task stays claimed (503); a retry does not break twice.
