## Overview
Finishes the task's lifecycle (Claimed -> Completed) and publishes `TaskCompleted`. Only the owning station's claim may complete it, and a completed task can never be completed again — this endpoint enforces the no-double-complete invariant, returning `409` on a repeat call rather than silently succeeding twice. A `RELOCATE` task (a slot-plan move, ADR-0047) completes only with the operator's confirmation: `quantity` (counted, at least 1) and the bins the move left open — `fromBin` for an Assign, `toBin` for a Vacate (see the task's `relocation`). A scan of a side the plan fixed must equal the planned bin. The confirmed move is published on `TaskCompleted` (`sku`, `from_bin`, `to_bin`, `quantity`, `relocation_ref`). Any other task type takes none of these fields.
