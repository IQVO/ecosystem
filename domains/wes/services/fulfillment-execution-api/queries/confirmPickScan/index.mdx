## Overview
The station holding the claim on a PICK task scans a GTIN (ADR 0054). The GTIN is resolved against the local copy of product-master's pack levels (no synchronous call): it must identify the task's SKU and, for a task planned in eaches, an EACH level; for a task planned in cases, a CASE level. `count` packs are added (default 1) and the answer reports the eaches confirmed so far. Quantities are always in eaches; `POST /tasks/{id}/complete` and `TaskCompleted` are unchanged. A rejected scan changes nothing.
