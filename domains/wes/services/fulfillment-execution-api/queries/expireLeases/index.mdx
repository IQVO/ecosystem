## Overview
The Clock-driven side of the at-most-once lease design: scans every Claimed task and, for each whose lease expiry has passed without a renewal or completion, frees it back to Pending (publishing `LeaseExpired`) so the work is never silently lost. A collection- level action on the `tasks` resource — not scoped to a single task id — analogous to how `/tasks/{id}/complete` is a single-resource action; deliberately not placed under an unscoped `/admin` path. Idempotent: a second call simply frees nothing new if nothing else has expired since the last sweep. Takes no request body.
