## Overview
A projection over the Station registry, not a staffing count: returns how many currently-registered stations hold `capability`, regardless of occupancy. This is the raw installed ceiling a process path can ever be staffed up to — workforce-management's CommitShiftPlan calls this endpoint to enforce `plannedHeads` against reality, live, instead of trusting a caller-supplied installed-station count alone (see this repo's ADR-0018). Read-only — never mutates state. An unrecognized `capability` is not an error; it simply has an installed count of `0`, the same "count over existing rows, not a lookup against a fixed enum" contract `getQueueDepth` already uses.





## GET `(/capacity/{capability})`

### Parameters
- **capability** (path) (required): The capability to count registered stations for (e.g. pick, pack, slam, rebin).
