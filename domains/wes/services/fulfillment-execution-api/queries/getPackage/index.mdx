## Overview
Read-only view of a single Package, in exactly the shape `POST /tasks/{id}/seal-package` returns on 201. This is how the SLAM operator and the outbound dock loader learn the SLAM outcome: `POST /packages/{id}/slam` answers `204` both when a label was applied and when the package was diverted, so read `status` here — `LABELED` means the carton goes to the truck by its `sortLane`, `DIVERTED` means it goes to problem-solve. Side-effect-free (see [ADR-0033](/docs/adr/0033-package-read-model)).





## GET `(/packages/{id})`

### Parameters
- **id** (path) (required): The package id, as returned by `POST /tasks/{id}/seal-package`.
