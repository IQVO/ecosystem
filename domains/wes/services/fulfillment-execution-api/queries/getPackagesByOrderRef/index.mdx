## Overview
Read-only query returning every Package sealed for `orderRef` — the Package-side twin of `GET /tasks?orderRef=` (same query-parameter contract, same 400 on a missing or empty `orderRef`, same empty array for an unrecognized one). An order normally yields one carton, but a multi-carton order or a re-pack after a SLAM diversion yields several, so treat the response as a set. Ordered by package id. Side-effect-free (see [ADR-0033](/docs/adr/0033-package-read-model)).





## GET `(/packages)`

### Parameters
- **orderRef** (query) (required): The order reference to look up (Package.orderRef, copied from the owning Pack task at seal time). Must be non-empty — an empty value is treated as a missing parameter and rejected with 400.
