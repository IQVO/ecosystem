## Overview
A projection, not a live domain query: returns how many tasks of `taskType` currently sit Pending (not yet claimed) in the pool. Read-only — this endpoint never mutates state. An unrecognized `taskType` is not an error; it simply has a depth of `0`, since this is a count over existing tasks rather than a lookup against a fixed enum the server enforces.





## GET `(/queues/{taskType}/depth)`

### Parameters
- **taskType** (path) (required): The process path to count (conventionally PICK, PACK, SLAM or RELOCATE).
