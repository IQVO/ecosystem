## Overview
Read-only query tracing an order-management order back to the Pick/Pack/SLAM tasks this service created for it — the endpoint that backs a cross-service console screen answering "what tasks has fulfillment-execution created/completed for order X". Returns every task whose `orderRef` matches, normally one PICK/PACK/SLAM leg each; a leg may appear more than once if it was retried (e.g. a new task created after a prior one's lease expired without completion), so treat the response as the full set of tasks for the order, not a single result per process path. An unrecognized `orderRef` is not an error — it returns an empty array, the same convention `GET /queues/{taskType}/depth` uses for an unknown `taskType`.





## GET `(/tasks)`

### Parameters
- **orderRef** (query) (required): The order reference to look up (Task.orderRef, set at creation). Must be non-empty — an empty value is treated as a missing parameter and rejected with 400.
