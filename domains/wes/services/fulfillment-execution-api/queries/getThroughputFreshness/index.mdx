## Overview
Returns now minus the newest `occurred_at` in `analytics_processed_events`: the data product's freshness signal (target p95 under 30 s). A growing lag means the projector is falling behind or has stopped. An empty read model reports 0, which looks the same as a perfectly fresh one, so read it alongside the report's own counts.
