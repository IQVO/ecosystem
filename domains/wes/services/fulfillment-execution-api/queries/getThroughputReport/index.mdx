## Overview
Returns the rows whose hour bucket falls in the half-open window [from, to). The on-time-to-CPT counts (ADR-0026) are populated on SLAM rows only; they are raw counts, so the rate is packagesOnTimeToCPT / packagesManifested, computed by the caller.





## GET `(/reports/throughput)`

### Parameters
- **from** (query) (required): Inclusive start of the window, RFC 3339. Compared against each row's hour bucket.
- **to** (query) (required): Exclusive end of the window, RFC 3339.
- **taskType** (query): Optional exact-match filter on the task type (for example PICK, PACK, SLAM). Omit it, or send it empty, for every task type. The value is not validated: an unknown type matches no rows.

- **stationId** (query): Optional exact-match filter on the station id. Omit it, or send it empty, for every station.
- **granularity** (query): Bucket resolution. Only hourly buckets are modelled; any other value is a 400.
