## Overview
Creates a station with the given capability set, or — if `stationId` already exists — replaces its capability set (e.g. recertifying a station for a new capability). This is deliberately idempotent by client-supplied id: re-registering the same `stationId` upserts rather than erroring or duplicating, which is what closes the pull-dispatch gap for HTTP-only smoke testing (without this endpoint there is no way to create a station over HTTP, so `claim-next` against a freshly started server always 404s).
