## Overview
Pushes out a task's lease expiry so a station still actively working it doesn't lose the claim to the automatic expiry sweep (`POST /tasks/expire-leases`). Only the station that currently owns the claim may renew it. Idempotent in effect: repeated calls simply keep extending the same lease.





## POST `(/tasks/{id}/renew-lease)`

### Parameters
- **id** (path) (required): The task id, as returned by `POST /tasks` or a claim-next response.
