## Overview
SLAM = Scan, Label, Apply, Manifest. Weighs a sealed package: if `|actualWeight - expectedWeight|` is within tolerance (0.05, same unit as the two weights — e.g. kilograms), a shipping label is applied (`LabelApplied`); otherwise the package is diverted (`WeightDiscrepancyDetected` + `PackageDiverted`) rather than shipped with a wrong manifest. Idempotent in effect once processed: a repeat call on an already-labeled-or-diverted package returns `409` rather than re-processing it.
