## Description
Raised when the last still-open member detaches — its lease expired and the task returned to the pool through the existing sweep — in the same transaction that flips the batch to ABANDONED. The tasks themselves are NOT lost — each detaches through the ordinary lease-expiry path and stays claimable. Published on `warehouse.fulfillment.events`, keyed (and `subject`-ed) by batch id. Published only with PICK_BATCH_MODE on.
> **No consumer by design:** pending: published only with PICK_BATCH_MODE on (ADR 0063); the contract names labor-performance (batch_size reporting) as the intended consumer, but labor-performance has no handler for it on develop.
