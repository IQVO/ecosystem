## Description
Raised when the last still-open member completes, in the same transaction that flips the batch to COMPLETED. Published on `warehouse.fulfillment.events`, keyed (and `subject`-ed) by batch id. walk_seconds is completion minus formation — the whole walk, not per-stop labor (per-stop durations stay on each member's own TaskCompleted, ADR 0064). Published only with PICK_BATCH_MODE on.
> **No consumer by design:** pending: published only with PICK_BATCH_MODE on (ADR 0063); the contract names labor-performance (batch_size reporting) as the intended consumer, but labor-performance has no handler for it on develop.
