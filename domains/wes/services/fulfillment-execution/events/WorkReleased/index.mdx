## Description
Published by wes-work-planning on `warehouse.work-planning.events`; consumed here to create a Task via CreateTask. Dispatch is on the full `type`; dedupe is on the CloudEvents `id`. A message that is not a valid CloudEvents 1.0 event is dead-lettered to `warehouse.work-planning.events.dlq`.
