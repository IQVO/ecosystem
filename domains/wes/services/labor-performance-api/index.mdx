Engineered labor standards (expected time per TaskType) and actual-vs-standard performance scoring for completed fulfillment-execution tasks. This service defines standards and reads performance/scorecards; it NEVER accepts a TaskPerformance write over REST — that is exclusively driven by the inbound Kafka consumer of fulfillment-execution's TaskCompleted event (see apis/asyncapi.yaml).
