## Overview
Measured task time vs. measured idle time for one associate, plus the still-running open-gap contribution when that associate is idle right now. Always returns 200, including a zero-count result for an associate this service has never observed.





## GET `(/associates/{associateId}/utilization)`

### Parameters
- **associateId** (path) (required)
- **window** (query): A Go duration string (e.g. "1h", "30m") for the trailing window to measure over. Defaults to 1 hour when omitted or malformed.





### Responses

#### <span className="text-green-500">200 OK</span>
Idle-gap / utilization read model for either one TaskType (fleet-wide) or one associate, over a trailing window. taskType and associateId are mutually exclusive -- whichever endpoint served the request populates its own identifying field and omits the other.
