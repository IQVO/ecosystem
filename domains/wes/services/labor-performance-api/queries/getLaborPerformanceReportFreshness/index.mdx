## Overview
Returns the age of the most recently projected event: the data product's published freshness signal. A growing lag means the projector is falling behind or has stopped; a lag of 0 on a never-populated read model is indistinguishable from a perfectly fresh one, so read it alongside the report's own task counts. Target: p95 under 30 seconds.
