## Description
The SAME domain event as the analytics stream's LaborStandardRevised message, with the SAME `data`, on the integration topic and with the `:events:` dataschema. `standard_id` is the NEW record; the closed one is never overwritten (append-only history, ADR 0004). Subject is the new standard id; the partition key is the TaskType.
