## Overview
Between legs, with the container at a confirmed handoff that is not an AS/RS output port (including
waiting for a station slot): `200`, status `FAILED` reason `CANCELLED`, `TransportFailed` at once. A leg in
flight not yet picked up: `202`, status `CANCEL_REQUESTED` (the subsystem's answer decides; a refused
cancellation lets the transport run to its outcome). The container on a robot, or waiting on an AS/RS
output port: `409 transport-not-cancellable`. An ended or rejected request: `409 transport-ended`. No body.





## POST `(/transport-requests/{transportRequestId}/cancellation)`

### Parameters
- **transportRequestId** (path) (required): The caller's transport request id.
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 printable ASCII characters (fleet guideline R3-R5); a missing one is `400 idempotency-key-required`, any other outside the rule `400 idempotency-key-invalid`.
