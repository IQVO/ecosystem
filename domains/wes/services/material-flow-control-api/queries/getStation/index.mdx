## Overview
The station's buffer limit, its occupants in arrival order and the transports waiting upstream in admission order (URGENT before NORMAL, then earlier `due_by`).




## GET `(/stations/{stationId})`

### Parameters
- **stationId** (path) (required): A goods-to-person station id of the layout.
