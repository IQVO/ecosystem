## Overview
The request's outcome view (status `REJECTED` with `reason` for a rejected id), for operators and agents —
not for polling: progress is reported only through events (seam decision 3).





## GET `(/transport-requests/{transportRequestId})`

### Parameters
- **transportRequestId** (path) (required): The caller's transport request id.
