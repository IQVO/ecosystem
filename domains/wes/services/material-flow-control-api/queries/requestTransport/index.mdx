## Overview
Accepted or rejected at once, from local state only (no subsystem is called before the answer). `202`
answers the order view with `Location`; the first leg is requested after commit and progress follows as
events. `422` carries one of the four rejection reasons and the `transport_request_id`, and publishes
`TransportRejected`. A retry of the same `transport_request_id` and request answers the original outcome
(`202` with the current view, or the same `422`).





## POST `(/transport-requests)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 printable ASCII characters (fleet guideline R3-R5); a missing one is `400 idempotency-key-required`, any other outside the rule `400 idempotency-key-invalid`.
