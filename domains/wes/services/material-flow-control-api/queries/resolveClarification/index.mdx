## Overview
An operator (later exception-management) releases the clarification hold; the optional `location` names
where the container now is (a place reference; default: where the track is). The container can then be
requested again.





## POST `(/container-tracks/{containerId}/clarification-resolution)`

### Parameters
- **containerId** (path) (required): The container id (LPN).
- **Idempotency-Key** (header) (required): Caller-minted key, 1 to 128 printable ASCII characters (fleet guideline R3-R5); a missing one is `400 idempotency-key-required`, any other outside the rule `400 idempotency-key-invalid`.
