## Description
`type` = `com.warehouse.wes.material-flow-control.containertrack.ContainerSentToClarification`; subject and key = the container id. `detected_at_location` is the location code or station id where the problem was detected; for a container on a failed robot, the place the failed leg started from. `transport_order_id` may name an internal clarification move, and then `transport_request_id` is absent. `clarification_point` is set when the container is moved there.
> **No consumer by design:** pending: exception-management WCS anomalies (plan 05b)
