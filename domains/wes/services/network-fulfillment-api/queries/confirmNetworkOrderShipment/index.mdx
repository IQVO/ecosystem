## Overview
The one write endpoint of this context (ADR 0014). Tells the network that the order has shipped (`submitShipmentConfirmations`), moves the order to `CONFIRMED` and publishes `NetworkOrderShipmentConfirmed`. Takes no request body.

The trigger is an explicit call naming the `networkRef` rather than a `PackageManifested` correlation, because no persisted mapping from a work unit back to a `networkRef` exists (ADR 0014).

Idempotent: an order already `CONFIRMED` is returned unchanged with 204, without re-submitting to the network or re-publishing the event. The route is registered only when the shipment-confirmation use case is wired.





## POST `(/network-orders/{networkRef}/shipment-confirmation)`

### Parameters
- **networkRef** (path) (required): The network's own reference for the demand.
