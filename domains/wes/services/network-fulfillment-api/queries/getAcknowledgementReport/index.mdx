## Overview
Bucketed by day: how much demand arrived, how it was answered, and how fast. `ordersRejected` is split by cause — `ordersRejectedUntranslatableSku` (a catalogue gap: the Anti- Corruption Layer had no SKU mapping) is a different operational signal from `ordersRejectedDomain` (order-management's promise policy could not meet the deadline) or `acknowledgementDeadlinesMissed` (the 24-hour window closed with no answer ever sent — an operational failure, not a business decision).

Served by the `netfulfil-reports` deployable, reading a Postgres read model that `netfulfil-projector` maintains from this context's own domain events. Never the OLTP database.





## GET `(/reports/acknowledgement)`

### Parameters
- **from** (query) (required): Inclusive start of the window (RFC3339).
- **to** (query) (required): Exclusive end of the window (RFC3339).
- **granularity** (query): Bucket size. Only `day` exists today; omit for the default.
