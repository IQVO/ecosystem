## Overview
Counters for the poller plus the size of the unanswered working set. This exists because a stalled poller is SILENT: no orders, no errors, a healthy liveness probe, and an acknowledgement window closing regardless.

`polls` climbing with `since` advancing means the leg is working and the network simply has nothing for us. `polls` climbing while `since` stays put means every pass is failing. `since` absent after real uptime means no pass has ever succeeded.

`overdue` above zero is the fact worth alerting on: demand whose 24-hour window has already closed unanswered.
