## Overview
What we recorded for one unit of network demand, and what we told the network about it.

Lines carry BOTH vocabularies: the network's product identifier and the SKU this platform acted on. Publishing only one would make the Anti-Corruption Layer's translation decision invisible to whoever has to reconcile a disputed order.





## GET `(/network-orders/{networkRef})`

### Parameters
- **networkRef** (path) (required): The network's own reference for the demand (for Vendor Direct Fulfillment, its purchase-order number). Treated as an opaque string: this context is Conformist upstream, so the network owns the format and we never parse it.
