## Overview
The figure this context would tell the network it can ship for each (SKU, site) it knows about: `min(physicalAvailable, throughputFeasibleBefore(nextCutoff))` (ADR 0001 §8). Offers are persisted by the recompute loop; they are not yet submitted to the network.

Registered only when `CAPABILITY_OFFER_ENABLED` is set; otherwise the route does not exist and the API answers 404.
