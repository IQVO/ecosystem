## Overview
The unanswered working set — orders in `NEW`, the ones the acknowledgement sweep acts on.

Only this list is exposed, deliberately. It is the only listing whose size is an operational signal; a general "all orders" endpoint would need paging and would answer no question anybody has while something is wrong.
