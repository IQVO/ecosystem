## Description
Raised by `SweepAcknowledgementDeadlines` for every order found still `NEW` past its `acknowledgeBy` instant (ADR 0001 §6), and published on the analytics topic like every other event (the composition root's fan-out publishes each event to both topics). Re-fires on every sweep pass while the condition holds — not edge-triggered. Not used by the analytics projector today (ignored as an unknown type).

`type`: `com.warehouse.wes.network-fulfillment.networkorder.AcknowledgementDeadlineAtRisk` — `dataschema`: `urn:warehouse:network-fulfillment:analytics:AcknowledgementDeadlineAtRisk:v1`.
