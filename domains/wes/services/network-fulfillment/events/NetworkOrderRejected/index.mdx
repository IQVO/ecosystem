## Description
Raised by the `NetworkOrder` aggregate whenever the order is refused. `reason` distinguishes a catalogue gap, a capacity signal and an operational failure.

`type`: `com.warehouse.wes.network-fulfillment.networkorder.NetworkOrderRejected` — `dataschema`: `urn:warehouse:network-fulfillment:events:NetworkOrderRejected:v1`.
