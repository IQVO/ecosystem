## Description
Raised when the order moves to `SUBMITTED`; what `NetworkOrderAcknowledged` v1 used to announce (ADR 0016). Recognised and claimed by the analytics projector, with no effect on the acknowledgement report.

`type`: `com.warehouse.wes.network-fulfillment.networkorder.NetworkOrderSubmitted` — `dataschema`: `urn:warehouse:network-fulfillment:analytics:NetworkOrderSubmitted:v1`.
