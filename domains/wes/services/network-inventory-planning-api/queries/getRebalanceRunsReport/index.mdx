## Overview
For the RebalanceRunCompleted occurrences in [from, to), per UTC day: the runs, the proposals the
planner produced in total, how many of them the runs' own safety checks rejected (never an
operator rejection: the run approves nothing), `rejection_rate` (rejected / proposals, 0 when
there were no proposals) and the stale facts seen. Ordered by day. `from` / `to` as in
/reports/transfer-funnel. 200 with `days: []` when nothing matches.





## GET `(/reports/rebalance-runs)`

### Parameters
- **from** (query): RFC 3339; inclusive. Defaults to `to` minus 30 days.
- **to** (query): RFC 3339; exclusive. Defaults to now.
