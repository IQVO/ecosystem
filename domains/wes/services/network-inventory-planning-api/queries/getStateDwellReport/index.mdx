## Overview
For the TransferStateAdvanced occurrences in [from, to), per UTC day and state `from` (the state
the transition LEFT), the number of transitions and the continuous p50/p95 (linear
interpolation) of `age_seconds`. `age_seconds` is the saga's age since creation at the moment of
the transition, so it is how far along the saga was when it left the state, not a per-state
duration; the difference between consecutive states approximates the time spent. Creation
entries (empty `from`) leave no state and are not counted. Ordered by day, then state. `from` /
`to` as in /reports/transfer-funnel. 200 with `days: []` when nothing matches.





## GET `(/reports/state-dwell)`

### Parameters
- **from** (query): RFC 3339; inclusive. Defaults to `to` minus 30 days.
- **to** (query): RFC 3339; exclusive. Defaults to now.
