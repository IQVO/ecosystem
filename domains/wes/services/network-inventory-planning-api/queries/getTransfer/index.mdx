## Overview
Read-only view of one transfer: its current state and facts plus the
immutable audit trail of state transitions (timestamp and cause of
each). 404 problem+json for an unknown id; 503 problem+json when the
instance runs without a database.





## GET `(/v1/transfers/{id})`

### Parameters
- **id** (path) (required): The transfer id (the transferId returned by approval).
