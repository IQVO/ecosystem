## Overview
For the TransferStateAdvanced analytics occurrences in the half-open range [from, to) (by the
CloudEvents time: from inclusive, to exclusive), counts per UTC day and state `to` the DISTINCT
transfers that reached it. Ordered by day, then state. Built from the analytics stream only
(ADR 0009). `from` / `to` are optional RFC 3339 timestamps: both omitted means the 30 days
ending now; only `to` means the 30 days before it; only `from` means from..now; the range must
be non-empty and at most 366 days. 200 with `days: []` when nothing matches.





## GET `(/reports/transfer-funnel)`

### Parameters
- **from** (query): RFC 3339; inclusive. Defaults to `to` minus 30 days.
- **to** (query): RFC 3339; exclusive. Defaults to now.
