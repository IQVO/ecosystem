## Overview
The operator-managed Rebalance Policy catalogue (ADR 0015), one entry
per site + SKU, ordered by site then SKU. Each entry embeds the SAME
Policy shape POST /v1/transfer-proposals:generate accepts, plus its
revision (the optimistic-concurrency token). The scheduled rebalance
pass plans from this catalogue.
