## Overview
The observe-only scheduled-rebalance run history (ADR 0007): one
row per NIP_REBALANCE_SCHEDULE tick, recording the snapshot
watermark the pass planned from, the proposal/rejected counts,
and the outcome — a fail-closed snapshot refusal is a FAILED run
carrying its reason, never a hidden error. Runs never approve
anything and never emit an allocation command.





## GET `(/v1/rebalance-runs)`

### Parameters
- **limit** (query): Page size, clamped to [1, 200]; default 50.
