## Overview
The operator-managed Transfer Lane catalogue (ADR 0015), one entry
per directed origin → destination, ordered by origin then
destination. Each entry embeds the SAME Lane shape the generate
endpoint accepts, plus its revision. The scheduled pass uses a lane
only when it is Enabled AND site_capability lets its origin send and
its destination receive.
