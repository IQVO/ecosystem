## Overview
Read-only page of inter-warehouse transfers from the saga store,
newest created first, optionally filtered by lifecycle state and by
origin and/or destination site. Never mutates anything. 400 for an
unknown state or out-of-range paging; 503 problem+json when the
instance runs without a database.





## GET `(/v1/transfers)`

### Parameters
- **state** (query): Only transfers currently in this lifecycle state (case-insensitive).
- **originSiteId** (query): Only transfers leaving this origin site.
- **destinationSiteId** (query): Only transfers going to this destination site.
- **limit** (query): Page size, 1 to 200 (default 50).
- **offset** (query): Number of matching transfers to skip (default 0).
