## Overview
Upserts the Lane in the body, keyed by its Origin → Destination
(directed: WH1→WH2 and WH2→WH1 are two lanes). Same idempotency,
If-Match, 409 and 422 rules as PUT /v1/rebalance-policies; a lane
whose Origin equals its Destination, or with a negative LeadTime or
UnitHandlingCost, is a 422. Disable a lane with Enabled: false
(there is no DELETE).





## PUT `(/v1/transfer-lanes)`

### Parameters
- **If-Match** (header): Optimistic concurrency for a catalogue PUT (ADR 0015): the entry's
current revision, as its ETag ("3") or bare (3). The PUT applies only
while the stored revision still equals it (412 version-mismatch
otherwise, including when the entry does not exist). Omit it to
apply the PUT to whatever revision is current.
