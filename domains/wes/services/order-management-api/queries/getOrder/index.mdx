## Overview
The GetOrder use case. Returns the order with every line's current status, its reservation reference where allocated, and the promise date once allocation has computed one. The order-level `status` in this response is derived from the line statuses at read time — it is not a stored field.





## GET `(/orders/{id})`

### Parameters
- **id** (path) (required): The order's identifier, as returned by receiveOrder.
