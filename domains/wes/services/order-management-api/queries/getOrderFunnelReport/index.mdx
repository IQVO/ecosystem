## Overview
Returns one row per (pathId, hour bucket) in the half-open window [from, to), ordered by hour bucket then path. An empty window is a 200 with an empty `rows` array, not a 404.

Order-level counters are attributed to the order's first line's path (an approximation since multi-path routing, ADR 0021). `ordersRepromised` is not path-dimensioned and is only ever non-zero on the row whose `pathId` is the empty string.





## GET `(/reports/funnel)`

### Parameters
- **from** (query) (required): Inclusive window start, RFC 3339.
- **to** (query) (required): Exclusive window end, RFC 3339.
- **pathId** (query): Optional exact-match process-path filter. Omit for every path.
- **granularity** (query): Bucket resolution. Only hourly buckets exist.
