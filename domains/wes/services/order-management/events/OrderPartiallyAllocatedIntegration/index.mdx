## Description
An order with AllowPartialShipment=true concluded its pass with some lines allocated (and released in this same pass — `data.lines[]` carries exactly those) and some lines Backordered. A ship-complete order NEVER emits this event: under BR3 its whole status stays Backordered until RetryAllocation succeeds.
