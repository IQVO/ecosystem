## Description
Consumed from warehouse.outbound-shipping.events (ADR 0051). source_order_id is a BARE OrderId (not the WorkUnitId shape fulfillment-execution's events carry), so this event drives the ORDER-WIDE re-promise (RepromiseOrder.ExecuteForMissedLoad), not the per-line one. cutoff is decoded for logging only; the fresh promise comes from current inputs. A payload without source_order_id is skipped-and-logged (nothing to join on).
