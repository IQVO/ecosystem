## Description
Consumed from warehouse.product-master.events (ADR 0036). Subject and Kafka key = the SKU. Full-state replacement of the classification; `temperature_class` and `dot_hazard_class` are omitted when unset. Tags come in product-master's stable order (Hazmat, Fragile, TemperatureSensitive, Oversized, HighValue). There is no "unclassify" event in v1.
