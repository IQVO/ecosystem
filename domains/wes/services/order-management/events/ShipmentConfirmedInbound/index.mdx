## Description
Consumed from warehouse.outbound-shipping.events (ADR 0051). The orders[] entries carry the DISTINCT source_order_id of the shipped packages (a bare OrderId — the producer strips any -line-N suffix); a package manifested without one is excluded by the producer. Only load_id and orders[].order_id are read; every other member (site_id, cpt_id, carrier, trailer_id, seal_number, departed_at, version) is ignored by the fixed decode struct. One event ships every named order's Released lines atomically.
