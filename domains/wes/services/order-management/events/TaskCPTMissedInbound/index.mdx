## Description
Consumed from warehouse.fulfillment.events (ADR 0018). Re-fires on every sweep pass fulfillment-execution runs, for as long as the task stays overdue (that service's own ADR 0025 §4) — this context's own CloudEvents-id-keyed idempotency gate is what makes that safe to consume. order_ref is a WorkUnitId-shaped reference (`{orderId}-line-{lineNo}`), not a bare OrderId.
