## Description
The enqueue confirmation. Since wes-work-planning's ADR 0041 its integration-stream `data` carries two OPTIONAL fields beside the existing `path_id` and `work_unit_id`: `reference` (the work unit's originating reference; for order work, the order id) and `line_no` (integer > 0; omitted when unknown). The CloudEvents `type`, `subject` (the work unit id) and `dataschema` v1 are unchanged. Only `reference` and `line_no` are read.
