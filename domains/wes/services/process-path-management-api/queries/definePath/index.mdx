## Overview
Rejects with 409 if the given pathId is already defined — active or deactivated. A path's identity is permanent once created; a caller wanting to re-use an id after deactivation must be told explicitly, never silently overwritten. Publishes ProcessPathCreated on success.





## POST `(/process-paths)`

### Parameters
- **Idempotency-Key** (header): Caller-supplied idempotency key for this resource-creating request (ADR 0011). Clients MUST always send a non-empty, unique-per-logical- request key (e.g. a UUID minted per submit): a retried request with the same key AND the same body replays the original response instead of creating a second path, while the same key with a different body is rejected 422 idempotency-key-reused. Declared required: false with no minLength only because the Schemathesis contract job boots the API in in-memory mode, which does not enforce the header — against a Postgres-backed deployment an absent/empty key is a 400 idempotency-key-required.
