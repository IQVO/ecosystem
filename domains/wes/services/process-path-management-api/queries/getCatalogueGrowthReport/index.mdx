## Overview
Returns one row per UTC day bucket whose start lies in the half-open window [from, to), ordered by day. Days with no catalogue change have no row. An empty window is a 200 with an empty `rows` array, never `null` and never a 404.





## GET `(/reports/catalogue-growth)`

### Parameters
- **from** (query) (required): Inclusive window start, RFC 3339, compared with the day bucket.
- **to** (query) (required): Exclusive window end, RFC 3339, compared with the day bucket.
- **granularity** (query): Bucket resolution. Only daily buckets exist; omit it or send `day`.
