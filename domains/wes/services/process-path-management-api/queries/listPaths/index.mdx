## Overview
Returns only Active paths by default — matching the retired YAML catalogue's own posture that every consumer's normal read is "the currently valid set," not everything that ever existed. Pass ?all=true for the audit view (Active and Deactivated paths).





## GET `(/process-paths)`

### Parameters
- **all** (query): When true, includes Deactivated paths too.
