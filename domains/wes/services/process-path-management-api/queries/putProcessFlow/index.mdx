## Overview
The ordered stages a workload passes through (ADR 0042). The body is the flow's FULL definition: every PUT replaces the name and the stages. Idempotent by nature (full state), so it takes no Idempotency-Key. 201 when the flowId is new, 200 for every later PUT — including one that changes nothing, which raises no event and keeps the version. Each accepted change raises ProcessFlowDefined (first) or ProcessFlowRevised, carrying the full state and a `version` that starts at 1 and grows by one per accepted change. Invariants: at least one stage; a pathId appears at most once; each processType is one of the closed set; each stage's pathId names an ACTIVE process path of this service's own catalogue (checked at write time, under the path's row lock). A RETIRED flow cannot be revised (422 `flow-retired`).
