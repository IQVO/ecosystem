## Overview
pathId and direct are not revisable (direct describes a structural routing fact, not an operator-tunable parameter). Returns 422 if the path is Deactivated — a deactivated path is a closed historical record. A no-op revision (identical matchPrefix, requiredCapabilities, cycleTimeP95, eligibility, and intake) is a successful 200 that does NOT republish ProcessPathUpdated. intake (ADR 0034) is optional here: omitting it keeps the current intake.
