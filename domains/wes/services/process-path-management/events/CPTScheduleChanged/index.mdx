## Description
Raised by DefineCPTSchedule whenever a schedule is first defined or a subsequent revision actually changes something (ADR 0010). Carries the FULL schedule — a snapshot, not a diff — so a fresh consumer replaying from FirstOffset needs no prior state to build its read model, the same self-sufficient-event convention ProcessPathCreated/Updated already use. Keyed by `site_id`, not `path_id` — a different aggregate sharing this topic.
