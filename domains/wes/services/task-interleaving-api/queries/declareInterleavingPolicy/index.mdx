## Overview
Declares the interleaving policy of a site, or replaces it with a new
version. Until a site has a policy no hint is issued for it. Validation:
`maxDetourM` greater than 0, `maxCandidates` 1 to 5, `hintTtlSeconds`
greater than 0, `eligibleTaskTypes` non-empty and a subset of `PICK`,
`PACK`, `REBIN`, `SLAM`, `RELOCATE`, `REPLENISH`, `verticalWeight` at
least 0 (default 1). The first declaration sends no `If-Match`; once a
policy exists, `If-Match` must carry its current version. A stale or
missing `If-Match` on an existing policy is a 412 `version-mismatch`.
Declaring the same values again still advances the version.





## PUT `(/sites/{siteId}/policy)`

### Parameters
- **siteId** (path) (required): The site (the fleet's site code), 1 to 64 characters without whitespace or `/`.
- **If-Match** (header): The `ETag` the caller last saw. Omitted only for the first declaration;
for an existing policy a missing or stale value is refused with 412
`version-mismatch`.
