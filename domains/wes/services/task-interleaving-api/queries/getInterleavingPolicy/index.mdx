## Overview
Returns the current policy of the site with its `version` (also as the
`ETag`). A site that never declared one is a 404 `policy-not-found`: it is
inert and issues no hints.





## GET `(/sites/{siteId}/policy)`

### Parameters
- **siteId** (path) (required): The site (the fleet's site code), 1 to 64 characters without whitespace or `/`.
