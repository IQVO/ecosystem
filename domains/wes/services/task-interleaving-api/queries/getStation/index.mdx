## Overview
Returns what the context knows about the station: its position (the end
location of the last task it completed), the last completed task and the
Active hint, if any. A station that has completed no task since this
context started listening is a 404 `station-not-found`.





## GET `(/stations/{stationId})`

### Parameters
- **stationId** (path) (required): The station id, 1 to 64 characters without whitespace or `/`.
