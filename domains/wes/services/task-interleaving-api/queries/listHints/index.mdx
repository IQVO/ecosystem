## Overview
Lists hints newest first, a page at a time. `cursor` is the opaque
`nextCursor` of the previous page; a response without `nextCursor` is the
last page. Optional filters narrow by station, site and state.





## GET `(/hints)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100).
- **cursor** (query): The `nextCursor` value from the previous page.
- **stationId** (query): Only hints issued to this station.
- **siteId** (query): Only hints of this site.
- **state** (query): Only hints in this state.
