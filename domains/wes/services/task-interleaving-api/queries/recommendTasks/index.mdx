## Overview
A read-only simulation: runs the same pure recommender that issues hints
against the current open-task pool and the site's policy, and returns the
ranked candidates. It issues no hint, publishes no event and changes no
state. The origin is the station's recorded position, or `fromLocation`
when given (a what-if). The site is the station's site, or the site of
`fromLocation`. An empty `candidates` list means no hint would be issued.
The site must have a declared policy (422 `policy-not-declared`
otherwise) and the origin must have known geometry (422
`origin-unknown`). Accepts an `Idempotency-Key` like every POST.





## POST `(/recommendations)`

### Parameters
- **Idempotency-Key** (header): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. Required whenever the service runs with Postgres,
that is in every deployment, and answered with 400
`idempotency-key-required` when absent; a replay with the same key and
the same body returns the original response, while the same key with a
different body is 422 `idempotency-key-reused`. The in-memory development
mode (no `DATABASE_URL`) does not enforce it, which is why the header is
not marked `required` here.
