## Description
`type` = `com.warehouse.wes.task-interleaving.stationtrip.InterleavingHintIssued`,
`dataschema` = `urn:warehouse:task-interleaving:events:InterleavingHintIssued:v1`;
subject and Kafka key = the station id. The CloudEvents `time` is when the
hint was issued. `candidates` is non-empty (an empty candidate set issues
NO hint), ranked from 1 by `detour_m` ascending then `task_id`, at most
the policy's `max_candidates`. The hint is valid until `expires_at`.
