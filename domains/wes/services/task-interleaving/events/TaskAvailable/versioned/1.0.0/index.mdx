## Description
PENDING PRODUCER CHANGE P2: not yet published by fulfillment-execution, this
contract is pinned here so the consumer ships first and the producer
matches it. `type` = `com.warehouse.wes.fulfillment-execution.task.TaskAvailable`,
source `/warehouse/fulfillment-execution`, dataschema
`urn:warehouse:fulfillment-execution:events:TaskAvailable:v1`. Subject and
Kafka key = the task id. Raised whenever a task ENTERS or RE-ENTERS the pool
(release, lease expiry); upsert it into the pool copy. `from_location` is
where the operator must go first, `to_location` is where the operator ends
(PICK: both the pick bin; RELOCATE and REPLENISH: source and destination
bin; PACK, SLAM and REBIN: the station code). `priority_band` is an opaque
string equal across tasks that fulfillment-execution orders as peers; this
context stores it and never interprets it. A message with an unknown
`task_type` is stored but is never a candidate.
