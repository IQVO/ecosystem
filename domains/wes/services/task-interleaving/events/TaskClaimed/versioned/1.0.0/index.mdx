## Description
PENDING PRODUCER CHANGE P2: today a `TaskClaimed` occurrence exists only on
fulfillment-execution's analytics topic (`{task_id, task_type, station_id}`);
P2 adds it to the integration topic with `claimed_at`. `type` =
`com.warehouse.wes.fulfillment-execution.task.TaskClaimed`, dataschema
`urn:warehouse:fulfillment-execution:events:TaskClaimed:v1`. Subject and
Kafka key = the task id. Removes the task from the open pool (the row is
kept so a later `TaskCompleted` can read its end location) and, when the
claimed task is a candidate of the Active hint of `station_id`, marks that
hint Consumed; any other claim leaves the hint Active until it expires or is
superseded.
