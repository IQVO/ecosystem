## Overview
Upserts the inbound labour standard keyed by (location, path_id): fixed `minutes_per_appointment` plus an optional `minutes_per_asn` per ASN the appointment covers (the booked event carries no units, pallets or lines). The standard is a planning parameter owned by this service (docs/adr/0017): nobody upstream publishes it. Without one, dock appointments are recorded but contribute NO labour demand and the plan reports `inbound_standard_missing`; no default number is ever guessed. Nothing derived is stored, so a late declaration applies on the next read.
