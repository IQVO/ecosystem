## Overview
Upserts the StationStandard keyed by (location, process_type): the throughput of a single station in the process's natural unit, e.g. 180 PACKAGE per 3600 s for PACK at SIM1. The count of stations comes from facility-layout; count x standard is composed with the step's registered constraints when a path capacity or capacity plan is computed (nothing derived is stored, so a late declaration applies on the next read). `location` is the site (building) code, the first dash-separated segment of the facility zone ids.
