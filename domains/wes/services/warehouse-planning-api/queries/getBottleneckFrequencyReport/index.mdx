## Overview
For the plans PUBLISHED in the half-open range [from, to) (by the CloudEvents time of CapacityPlanPublished: from inclusive, to exclusive), counts, per site (warehouse_id + location), how many had each bottleneck_step bound by each binding_constraint (LABOR, STATION, ...; empty for a plan created before the constraint was recorded), and `share`: that count as a fraction of the site's published plans in the range. Rows are ordered by site, then count descending. Drafts never count. Built from the analytics stream only (ADR 0005). `from` / `to` are optional RFC 3339 timestamps: both omitted means the 30 days ending now; only `to` means the 30 days before it; only `from` means from..now; the range must be non-empty and at most 366 days. 200 with `rows: []` when nothing matches.





## GET `(/reports/bottleneck-frequency)`

### Parameters
- **from** (query): RFC 3339; inclusive. Defaults to `to` minus 30 days.
- **to** (query): RFC 3339; exclusive. Defaults to now.
