## Overview
Compares the stored plan with the TASKS fulfillment-execution reports completed (TaskCompleted, minute resolution) for the plan's bottleneck step at its location over its window, from the LOCAL observed_capacity read model (docs/adr/0017). ADVISORY: it never changes the planned capacity or the plan, and nothing is republished. Tasks are not orders, so the comparison needs `tasks_per_order`; without it `comparison.comparable` is false with the reason. `observed.has_data` false means nothing was observed, not zero throughput.





## GET `(/capacity-plans/{id}/variance)`

### Parameters
- **id** (path) (required)
- **tasks_per_order** (query): Conversion factor from completed tasks to orders; must be positive.
