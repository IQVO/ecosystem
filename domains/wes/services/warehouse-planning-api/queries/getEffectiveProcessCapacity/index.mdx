## Overview
Returns the effective rate (the minimum across every registered constraint), which constraint is binding, and the full list of registered constraints for the ProcessCapacity identified by (process_type, location, window_start, window_end). This lookup keeps EXACT-key semantics (it reads one registered aggregate; it does NOT match by coverage -- path capacity and capacity plans do, see docs/adr/0003). 404 if nothing has been registered for that identity yet.

- **location** (query) (required)
- **window_start** (query) (required)
- **window_end** (query) (required)
