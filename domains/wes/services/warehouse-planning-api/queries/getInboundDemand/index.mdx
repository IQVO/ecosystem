## Overview
The BOOKED dock appointments at a site whose door window STARTS in the half-open window [window_start, window_end), read from the LOCAL read model this service builds from inbound-receiving's DockAppointmentBooked / DockAppointmentCancelled CloudEvents (docs/adr/0017; never a live call). A cancelled appointment never counts, whatever the arrival order of the two events (the producer's event time is the ordering guard). `labour_minutes` is what the standard declared for `path_id` attributes to them; with no standard it is 0 and `standard_missing` is true when appointments exist. Appointments carry no site, so every one is attributed to the ONE site configured on this service; any other location reads 0. 200 with appointments 0 and as_of null when nothing is known.





## GET `(/inbound-demand)`

### Parameters
- **location** (query) (required)
- **path_id** (query) (required): The process path whose declared inbound standard prices the appointments.
- **window_start** (query) (required): RFC 3339; inclusive.
- **window_end** (query) (required): RFC 3339; exclusive, must be after window_start.
