## Overview
The ProcessPath an id resolves to: its ACTIVE process flow consumed from process-path-management (its steps are the stages' process types in order; docs/adr/0025). `source` is read-only and always `flow` (the local declaration retired with stage 3). A RETIRED flow, or an id no ACTIVE flow has, is a 404. Read-only.
