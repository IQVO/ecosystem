## Overview
The facility-layout tally of one site: storage positions per zone and locationType and work-center station counts per zone and activity, over the zones whose id starts with `<location>-`. It is a READ MODEL, not a throughput (storage positions are not process capacity), and it has no "consumed" figure: stock is never read from inventory-storage. 200 with empty lists when nothing is tallied for the site.
