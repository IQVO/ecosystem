## Overview
The most recently created plans, newest first (ties broken by id, descending), each in exactly the shape of GET /capacity-plans/\{id\}. `location` restricts the list to one location; omitted means every location (and the response then carries no `location`). `limit` defaults to 20 and is capped at 100: a larger value is served as 100, a value that is not a positive integer is rejected with 400 malformed-limit. 200 with an empty list when nothing matches. Read-only; there is no MCP tool for it.
