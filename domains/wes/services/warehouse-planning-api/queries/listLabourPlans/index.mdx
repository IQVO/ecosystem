## Overview
The plans of one (site_id, shift_id), ordered by path id, one keyset page at a time (limit + cursor; follow nextCursor until it is absent). Both filters are required and are repeated on every page request.





## GET `(/labour-plans)`

### Parameters
- **site_id** (query) (required)
- **shift_id** (query) (required)
- **limit** (query): Page size (1-500, default 100).
- **cursor** (query): Opaque keyset cursor from the previous page's nextCursor. Repeat the filters on every page request.
