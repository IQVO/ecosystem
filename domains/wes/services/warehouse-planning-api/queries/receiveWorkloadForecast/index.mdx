## Overview
Stores the volume a process path is expected to receive at a site, as CPT buckets (docs/adr/0023 decision 1; it was wes-work-planning's charge forecast). One forecast per (site_id, path_id); a receipt replaces the buckets as a whole. 201 with version 1 for a first receipt; 200 with version + 1 when the buckets changed; 200 with the stored forecast, its version and received_at unchanged, when the buckets equal the stored ones (same order): nothing is written and no event is raised. A receipt that changed something raises WorkloadForecastReceived (integration and analytics topics, asyncapi.yaml) in the same transaction. The PUT is naturally idempotent and takes no Idempotency-Key.





## PUT `(/workload-forecasts/{site_id}/{path_id})`

### Parameters
- **site_id** (path) (required): Canonical facility-layout site code (ADR 0012).
- **path_id** (path) (required): The process path code: case-insensitive; stored and published in upper case (trimmed), so "pick" and "PICK" name the same forecast and labour plan. Upper-cased, it also names the facility-tally activity whose stations the labour plan's warning compares with.
