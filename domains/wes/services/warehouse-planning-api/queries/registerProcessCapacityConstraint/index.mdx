## Overview
Upserts one named constraint (LABOR, LOCATION, EQUIPMENT, STATION, CONVEYOR, BUFFER or REPLENISHMENT) on the ProcessCapacity identified by (process_type, location, window_start, window_end), creating the aggregate on first registration. Returns the recomputed effective rate (the minimum across every registered constraint) and which constraint is binding. The window is the aggregate's identity: this endpoint (like GET /process-capacities) uses EXACT-key semantics. When path capacity or a capacity plan is computed, a registered window applies to the requested planning window if it COVERS it (docs/adr/0003).
