## Description
Raised by the `CapacityPlan` aggregate on `POST /capacity-plans` and queued
in the transactional outbox in the same transaction as the plan. `type` =
`com.warehouse.wes.warehouse-planning.capacityplan.CapacityPlanCreated`, `subject` and Kafka key = the plan id.
