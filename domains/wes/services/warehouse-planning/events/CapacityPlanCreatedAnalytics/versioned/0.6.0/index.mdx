## Description
Same `type`, same `id`, same payload as the integration CapacityPlanCreated;
only `dataschema` differs (`urn:warehouse:warehouse-planning:analytics:CapacityPlanCreated:v1`).
The projector uses the CloudEvents `time` as the plan's creation instant.
