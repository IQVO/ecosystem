## Description
Same `type` and `id` as the integration CapacityPlanPublished; the payload adds
`binding_constraint` (additive, analytics-only): the constraint type binding the
bottleneck step, which the bottleneck-frequency report groups by. The projector
uses the CloudEvents `time` as the plan's publication instant.
