## Description
CONSUMED from `warehouse.order-management.events` (producer: order-management,
its own `apis/asyncapi.yaml`). Upserts the order into the expected-demand read
model: promise cutoff = `data.promise_date`, released lines = `len(data.lines)`,
site = the configured `DEMAND_SITE_ID` (the event carries none). `subject` must
equal `data.order_id`. Deduped on the CloudEvents `id`; last writer wins per
order on `time`. `type` =
`com.warehouse.wes.order-management.order.OrderAllocated`.
