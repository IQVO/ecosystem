## Description
Same `type`, same `id`, same payload as the integration LabourPlanCommitted (with
`shift_start` omitted when the plan has none); only `dataschema` differs
(`urn:warehouse:warehouse-planning:analytics:LabourPlanCommitted:v1`). The projector
acknowledges it without projecting it.
