## Overview
Returns the `UsableInventoryObserved` read model — the latest usable-quantity projection for a SKU, built from Inventory's `StockReserved` (decrements) and `ReservationRevoked` (increments) integration events, projected via the Kafka consumer (Task 7). Keyed by SKU, not by process path — Inventory reservations are SKU-scoped, with no natural path mapping. `404` until at least one event has been observed for the SKU.





## GET `(/inventory-view/{sku})`

### Parameters
- **sku** (path) (required): The stock-keeping unit identifier this inventory view is projected for.
