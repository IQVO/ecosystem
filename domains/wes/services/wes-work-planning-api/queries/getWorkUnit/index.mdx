## Overview
Returns a single `WorkUnit` resolved by its own `workUnitId` — the GetWorkUnit use case. This is the identity lookup, distinct from `GET /work-units?reference=` (which looks units up by their UPSTREAM order-line reference and always returns an array). A client holding only a work unit id — e.g. an associate's RF gun that claimed a PICK task from fulfillment-execution, whose `orderRef` is this service's `workUnitId` — reads the unit's `sku`, upstream `reference`, `pathId`, `cpt` and `state` here instead of parsing the id string (ids are opaque to clients). Read-only and side-effect-free; the response shape is the same `WorkUnitResponse` the other work-unit endpoints return. An unknown id returns `404` (`not-found`).





## GET `(/work-units/{id})`

### Parameters
- **id** (path) (required): The work unit's client-supplied identifier.
