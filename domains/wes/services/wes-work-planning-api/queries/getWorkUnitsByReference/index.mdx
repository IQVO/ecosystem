## Overview
Returns every `WorkUnit` ever enqueued for the given `reference` — the GetWorkUnitsByReference use case. `reference` is the external reference threaded through `POST /paths/{pathId}/work-units` (typically an order line), NOT this service's internal client-supplied `workUnitId`. A reference can plausibly correspond to more than one `WorkUnit` across retries/history (e.g. re-enqueued after an abandoned attempt) — the response is always an array, even when a caller expects at most one live unit, and is empty (not `404`) when the reference has never been seen. This is the cross-service lookup a console screen uses to answer "what work did this service release for order X, line N".





## GET `(/work-units)`

### Parameters
- **reference** (query) (required): The external order-line reference to look up (as supplied on `EnqueueWorkUnitRequest.reference`). Missing or empty returns `400`.
