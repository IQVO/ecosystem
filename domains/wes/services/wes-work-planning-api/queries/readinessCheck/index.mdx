## Overview
Readiness probe for the service. Returns 200 `{"status":"ready"}` while the process accepts traffic, and 503 `{"status":"not_ready"}` once graceful shutdown has begun (readiness is flipped first so a Kubernetes readinessProbe stops routing new requests during the drain window). Separate from `/healthz`, which is liveness and is never flipped by shutdown. Does not check downstream dependencies.
