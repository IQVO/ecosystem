## Overview
Finishes a released work unit — the RecordCompletion use case. Transitions Released → Completed and publishes `WorkUnitCompleted`, which updates backlog telemetry projections. Enforces the `WorkUnit` aggregate's at-most-once-completion invariant: completing an already completed unit, or one that was never released, returns `409`. This endpoint is also the target of the additive `TaskCompleted` Kafka consumer (Task 8) — fulfillment-execution's task completion drives the exact same use case as this HTTP call.





## POST `(/work-units/{id}/complete)`

### Parameters
- **id** (path) (required): The work unit's client-supplied identifier.
