## Overview
Returns the current backlog depth/WIP read model for a process path's work pool — the SampleBacklog use case. This is a projection built from live `WorkPool` state, not persisted aggregate state. Side effect: if the pool is over its alarm threshold, publishes `BacklogThresholdBreached` (an existing, documented telemetry side effect of sampling — it does not mutate the `WorkPool` or `WorkUnit` aggregates themselves, so this remains a safe GET).

When the optional `cutoffAt` query parameter is supplied, this same read additionally reports — and publishes — the path's current remaining admission capacity for that CPT cutoff window (`PathCapacityChanged`, see ADR-0018). `remainingCapacityKnown` is `false` for a FlowFed path (no hard admission ceiling) or a ReleaseFed path with no WIP limit provisioned; `remainingCapacityUnits` is present only when `remainingCapacityKnown` is `true`. Omitting `cutoffAt` entirely skips capacity reporting and publishing, keeping every existing caller's behavior unchanged.





## GET `(/paths/{pathId}/telemetry)`

### Parameters
- **pathId** (path) (required): The process path's identifier — a named station that owns a queue (unit-in → unit-out), e.g. a pick zone or pack line. Must belong to a process-path family declared in this deployment's process-path catalogue (ADR-0012; today the fleet's sortable-fc topology declares the pick/pack/rebin/slam families, each optionally carrying a "-"-delimited station/zone suffix, e.g. pick-a or pack-station-1). The write endpoints (receiveChargeForecast, commitShiftPlan, enqueueWorkUnit) reject ids outside the declared families with `400 unknown-path-id`; read endpoints surface a missing pool/projection as `404` instead.

- **cutoffAt** (query): Optional RFC3339 CPT cutoff timestamp. When supplied, the response additionally reports remaining admission capacity for this path correlated against this cutoff, and a `PathCapacityChanged` event is published (ADR-0018). Must be non-empty when present — `?cutoffAt=` (present but empty) is a `400`, not "omitted".
