## Description
Raised by the WorkPool aggregate when `SampleBacklog` observes that the pool's backlog depth has crossed the alarm threshold — the buffer signal that drives flow balancing. Actively published to `warehouse.work-planning.events`; the published `data` carries only `path_id`. Consumers wanting the depth and rate numbers should read the telemetry projection over REST rather than infer them here.
