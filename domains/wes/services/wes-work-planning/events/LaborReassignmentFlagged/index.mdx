## Description
Raised by `RebalanceDecision` when a release-fed pool is at its WIP limit with backlog still queued: releasing more work cannot help, so the recommendation is to move heads onto the path instead. Actively published to `warehouse.work-planning.events`; the published `data` carries only `path_id`. Workforce Management is the intended reader.
