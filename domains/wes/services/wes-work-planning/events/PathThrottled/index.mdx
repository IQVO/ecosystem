## Description
Raised by `RebalanceDecision` when a flow-fed pool is over its alarm threshold and the recommendation is to throttle upstream release — the rope in Drum-Buffer-Rope pulling back on a saturated buffer. Actively published to `warehouse.work-planning.events`; the published `data` carries only `path_id`.
