## Description
**Reserved: declared for a future detection rule (ADR 0020 defers it); not emitted today.** Decided 2026-10-06: kept declared, neither emitted nor removed. Re-checked 2026-10-12 (gap fix D26): no ADR defines when it is raised, so it stays reserved; the architecture fitness test TestRateDeviationDetectedStaysReserved fails if production code starts raising it without that ADR.

Raised when a process path's observed throughput diverges materially from the rate committed in its PathPlan — the plan-vs-actual signal for flow balancing. **Not yet wired to the outbound Kafka adapter — documented here as part of the domain-event catalog, in-process only today.** The event type is declared in `internal/domain/shared/events.go` and the publisher's payload switch already handles it, but no application use case currently raises it, so nothing is emitted onto the topic. The example below shows the shape it would take once wired.

> **No consumer by design:** reserved, not emitted today (ADR 0020)
