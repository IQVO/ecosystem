## Description
Raised by the WorkUnit aggregate when `RecordCompletion` marks a released unit as done — either from the REST endpoint or from a `TaskCompleted` event consumed off `warehouse.fulfillment.events`. The aggregate refuses a double-complete. Actively published to `warehouse.work-planning.events`; the published `data` carries `path_id` and `work_unit_id`.
