## Overview
Adds a named qualification (e.g. "pack", "hazmat", "pick") to an already-started AssociateShift, raising AssociateCertified. An associate untrained on a path cannot be assigned to it (see POST /associates/\{id\}/assignments). Adding a certification the associate already holds is a no-op on state (set semantics) but still re-raises the event and returns 204 — certifications are not independently addressable sub-resources, so this returns 204 rather than 201.




## POST `(/associates/{id}/certifications)`

### Parameters
- **id** (path) (required): The associate's identity (AssociateId).
