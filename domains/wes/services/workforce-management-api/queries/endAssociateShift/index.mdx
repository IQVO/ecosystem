## Overview
Closes the associate's shift, raising AssociateShiftEnded. Any currently active LaborAssignment is closed first (its hours logged against the shift). Idempotent: ending an already-ended shift is a no-op — no error, no event, still 204.




## POST `(/associates/{id}/end-shift)`

### Parameters
- **id** (path) (required): The associate's identity (AssociateId).
