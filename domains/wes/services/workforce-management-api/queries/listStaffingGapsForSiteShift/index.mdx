## Overview
The canonical route of the all-paths staffing-gap list (ADR 0035; supersedes GET /buildings/\{buildingId\}/shifts/\{shiftId\}/staffing-gap, which stays as a deprecated alias). Same handler core and response shape. The path siteCode is both the plan lookup key and the associate scope: every path's activeHeads counts only associates with an active shift at that site (ADR 0034). Reuses the exact same per-path computation as GET /paths/\{pathId\}/staffing-gap and raises PathUnderstaffed for every understaffed path in the plan. This surfaces the gaps only — it never decides or performs a rebalance; that stays a human call recorded via POST /associates/\{id\}/assignments.




## GET `(/sites/{siteCode}/shifts/{shiftId}/staffing-gap)`

### Parameters
- **siteCode** (path) (required): The canonical Site code (the facility-layout Site code, e.g. WH1). It is both the plan lookup key AND the associate scope: activeHeads counts only assignments whose associate has an active (not-ended) shift at that site (ADR 0034, ADR 0035). The key is the resource identity and is used exactly as given (never trimmed); it is not required to be a canonical facility-layout code, because plans written under a legacy buildingId are read here too (ADR 0035). It is never validated against facility-layout: a key with no plan is 404.
- **shiftId** (path) (required): The shift (within the site) whose committed plan to read.
