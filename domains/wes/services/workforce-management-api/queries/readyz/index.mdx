## Overview
Reports whether this instance should receive traffic. Returns 200 `{"status":"ready"}` while serving and 503 `{"status":"not_ready"}` once graceful shutdown has begun (ADR-0022): readiness is flipped first so a Kubernetes readinessProbe stops routing new requests during the drain window, while the liveness probe (`/healthz`) stays green. Like `/healthz` it does not probe downstream dependencies.
