## Overview
Begins a logged break for the associate, raising AssociateBreakStarted. While on break, the associate cannot receive a new labor assignment (see POST /associates/\{id\}/assignments). Not idempotent: calling this while already on break is rejected as a conflict rather than treated as a no-op, since it represents a discrete state transition, not an upsert.




## POST `(/associates/{id}/break/start)`

### Parameters
- **id** (path) (required): The associate's identity (AssociateId).
