## Overview
Creates a new AssociateShift roster entry for this shift, with an initial set of certifications, raising AssociateShiftStarted. The associate id is client-supplied and this endpoint is naturally idempotent by that id: calling it twice for the same associate upserts the roster entry rather than erroring (each call still re-raises AssociateShiftStarted and returns 201). The optional siteCode records the canonical site the associate works at (ADR 0034) so the staffing gap can be scoped to a site.
