## Description
Raised by the `LaborAssignment` aggregate when an associate's prior
active assignment is closed and a new one opened on a different path
— the intra-shift move that keeps the one-ACTIVE-assignment invariant
intact. The move is always a human call recorded here; this context
never decides a rebalance on its own.

**Not on the integration topic.** Published only to the internal
analytics topic `warehouse.workforce.analytics` (dataschema
`urn:warehouse:workforce-management:analytics:<EventName>:v1`).
