## Description
Raised by the `ShiftPlan` aggregate when heads for a path are
proposed as a pure computation — `heads = ceil(charge / plannedRate)`
— before a human commits anything. A proposal is advisory: the
software proposes, a human commits.

**Not on the integration topic.** Published only to the internal
analytics topic `warehouse.workforce.analytics` (dataschema
`urn:warehouse:workforce-management:analytics:<EventName>:v1`).
