## Overview
Books a window on a door. The door must be a known Dock slot of a site whose `dockFlow` allows the direction; the
window must not start in the past, last at most the site's maximum (4 h) and start and end on the site's slot granularity, lie inside the door's operating hours and
outside its closures, and not overlap another `BOOKED` or `CHECKED_IN` appointment of the door. INBOUND covers at
least one known, not cancelled ASN that sits on no other active appointment (409 `asn-already-scheduled`); OUTBOUND names a known `cptId` or at least one shipment reference. Requires an
`Idempotency-Key`. Publishes `DockAppointmentBooked`. The answer carries the `Location` of the new appointment and
its `ETag`.





## POST `(/appointments)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit; a retry reuses it) that makes a retried request safe.
Required on every POST; answered with 400 `idempotency-key-required` when absent and 400
`idempotency-key-invalid` when it is longer than 128 characters or not printable ASCII. A replay with the same key
and the same request (method, path and body) returns the stored response with `Idempotency-Replayed: true`; the
same key with a different request is a 409 `idempotency-key-reused`.
