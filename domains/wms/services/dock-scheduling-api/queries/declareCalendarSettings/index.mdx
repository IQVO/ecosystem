## Overview
Sets `maxWindowMinutes` (1..240), `slotGranularityMinutes` (1..240), `arrivalToleranceMinutes` (0..240) and
`noShowGraceMinutes` (0..1440). Idempotent by method.





## PUT `(/sites/{siteId}/dock-calendar/settings)`

### Parameters
- **siteId** (path) (required): The facility-layout `siteCode`.
