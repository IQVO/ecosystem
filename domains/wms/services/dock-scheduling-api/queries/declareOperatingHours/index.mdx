## Overview
Replaces the whole set of operating-hours rows of the site. A door with rows of its own uses only those; a door
without rows uses the rows whose `doorCode` is null; no rows at all means 24x7. Refused with 409 `hours-conflict-with-appointments` (listing the ids) when an active appointment would fall outside the new hours. Idempotent by method. Publishes
`DoorOperatingHoursDeclared` (analytics stream).





## PUT `(/sites/{siteId}/dock-calendar/operating-hours)`

- **siteId** (path) (required): The facility-layout `siteCode`.
