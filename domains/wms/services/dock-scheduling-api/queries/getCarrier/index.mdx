## Overview
Reads one carrier by SCAC. A SCAC that is not registered is 404 `carrier-not-found`; that does NOT mean it cannot book (the registry is opt-in).




## GET `(/carriers/{scac})`

### Parameters
- **scac** (path) (required): The carrier's SCAC, 2..4 upper-case letters (anything else is 422 `invalid-scac`).
