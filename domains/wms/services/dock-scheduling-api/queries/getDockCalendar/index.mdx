## Overview
Returns the operating hours, the closures and the settings of a site, with defaults applied (24x7 hours when none
are declared; max window 240, granularity 15, arrival tolerance 15, no-show grace 60). A site that never declared
anything answers the defaults at version 0. A composite view: not paged.





## GET `(/sites/{siteId}/dock-calendar)`

### Parameters
- **siteId** (path) (required): The facility-layout `siteCode`.
