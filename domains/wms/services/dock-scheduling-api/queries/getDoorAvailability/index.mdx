## Overview
Answers the free windows of one door inside `[from, to)` (at most 14 days): the door's operating hours minus its
closures minus its `BOOKED` and `CHECKED_IN` appointments, cut on the site's slot granularity, optionally only
windows at least `minutes` long. A composite view, not a collection: it is not paged.





## GET `(/doors/{doorCode}/availability)`

### Parameters
- **doorCode** (path) (required): The facility-layout location code of the door (1..64 characters, no whitespace, control characters or `/`).
- **from** (query) (required): RFC 3339 start of the range.
- **to** (query) (required): RFC 3339 end of the range, after `from`, at most 14 days later.
- **minutes** (query): Only return free windows at least this long (default the slot granularity).
