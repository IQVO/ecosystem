## Overview
On-time, early, late and no-show counts and shares per site and carrier over `[from, to)`, folded from this
service's analytics topic (ADR 0006). An appointment counts once it has an outcome: an arrival by its status
(`EARLY`, `ON_TIME`, `LATE`), an implicit arrival (completed without a check-in) as `ON_TIME`, a no-show as
`NO_SHOW`; an appointment that was only booked, or cancelled before anyone arrived, is not counted. The range
applies to the current window start. Mandatory range of at most 92 days; an empty or inverted range is a 400
`invalid-report-range`. A range with no data answers 200 with an empty `items`.





## GET `(/reports/schedule-adherence)`

### Parameters
- **siteId** (query): Narrow to one site.
- **carrierScac** (query): Narrow to one carrier (`-` selects appointments that had no SCAC).
- **from** (query) (required): RFC 3339 start of the range (inclusive).
- **to** (query) (required): RFC 3339 end of the range (exclusive).
