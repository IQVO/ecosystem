## Overview
Lists appointments ordered by window start then id, one page at a time (`limit`, `cursor`; keyset). An empty result
is `200` with `{"items": []}`. All filters are optional and must be repeated on every page request. `from` and `to`
select appointments whose window overlaps `[from, to)`.





## GET `(/appointments)`

### Parameters
- **siteId** (query): Narrow to one site (facility-layout `siteCode`).
- **doorCode** (query): Narrow to one door.
- **state** (query): Narrow to one state.
- **direction** (query): Narrow to one direction.
- **carrierScac** (query): Narrow to one carrier SCAC.
- **atRisk** (query): `true` narrows to appointments flagged at risk.
- **from** (query): RFC 3339 start of the overlap range (inclusive).
- **to** (query): RFC 3339 end of the overlap range (exclusive).
- **limit** (query): Page size, 1 to 500 (default 100); anything else is 400 `invalid-limit`. A query parameter the collection does not declare is 400 `unknown-query-parameter`.
- **cursor** (query): Opaque page token, copied from the previous page's `nextCursor`; absent for the first page. A value that does not decode is 400 `invalid-cursor`. Repeat the filters on every page request.
