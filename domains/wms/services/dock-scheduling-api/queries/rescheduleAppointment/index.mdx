## Overview
Moves the window of a `BOOKED` appointment and optionally its door (`doorCode`). The new door and window are checked like a
booking, ignoring the appointment's own current window. Requires an `Idempotency-Key`;
`If-Match` with the `ETag` is honoured (412 on mismatch). Publishes `DockAppointmentRescheduled`.





## POST `(/appointments/{appointmentId}/reschedules)`

### Parameters
- **appointmentId** (path) (required): The appointment id (`appt-` followed by a lowercase UUID).
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit; a retry reuses it) that makes a retried request safe.
Required on every POST; answered with 400 `idempotency-key-required` when absent and 400
`idempotency-key-invalid` when it is longer than 128 characters or not printable ASCII. A replay with the same key
and the same request (method, path and body) returns the stored response with `Idempotency-Replayed: true`; the
same key with a different request is a 409 `idempotency-key-reused`.

- **If-Match** (header): The appointment `ETag` the caller last saw; a different current version answers 412 `precondition-failed`.
