## Overview
A JSON merge patch of `name`, `usdot` and `mc` (UpdateCarrier): an absent field is kept, `null` or an empty string clears an optional identifier
(`name` cannot be cleared). The status is not patchable: use the suspension routes. A patch that changes nothing is `200` and
publishes nothing. Requires an `Idempotency-Key`; `If-Match` with the `ETag` is honoured (412 on mismatch). Publishes
`CarrierRegistered` with the new snapshot and version.





## PATCH `(/carriers/{scac})`

### Parameters
- **scac** (path) (required): The carrier's SCAC, 2..4 upper-case letters (anything else is 422 `invalid-scac`).
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit; a retry reuses it) that makes a retried request safe.
Required on every POST; answered with 400 `idempotency-key-required` when absent and 400
`idempotency-key-invalid` when it is longer than 128 characters or not printable ASCII. A replay with the same key
and the same request (method, path and body) returns the stored response with `Idempotency-Replayed: true`; the
same key with a different request is a 409 `idempotency-key-reused`.

- **If-Match** (header): The `ETag` (version) of the appointment or carrier the caller last saw; a different current version answers 412 `precondition-failed`.
