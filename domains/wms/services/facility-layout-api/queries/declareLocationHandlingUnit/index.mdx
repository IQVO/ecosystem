## Overview
Sets or changes the unit of handling (EACH, CASE or PALLET) the slot accepts (ADR-0040). The slot must already exist and must not be Decommissioned. Naturally idempotent (same body, same state), like the geometry PUT, so it takes no Idempotency-Key. Publishes LocationSlotHandlingUnitDeclared. inventory-storage uses the value to decide whether a sealed case may be stowed in the bin.





## PUT `(/locations/{locationCode}/handling-unit)`

### Parameters
- **locationCode** (path) (required): The slot's full seven-segment code, `SITE-AREA-ZONE-AISLE-BAY-LEVEL-POSITION`.
