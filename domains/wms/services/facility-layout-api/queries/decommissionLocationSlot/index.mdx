## Overview
Marks the slot Decommissioned. This is a genuine domain command, not a CRUD update, which is why it is a verb-suffixed action on the slot resource rather than a PATCH.

The transition is **one-way** in v1: there is no reactivation use case, calling it twice is a 409, and re-registering the same LocationCode afterwards is rejected as a duplicate rather than quietly resurrecting the slot. Publishes LocationSlotDecommissioned. Returns 204 with no body — there is nothing to say beyond "done".





## POST `(/locations/{locationCode}/decommission)`

### Parameters
- **locationCode** (path) (required): The slot's full seven-segment code, `SITE-AREA-ZONE-AISLE-BAY-LEVEL-POSITION`.
