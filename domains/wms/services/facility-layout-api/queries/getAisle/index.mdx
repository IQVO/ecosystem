## Overview
Returns a single Aisle by its zone id and aisle code. This is the URL the Location header of a successful registerAisle points at.





## GET `(/zones/{zoneId}/aisles/{aisleCode})`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.

- **aisleCode** (path) (required): The aisle segment of a LocationCode.
