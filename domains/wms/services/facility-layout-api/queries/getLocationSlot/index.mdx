## Overview
Returns a single LocationSlot by its LocationCode, with the code exploded into its seven typed coordinate segments so a renderer does not have to re-parse it. A code that is not seven `[A-Z0-9]` segments is a 400, not a 404 — it could never identify a slot.





## GET `(/locations/{locationCode})`

### Parameters
- **locationCode** (path) (required): The slot's full seven-segment code, `SITE-AREA-ZONE-AISLE-BAY-LEVEL-POSITION`.





### Responses

#### <span className="text-green-500">200 OK</span>
The coded leaf location. Its identity IS its LocationCode. It owns whether the code exists, is active, and is legal for a given kind of storage unit — never what is stored in it.
