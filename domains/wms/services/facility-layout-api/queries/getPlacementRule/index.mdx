## Overview
Returns a single PlacementRule by its id. This is the URL the Location header of a successful definePlacementRule points at.





## GET `(/placement-rules/{ruleId})`

### Parameters
- **ruleId** (path) (required): The placement rule's id.




### Responses

#### <span className="text-green-500">200 OK</span>
