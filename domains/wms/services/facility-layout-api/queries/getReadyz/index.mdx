## Overview
Returns 200 while the process is accepting traffic, 503 once graceful shutdown (ADR-0020) has begun: readiness is flipped to not-ready as the FIRST step of the shutdown sequence, before the listener closes, so a Kubernetes readinessProbe gets a window to stop routing new requests during the drain. Like /healthz it does not check downstream dependencies.
