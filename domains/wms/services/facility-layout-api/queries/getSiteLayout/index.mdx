## Overview
The primary "draw the warehouse" endpoint. Returns the whole structure of one Site as a single nested document — zones → aisles → location slots — with every slot's exploded coordinates, type, capacity and status. Zones come back ordered by id, aisles in SequenceHint **walk order** (not registration order), and slots ordered bay → level → position, so a frontend can render a floor plan directly with no client-side joining or sorting.

With `?format=svg` the identical read model is rendered server-side as a minimal SVG floor plan (one coloured band per zone, one row of rects per aisle, colour = temperature class / hazmat) that a human can curl straight into a `.svg` file and open in a browser.

This is a PROJECTION assembled by querying across the aggregates, not separately stored state. It performs no writes and publishes no events.





## GET `(/sites/{siteCode}/layout)`

### Parameters
- **siteCode** (path) (required): The site's code — the first segment of every LocationCode inside it.
- **format** (query): Response representation. Omit (or use `json`) for the nested JSON document; use `svg` to receive an `image/svg+xml` floor plan of the same data.





### Responses

#### <span className="text-green-500">200 OK</span>
The full nested, drawable structure of one Site: zones → aisles → slots, pre-grouped and pre-ordered for direct rendering. Also carries the site's fixed structures (ADR-0017): walls, columns, offices, and other physical obstacles that are not locations.
