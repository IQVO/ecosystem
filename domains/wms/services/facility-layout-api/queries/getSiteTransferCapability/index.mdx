## Overview
Returns whether the site may act as the origin (donates stock) and/or the destination (receives stock) of an inter-warehouse transfer, and the revision of its last published SiteCapabilityChanged (ADR-0035). A site whose capability was never set is capable of nothing at revision 0 — exactly how network-inventory-planning treats a site it has never heard about.





## GET `(/sites/{siteCode}/transfer-capability)`

### Parameters
- **siteCode** (path) (required): The site's code — the first segment of every LocationCode inside it.




### Responses

#### <span className="text-green-500">200 OK</span>
A site's transfer capability (ADR-0035) and the revision of the last SiteCapabilityChanged published for it. The revision only ever increases per site; 0 means no snapshot was ever published.
