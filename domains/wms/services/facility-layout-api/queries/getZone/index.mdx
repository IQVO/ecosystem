## Overview
Returns a single Zone by its id (`SITE-AREA-ZONE`). This is the URL the Location header of a successful registerZone points at.





## GET `(/zones/{zoneId})`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.





### Responses

#### <span className="text-green-500">200 OK</span>
A behavioral classification scoped to a Site, bundling the Area and Zone code segments into one aggregate.
