## Overview
The second "draw the warehouse" endpoint. Returns one Zone's slots as an explicit matrix: rows are Levels, columns are (Aisle, Bay) pairs in aisle SequenceHint walk order, and `rows[i].cells` is index-aligned with `columns`. A cell is literal JSON `null` wherever the rack has a gap; otherwise it lists the Positions at that coordinate. A UI iterates rows × columns and paints — no client-side layout maths.

Like the site layout this is a pure projection: no writes, no events.





## GET `(/zones/{zoneId}/grid)`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.





### Responses

#### <span className="text-green-500">200 OK</span>
One Zone's slots as an explicit 2D matrix a UI can iterate and paint: rows are Levels, columns are (Aisle, Bay) pairs in walk order.
