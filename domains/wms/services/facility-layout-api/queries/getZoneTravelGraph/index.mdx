## Overview
Returns one zone's travel graph (ADR-0017) as every waypoint (aisle + bay) and every directed, weighted edge between them, built fresh from the zone's aisles, registered slots, and active cross-aisles. An edge's metresM is derived from an aisle's real centreline geometry when set, or from the zone's bay pitch otherwise (flagged estimated). This context reports map TOPOLOGY only — never travel time or congestion, which remain wes-work-planning's concern.





## GET `(/zones/{zoneId}/travel-graph)`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.
