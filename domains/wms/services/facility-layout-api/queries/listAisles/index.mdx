## Overview
Returns every Aisle in the given Zone, ordered by SequenceHint then aisle code — that is, in the order an associate would walk them. Answers 404 if the zone itself is unknown.





## GET `(/zones/{zoneId}/aisles)`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.
