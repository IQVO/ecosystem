## Overview
Answers "where are this site's dock doors" (or any other LocationRole) without walking the full nested site layout (ADR-0016). Results are ordered zone → aisle → bay → level → position, like getSiteLayout's slots.





## GET `(/sites/{siteCode}/locations)`

### Parameters
- **siteCode** (path) (required): The site's code — the first segment of every LocationCode inside it.
- **role** (query) (required): The LocationRole to filter on.
