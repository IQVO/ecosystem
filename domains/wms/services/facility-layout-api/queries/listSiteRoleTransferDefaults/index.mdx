## Overview
Read-only table (ADR-0037): for every assignable site role, whether a site of that role should be an inter-site transfer origin and/or destination. It is the ONE source of truth the warehouse-infra seed and operators read instead of hard-coding it. It is a default only: nothing applies it automatically, a role change never flips capability, and capability is set with `PUT /sites/{siteCode}/transfer-capability` (ADR-0035). `UNSPECIFIED` has no row: an unclassified site's capability is left as it is. Rows are in a stable display order.
