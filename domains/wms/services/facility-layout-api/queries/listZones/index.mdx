## Overview
Returns every Zone in the given Site, ordered by zone id. Answers 404 if the site itself is unknown, rather than an empty list, so a caller can tell "no zones yet" apart from "no such site".





## GET `(/sites/{siteCode}/zones)`

### Parameters
- **siteCode** (path) (required): The site's code — the first segment of every LocationCode inside it.
