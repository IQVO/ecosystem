## Overview
Records an aisle's straight-line travel centreline (ADR-0017), used by the travel graph as this aisle's walkable path. The aisle must already exist and must not be Decommissioned. Publishes AisleGeometryUpdated.





## PUT `(/zones/{zoneId}/aisles/{aisleCode}/geometry)`

### Parameters
- **zoneId** (path) (required): The zone's id, `SITE-AREA-ZONE` — exactly the first three segments of every LocationCode inside it.

- **aisleCode** (path) (required): The aisle segment of a LocationCode.
