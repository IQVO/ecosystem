## Overview
Records a coded slot's physical position, footprint, and (optionally) an explicit pick-sequence override (ADR-0017). The slot must already exist and must not be Decommissioned. Publishes LocationGeometryUpdated.





## PUT `(/locations/{locationCode}/geometry)`

### Parameters
- **locationCode** (path) (required): The slot's full seven-segment code, `SITE-AREA-ZONE-AISLE-BAY-LEVEL-POSITION`.
