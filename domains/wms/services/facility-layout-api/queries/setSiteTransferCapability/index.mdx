## Overview
Replaces the site's transfer capability with the full snapshot in the body (ADR-0035). When the snapshot differs from the current one — or no snapshot was ever published — the site's capabilityRevision advances by exactly one and SiteCapabilityChanged is published through the transactional outbox with that revision. Repeating the current snapshot is an idempotent no-op: 200, same revision, no event, so no Idempotency-Key is needed.

Optimistic concurrency (ADR-0025, extended to Site by ADR-0035): a concurrent change of the same site loses with 409 `concurrent-modification`; re-read and retry. A decommissioned site's capability is frozen (409 `site-not-active`).
