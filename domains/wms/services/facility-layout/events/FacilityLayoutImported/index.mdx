## Description
Raised once per `ImportFacilityLayout` call, summarising rows submitted/imported/rejected — in addition to, not instead of, the per-slot `LocationSlotRegistered` events for each successful row. Kafka key: the event's CloudEvents `id` (no single aggregate identity — a batch outcome — so batches spread across partitions; ordering against other events is not guaranteed); CloudEvents `subject`: the fixed batch identity `layout-import`. No consumer wired today.
