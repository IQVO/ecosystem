## Description
Raised by `DecommissionLocationSlot`. Kafka key: `locationCode`. **Consumed live** by inventory-storage's location-classification cache, which evicts the slot (its stow placement check then fails open for that location, by design). Decommissioning is irreversible — there is no compensating event.
