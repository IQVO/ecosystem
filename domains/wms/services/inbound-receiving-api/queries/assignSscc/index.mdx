## Overview
For a case that arrived with no SSCC label (ADR 0024). Give the case
GTIN; the service receives ONE case of the active CASE pack under a new
SSCC of the **receiver's own GS1 company prefix** (extension digit 0, a
serial from a never-reused per-prefix sequence, a valid check digit),
raises `UnlabelledCarton` against a carton ASN as always, and answers
**201** with what a printer needs: `sscc`, `humanReadable`
(`(00)<sscc>`), `elementString` (the GS1-128 data) and `symbology`. The
service has no printer driver: the floor client prints. The carton
carries `ssccSource: receiver` on `ReceiptCartonReceived`.

**409 `sscc-prefix-not-configured`** until the business supplies a GS1
company prefix (`RECEIVER_GS1_COMPANY_PREFIX`, 7 to 10 digits): the
prefix is a licensed asset and there is no default. **409
`sscc-serial-exhausted`** when every serial of the prefix is used.
Not naturally idempotent, so the `Idempotency-Key` is required: a retry
with the same key replays the same SSCC and receives nothing twice.





## POST `(/receipts/{receiptId}/sscc-assignments)`

### Parameters
- **receiptId** (path) (required): The receipt id, `rcpt-` followed by a lowercase UUID.
- **Idempotency-Key** (header) (required): Caller-supplied key, unique per logical submit (a UUID minted per user
action and reused on every retry of it). Required on every POST. A
retry with the same key and the same request (method, path and body)
replays the stored response with `Idempotency-Replayed: true`; the same
key with a different request is 409 `idempotency-key-reused`; a missing
key is 400 `idempotency-key-required` and one longer than 128
characters or with non-printable characters is 400
`idempotency-key-invalid`.

- **If-Match** (header): The `ETag` the caller last saw (quoted or bare integer >= 1). When it no
longer matches the current version the request is refused with 412
`version-mismatch`; an empty value or `*` skips the check and any
other value is 400 `malformed-request`.
