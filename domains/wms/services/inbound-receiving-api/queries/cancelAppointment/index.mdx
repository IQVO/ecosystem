## Overview
Cancels a `Booked` appointment and publishes `DockAppointmentCancelled`;
any other state is 409 `appointment-not-booked`. The body and its
`reason` are optional.





## POST `(/appointments/{appointmentId}/cancel)`

### Parameters
- **appointmentId** (path) (required): The appointment id, `appt-` followed by a lowercase UUID.
- **Idempotency-Key** (header): Optional on action requests; honoured like the required key when present.
- **If-Match** (header): The `ETag` the caller last saw. When it no longer matches the current
version the request is refused with 412 `version-mismatch`.
