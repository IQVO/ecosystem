## Overview
Cancels a `Registered` ASN and publishes `ASNCancelled`. An ASN that is
already being received is 409 `asn-in-progress`; a `Closed` or
`Cancelled` one is 409 `asn-terminal`. The body and its `reason` are
optional.





## POST `(/asns/{asnNumber}/cancel)`

### Parameters
- **asnNumber** (path) (required): The ASN number (1 to 64 characters of `[A-Za-z0-9._-]`).
- **Idempotency-Key** (header): Optional on action requests; honoured like the required key when present.
- **If-Match** (header): The `ETag` the caller last saw. When it no longer matches the current
version the request is refused with 412 `version-mismatch`.
