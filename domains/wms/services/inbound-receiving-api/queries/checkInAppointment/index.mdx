## Overview
Records the carrier's arrival at the door (server clock) and publishes
`DockAppointmentCheckedIn`. Only a `Booked` appointment can check in
(409 `appointment-not-booked`), and only from 30 minutes before
`windowStart` until `windowEnd` (409 `outside-check-in-window`).





## POST `(/appointments/{appointmentId}/check-in)`

### Parameters
- **Idempotency-Key** (header): Optional on action requests; honoured like the required key when present.
- **If-Match** (header): The `ETag` the caller last saw. When it no longer matches the current
version the request is refused with 412 `version-mismatch`.
