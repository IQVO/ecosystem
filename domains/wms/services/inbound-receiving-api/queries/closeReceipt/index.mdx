## Overview
Ends receiving, computes the discrepancies per line (`Short`, `Over`,
`Damaged`), completes the ASN and, when the receipt was opened from an
appointment, completes that appointment. Publishes `ReceiptClosed` and,
with an appointment, `DockAppointmentCompleted`. Closing a receipt that
is already `Closed` is 409 `receipt-closed`. A line nothing was received
for is `Short`.





## POST `(/receipts/{receiptId}/close)`

### Parameters
- **receiptId** (path) (required): The receipt id, `rcpt-` followed by a lowercase UUID.
- **Idempotency-Key** (header): Optional on action requests; honoured like the required key when present.
- **If-Match** (header): The `ETag` the caller last saw. When it no longer matches the current
version the request is refused with 412 `version-mismatch`.
