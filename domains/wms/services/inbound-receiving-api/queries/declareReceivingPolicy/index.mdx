## Overview
Creates or replaces the tolerance policy of one (`ownerRef`,
`supplierRef`) pair (ADR 0026) and publishes `ReceivingPolicyDeclared`.
An absent `ownerRef` declares the house default (a client-owned
receipt does not fall back to it: the lookup is exact-match). Per side
`0 <= tolerance < hardStop <= 1`, else 400 `invalid-tolerance-band`.
201 on create, 200 on replace; both answer the stored policy with its
`version`.





## POST `(/receiving-policies)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-supplied key, unique per logical submit (a UUID minted per user
action and reused on every retry of it). Required on every POST. A
retry with the same key and the same request (method, path and body)
replays the stored response with `Idempotency-Replayed: true`; the same
key with a different request is 409 `idempotency-key-reused`; a missing
key is 400 `idempotency-key-required` and one longer than 128
characters or with non-printable characters is 400
`idempotency-key-invalid`.

What is stored. A 2xx is stored. A 5xx is never stored. A refusal is
stored (and replayed) only when it is final for the request: the
validation problems (the `invalid-*`, `*-requires-*`, `duplicate-sku`,
`duplicate-asn-number`, `unsupported-gtin`, `homogeneous-carton-mixed`,
`carton-contents-mismatch` slugs), `asn-already-exists`, `asn-terminal`,
`appointment-cancelled`, `receipt-closed` and `receipt-not-found`.
A refusal that depends on state that can change is NOT stored: its key is
released, a retry with the same key and request executes again (it can
succeed once the state allows), and a different request under the
released key is a new request, not `idempotency-key-reused`. These are
`concurrent-modification`, `version-mismatch` (re-read, then retry with
the new `If-Match`), `malformed-request`, `asn-not-found`,
`appointment-not-found`, `receiving-policy-not-found`, `carton-not-found`,
`unknown-asn`, `unknown-appointment`, `unknown-sku`, `unknown-gtin`,
`counted-sku-unknown`, `asn-not-on-appointment`, `line-not-on-asn`,
`duplicate-sscc`, `asn-in-progress`, `asn-not-receivable`,
`receipt-already-open`, `tolerance-override-required`, `tolerance-blocked`,
`sscc-prefix-not-configured`, `sscc-serial-exhausted`,
`counted-contents-not-mixed`, `scan-kind-mismatch` and
`unsupported-pack-level`. Rows are kept for the retention window
(default 24 hours).
