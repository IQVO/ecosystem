## Overview
Returns the appointment with its window, ASN numbers, state and version (also as the `ETag`).




## GET `(/appointments/{appointmentId})`

### Parameters
- **appointmentId** (path) (required): The appointment id, `appt-` followed by a lowercase UUID.
