## Overview
Returns the ASN with its lines, state and version (also as the `ETag`).




## GET `(/asns/{asnNumber})`

### Parameters
- **asnNumber** (path) (required): The ASN number (1 to 64 characters of `[A-Za-z0-9._-]`).
