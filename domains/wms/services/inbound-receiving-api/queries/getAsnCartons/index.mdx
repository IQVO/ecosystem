## Overview
The cartons the supplier announced (`cartons` is empty for a flat ASN)
with the status of each against the ASN's receipt: `Expected` (no
receipt yet, or not scanned yet), `Accepted` (its SSCC was scanned) or
`Missing` (the receipt is closed and it never was). Cartons are
announced on `POST /asns`; there is no endpoint to add one later.





## GET `(/asns/{asnNumber}/cartons)`

### Parameters
- **asnNumber** (path) (required): The ASN number (1 to 64 characters of `[A-Za-z0-9._-]`).
