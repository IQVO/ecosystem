## Overview
The policy of the exact (`ownerRef`, supplier) key: the house default
when `ownerRef` is absent, that owner's own policy when present (ADR
0026). 404 `receiving-policy-not-found` when the exact key has no
policy.





## GET `(/receiving-policies/{supplierRef})`

### Parameters
- **supplierRef** (path) (required): The supplier reference (1 to 64 characters).
- **ownerRef** (query): Opaque tenant tag; absent reads the house default.
