## Overview
Lists appointments in ascending `windowStart` order (ties by id), a page
at a time. `door` and `state` narrow by equality; `from` and `to`
narrow to appointments whose window overlaps `[from, to)`.





## GET `(/appointments)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100).
- **cursor** (query): The `nextCursor` value from the previous page.
- **door** (query): Only appointments at this door code.
- **state** (query): Only appointments in this state.
- **from** (query): RFC 3339 instant; only appointments whose window ends after it.
- **to** (query): RFC 3339 instant; only appointments whose window starts before it.
