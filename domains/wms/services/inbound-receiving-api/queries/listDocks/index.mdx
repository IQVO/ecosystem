## Overview
The inbound dock doors this service knows from facility-layout events
(ADR 0003): doors registered with `role=Dock` and `dockFlow` of
`Inbound` or `Both`, minus decommissioned ones, in ascending door-code
order. `mode` is the current `DOCK_DOOR_MODE`; in `permissive` the list
is informational and any door code can be booked.
