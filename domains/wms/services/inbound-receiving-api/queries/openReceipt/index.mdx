## Overview
Starts receiving an ASN: opens a receipt against a snapshot of its
lines, moves a `Registered` ASN to `Receiving` and publishes
`ReceiptOpened`. The ASN must be `Registered` or `Receiving`
(409 `asn-not-receivable`) and may have only one open receipt
(409 `receipt-already-open`). With `appointmentId` the appointment
must be `CheckedIn` (409 `appointment-not-checked-in`) and cover the
ASN (422 `asn-not-on-appointment`); the receipt takes its door code
from it. Without one it is a walk-in delivery with no door. A missing
ASN or appointment is 422 `unknown-asn` / `unknown-appointment`.





## POST `(/receipts)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-supplied key for this resource-creating request, unique per
logical action (a UUID minted per submit). A retry with the same key
and body replays the original response; the same key with a different
body is 422 `idempotency-key-reused`; a missing or empty key is 400
`idempotency-key-required`.
