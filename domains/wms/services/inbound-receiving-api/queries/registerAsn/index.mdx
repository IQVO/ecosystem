## Overview
Registers the supplier's announcement of a delivery in state
`Registered`. `asnNumber` (1 to 64 characters of `[A-Za-z0-9._-]`) is
the identity; registering an existing number is 409
`asn-already-exists`. `lines` is non-empty, `lineNo` runs exactly
`1..n` in order, SKUs are unique across lines and every `expectedQty`
is positive. When `PRODUCT_MODE=kafka` an unknown SKU is 422
`unknown-sku`. Publishes `ASNRegistered`.





## POST `(/asns)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-supplied key for this resource-creating request, unique per
logical action (a UUID minted per submit). A retry with the same key
and body replays the original response; the same key with a different
body is 422 `idempotency-key-reused`; a missing or empty key is 400
`idempotency-key-required`.
