## Description
`type` = `com.warehouse.wms.inbound-receiving.receipt.CartonDiscrepancyRaised`;
subject = the receipt id, key = the ASN number. Same payload as on the integration topic; dataschema `urn:warehouse:inbound-receiving:analytics:CartonDiscrepancyRaised:v1`.
Carton discrepancies travel ONLY on this event; `ReceiptClosed` keeps
its three v1 kinds. A refused scan books nothing and raises this
event; an accepted carton can raise it too (for example
`UnlabelledCarton`).
