## Description
`type` = `com.warehouse.wms.dock-scheduling.dockappointment.DockAppointmentBooked`,
source `/warehouse/dock-scheduling`; key and subject = `appointment_id`.
`data` is snake_case. Only the fields in the schema are read; the rest
of dock-scheduling's payload (`site_id`, `carrier_scac`, `cpt_id`,
`shipment_refs`, `expected_seal_number`, `provenance`,
`arrival_tolerance_minutes`, ...) is ignored.
