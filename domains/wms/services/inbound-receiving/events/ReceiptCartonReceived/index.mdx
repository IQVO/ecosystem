## Description
`type` = `com.warehouse.wms.inbound-receiving.receipt.ReceiptCartonReceived`;
subject = the receipt id, key = the ASN number.
IDENTITY ONLY: it never books quantity (`ReceiptLineReceived` stays the
sole quantity authority, in eaches). inventory-storage uses it to
create or link a Container keyed (receipt_id, line_no, lpn), in either
arrival order. `lpn` is the SSCC, or an internal `LPN-<ulid>` for a
case received without one. There is no site: the site is derived by
inventory-storage at stow (ADR 0013).
