## Description
`type` = `com.warehouse.wms.inbound-receiving.receipt.ReceivingAdviceOverdue`;
subject = the receipt id, key = the ASN number. Raised by the housekeeping
sweep exactly once per receipt that is still Open when
`last_carton_at + sla_seconds` (`due_at`) is in the past. It does not stop
the receipt: closing it later still issues the advice, with `within_sla`
false. `overdue_at` (the CloudEvents `time`) is when the sweep saw it.

> **No consumer by design:** none yet: an alarm for the planned partner-connectivity and warehouse-ops consumers (D-3)
