## Overview
BreakCase (ADR 0045): the whole sealed case is opened and its eaches move to loose stock of the same owner in `looseBin`. Full-quantity and conserving: exactly `unitsPerPack` eaches leave the SEALED_CASE unit and arrive as loose stock, and the container goes SEALED, OPEN, EMPTY in one transaction, with `CaseBroken` and `ContainerEmptied` in the transactional outbox. A case that is reserved (a `cases` reservation) cannot be broken; a container that is not SEALED and stowed cannot either; `looseBin` must accept loose eaches and be in the container's site.

Behind the Idempotency-Key middleware (ADR 0018).




## POST `(/containers/{lpn}:break)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a retried request safe (ADR 0018). Postgres is the only runtime, so the check is on in every deployment: a missing or empty key is answered with 400 `idempotency-key-required`; a replay with the same key and the same body returns the original response, while the same key with a different body is 422 `idempotency-key-reused`.

- **lpn** (path) (required): The container's license plate (the carton SSCC, or an internal `LPN-<site>-<id>`).
