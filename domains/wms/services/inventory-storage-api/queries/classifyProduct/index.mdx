## Overview
Retired by ADR 0034 (product-master ADR 0003 stage C). product-master owns product classification; this service keeps a read-only local copy fed by product-master's `ProductClassified` events. Every call returns `410 Gone` with problem type `classification-moved`, naming product-master's `PUT /products/{sku}/classification` (same request body). Any request body is ignored and nothing is written. Removed at product-master ADR 0003 stage E.
