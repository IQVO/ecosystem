## Overview
Consumes a reservation: for every Allocation it holds, the allocated quantity is physically removed from its StockUnit (StockUnit transitions toward PICKED/REMOVED) and the corresponding bin capacity is released. This is a terminal, one-way command on the resource in the domain command style (not forced into PUT/PATCH) — a reservation that is already resolved, expired, or has no allocations cannot be confirmed again.





## POST `(/reservations/{id}/confirm-pick)`

### Parameters
- **id** (path) (required): The reservation's id, formatted `res-<uuid>`.
