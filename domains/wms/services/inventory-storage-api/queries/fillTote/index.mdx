## Overview
Scan the item, scan the tote (ADR 0054): the same semantics, placement checks and events as `POST /stowages`, at the bin the tote is in (the decant station). Creates one stock unit of the SKU in the tote, raises `ItemStowed`, `LocationRecorded`, `BinStockLevelChanged` and `ToteFilled`. A tote in no bin is 409 `tote-not-placed`: stow it first.

Behind the Idempotency-Key middleware like every other POST (ADR 0018).




## POST `(/totes/{lpn}/fills)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit; a retry reuses it, a new user action mints a new one) that makes a retried request safe (ADR 0018, REST guideline section 2): 1-128 printable ASCII characters. Postgres is the only runtime, so the check is on in every deployment: a missing key is answered with 400 `idempotency-key-required`, a malformed one with 400 `idempotency-key-invalid`; a replay with the same key and the same method, path and body returns the original response plus `Idempotency-Replayed: true`, while the same key with a different method, path or body is 409 `idempotency-key-reused`.
What is replayed (ADR 0053): a 2xx; a refusal that is a function of the request alone (validation: 400, 422; `reservation-not-found` and `held-unit-not-found`, ids minted by this service and never deleted); and a refusal that committed state (`reservation-already-resolved`, `transfer-scan-quarantined`). What is NOT replayed: a 5xx, and every refusal that depends on state that can change, among them `concurrent-modification`, `bin-not-found`, `container-not-found`, `insufficient-usable`, `insufficient-reserved`, `bin-full`, `receipt-not-staged`, `container-not-sealed`, `container-not-stowed`, `hazmat-zone-required`, `temperature-class-mismatch` and `location-classification-unavailable`. For those the key is released: retry with the SAME key and the request executes again, and a different body under the released key is a new request.

- **lpn** (path) (required): The tote's license plate: its permanent label, registered once (ADR 0054). One namespace with sealed cases.
