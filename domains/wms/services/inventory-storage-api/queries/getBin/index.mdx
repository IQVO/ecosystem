## Overview
Returns the bin's capacity, how much of it is occupied, and how much is still available for stow. Side-effect-free. An unknown bin is a 404 (there is no meaningful empty bin to return).





## GET `(/bins/{binId})`

### Parameters
- **binId** (path) (required): The bin's coded slot identifier.




### Responses

#### <span className="text-green-500">200 OK</span>
A coded storage slot with a fixed capacity (chaotic storage).
