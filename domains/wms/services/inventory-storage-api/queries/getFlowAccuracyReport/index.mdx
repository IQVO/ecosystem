## Overview
Read-only analytical report over the inventory-storage event stream (ADR 0011): per (SKU, bin, hour) received/stowed/picked quantities, reservation lifecycle counts, and cycle-count accuracy signals. Served by the `inventory-reports` deployment from its own read-only pool (ADR 0020 §CQRS split); the OLTP `inventory` binary does not serve this path. `from` and `to` are required RFC 3339 timestamps; `sku` and `binId` narrow the result; `granularity` is currently only `hour`. Side-effect-free and unauthenticated (ADR 0015).





## GET `(/reports/flow-accuracy)`

### Parameters
- **from** (query) (required): Inclusive start of the window, RFC 3339.
- **to** (query) (required): End of the window, RFC 3339.
- **sku** (query): Restrict to one SKU.
- **binId** (query): Restrict to one bin.
- **granularity** (query): Bucket size. Only `hour` is supported (the default).
