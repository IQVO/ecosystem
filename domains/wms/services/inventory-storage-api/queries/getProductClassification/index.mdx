## Overview
DEPRECATED (ADR 0034): product-master owns product classification; read it from product-master's `GET /products/{sku}/classification` (same response shape). This endpoint stays until product-master ADR 0003 stage E and is served from this service's local copy of product-master's `ProductClassified` events (the copy StowStock reads), so it can lag product-master briefly. Side-effect-free. Unlike GetUsableInventory, an unclassified SKU is a 404, not a zero-value response — there is no meaningful "empty" classification to return.





## GET `(/products/{sku}/classification)`

### Parameters
- **sku** (path) (required): The stock-keeping unit identifier.




### Responses

#### <span className="text-green-500">200 OK</span>
SKU-level master data describing how an item must be handled, independent of any StockUnit or bin. Owned by product-master (ADR 0034); this is this service's local copy. dotHazardClass adds a same-bin DOT segregation check enforced at stow time (ADR 0010).
