## Overview
Returns 200 `{"status":"ready"}` while the process is accepting traffic, and 503 `{"status":"not_ready"}` once graceful shutdown has begun (ADR 0020 — readiness is flipped FIRST so a Kubernetes readinessProbe stops routing new requests during the drain window). Distinct from `/healthz`, which is liveness only and is never flipped by shutdown. Checks no downstream dependency.
