## Overview
Returns every Reservation ever created against a caller-supplied demandRef (an external system's order+line reference, e.g. from order-management). A demandRef can have MULTIPLE reservations across its lifetime — a reservation that was revoked, followed by a successful retry — so this returns an array, not a single resource; an unknown demandRef returns 200 with an empty array, not 404. This is the read side backing a cross-service order-lifecycle console screen that needs to answer "what did inventory-storage do for order X, line N". Side-effect-free.





## GET `(/reservations)`

### Parameters
- **demandRef** (query) (required): The caller-supplied demand reference to look reservations up by (e.g. an external order+line reference). Required — there is no list-all semantics for this endpoint.
