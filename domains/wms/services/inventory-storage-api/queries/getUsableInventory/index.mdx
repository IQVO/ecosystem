## Overview
Returns the usable-inventory read model for a SKU: on-hand minus active reservations minus held/unlocated stock, summed across every StockUnit for that SKU. This is a projection, not a stored aggregate — it is what constrains ReserveStock, since total on-hand is not what's available to promise to new demand. Side-effect-free.





## GET `(/inventory/{sku}/usable)`

### Parameters
- **sku** (path) (required): The stock-keeping unit identifier.
