## Overview
The totes whose logical location is the bin (ADR 0054), ordered by LPN (which is unique, so it is both the sort key and the id of the keyset cursor). Keyset-paginated (REST guideline section 3): one page of `{items, nextCursor}`, `limit` (1-500, default 100) and the opaque `cursor` from the previous page's `nextCursor`; `nextCursor` is absent on the last page. Any other query parameter is 400 `unknown-query-parameter`. Side-effect-free.




## GET `(/bins/{binId}/totes)`

### Parameters
- **binId** (path) (required): The bin to inspect.
- **limit** (query): Page size of a collection GET (REST guideline 3.2): an integer from 1 to 500, default 100. Anything else is 400 `invalid-limit`.

- **cursor** (query): Opaque page token: the previous page's `nextCursor`, passed back unchanged together with the same filters. Absent on the first page. A value this API did not issue is 400 `invalid-cursor`.
