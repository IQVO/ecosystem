## Overview
The units still HELD (ADR 0052), oldest first (ties by id), filtered by `reason`, `sku` and age (`olderThanHours`: held for MORE than that many hours). A removed unit (released, returned, scrapped) is not listed; read it by id for its audit trail. Keyset-paginated (REST guideline section 3): `{items, nextCursor}`, `limit` (1-500, default 100) and the opaque `cursor`. Any other query parameter is 400 `unknown-query-parameter`. Side-effect-free.




## GET `(/held-stock)`

### Parameters
- **reason** (query): Only units held for this reason.
- **sku** (query): Only units of this SKU.
- **olderThanHours** (query): Only units held for more than this many hours (the ageing filter).
- **limit** (query): Page size of a collection GET (REST guideline 3.2): an integer from 1 to 500, default 100. Anything else is 400 `invalid-limit`.

- **cursor** (query): Opaque page token: the previous page's `nextCursor`, passed back unchanged together with the same filters. Absent on the first page. A value this API did not issue is 400 `invalid-cursor`.
