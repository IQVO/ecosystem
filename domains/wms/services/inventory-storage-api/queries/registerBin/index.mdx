## Overview
Declarative, idempotent bin registration by inventory control (ADR 0025). The body states the desired capacity and the bin converges to it. An absent bin is created empty (201). A present bin with the same capacity is left untouched (200, nothing written). A present bin with a different capacity is resized (200), as long as the new capacity is not below what the bin already holds — shrinking below occupancy is rejected (409 capacity-below-occupancy) because that stock is physically in the slot. Occupancy is never changed by this call; it moves only through stow and pick. A resize racing a concurrent stow can surface as 409 concurrent-modification (re-fetch and retry).
