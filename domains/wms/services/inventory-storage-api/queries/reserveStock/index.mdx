## Overview
Binds a quantity of a SKU's usable inventory (on-hand minus existing reservations, first-fit across whichever StockUnits have usable quantity) to a piece of demand identified by demandRef. The reservation is NOT permanently bound to one physical StockUnit — the specific units/quantities drawn from are recorded as Allocations, but a subsequent revoke-and-reserve cycle is free to draw from a different holding. This is what lets a failed physical pick be retried without stranding the order. The reservation expires automatically after a timeout if never confirmed or revoked. Idempotent (best-effort) by (demandRef, sku, quantity): retrying this call after a dropped response returns the existing ACTIVE reservation for the same demandRef, SKU and quantity instead of creating a second one (see REST_AUDIT.md's idempotency notes). One demandRef (e.g. an order) may hold several ACTIVE reservations at once -- one per line/SKU -- so a request for a different SKU or quantity under the same demandRef is always a new reservation. The optional `lineNo` (ADR 0036) names the order line the reservation is for: it is stored, returned, and also taken into account by the replay guard (two lines of one order with the same SKU and quantity stay two reservations when their `lineNo` differ). Replays of the same Idempotency-Key with an identical body still return the cached response; adding `lineNo` to a key first used without it is a different body (422).





## POST `(/reservations)`

### Parameters
- **Idempotency-Key** (header): Caller-generated unique key (a UUID per logical submit) that makes a retried request safe (ADR 0018). Required whenever the service runs with Postgres — i.e. in every deployment — and answered with 400 `idempotency-key-required` when absent; a replay with the same key and the same body returns the original response, while the same key with a different body is 422 `idempotency-key-reused`. The in-memory development mode (no DATABASE_URL) does not enforce it, which is why the header is not marked `required` here (the Schemathesis contract run boots that mode).
