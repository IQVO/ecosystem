## Overview
Cancels an ACTIVE reservation and returns its full reserved quantity to usable inventory on every StockUnit it had allocated from. This is the mechanism that makes reservations safe against physical delivery failure: revoke, then reserve again — the second reservation is free to draw from a different physical holding. Idempotent in effect (a resource that no longer exists or is already resolved simply can't be revoked again), though a second call on an already-resolved reservation is reported as 409, not a silent 204.





## DELETE `(/reservations/{id})`

### Parameters
- **id** (path) (required): The reservation's id, formatted `res-<uuid>`.
