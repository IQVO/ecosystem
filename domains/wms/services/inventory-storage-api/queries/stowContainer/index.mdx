## Overview
Scan the LPN, scan the location (ADR 0045). The bin must accept sealed cases (handling unit CASE or PALLET, as published by facility-layout); a bin whose handling unit is unknown or EACH is 409 `bin-handling-unit-mismatch` (fail closed). The first stow sets the container's site from the bin's site (a carton event carries no site) and creates the SEALED_CASE stock unit holding the case's eaches; moving a stowed container to another bin of the same site is allowed, to another site is 409 `container-not-at-site`. Stowing into the bin it is already in is a no-op.

Behind the Idempotency-Key middleware like the other creating POSTs (ADR 0018).




## POST `(/containers/{lpn}:stow)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a retried request safe (ADR 0018). Postgres is the only runtime, so the check is on in every deployment: a missing or empty key is answered with 400 `idempotency-key-required`; a replay with the same key and the same body returns the original response, while the same key with a different body is 422 `idempotency-key-reused`.

- **lpn** (path) (required): The container's license plate (the carton SSCC, or an internal `LPN-<site>-<id>`).
