## Description
Raised by BreakCase (ADR 0045) in the same transaction that moves exactly `qty_eaches` (the case's units per pack) from the SEALED_CASE unit to loose stock of the same owner in `loose_bin`; the ledger total in eaches does not change (conservation). `ContainerEmptied` follows in the same transaction. `owner_ref` is an additive field beyond the contract's minimal payload. Kafka key and `subject` are the LPN.
> **No consumer by design:** pending: container fact (ADR 0045/0046); no consumer declared in any fleet spec yet
