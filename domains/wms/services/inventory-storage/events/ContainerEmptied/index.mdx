## Description
Raised when a Container reaches EMPTY (ADR 0045): `reason` is `BROKEN` (BreakCase) or `PICKED` (a whole-case reservation was confirmed as picked). Kafka key and `subject` are the LPN.
> **No consumer by design:** pending: container fact (ADR 0045/0046); no consumer declared in any fleet spec yet
