## Description
Raised by the RunCycleCount use case once a bin has been counted and reconciled. The `discrepancy` flag says whether the counted quantity matched the system quantity; when it did not, a DiscrepancyDetected event and possibly ItemUnlocated events are emitted alongside this one.

Published to `warehouse.inventory.analytics` only (subject = bin id, Kafka key = bin id). Analytics `data`: `{bin_id, counted, system, discrepancy}`.
