## Description
Raised by the RunCycleCount use case when the counted quantity differs from the system quantity for a bin, before reconciliation is applied. A shortfall additionally produces ItemUnlocated events for the quantity that could not be found.

**Published to both topics** (promoted to the integration topic 2026-10-21, ADR 0043, for exception-management). Subject = Kafka key = bin id on both topics; `data` is byte-identical: `{bin_id, counted, system}`. Only the `dataschema` stream differs.
