## Description
Raised by the StowStock use case once BOTH an item scan and a location scan are present — a stow without both is rejected, because skipping either is precisely how inventory gets lost. Chaotic storage applies: any SKU may go into any free bin, provided the bin's capacity is not exceeded. This is the point at which the quantity becomes usable.

**Published to both topics** (promoted to the integration topic 2026-10-21, ADR 0043, so returns-processing can close its restock loop on it). Subject = Kafka key = SKU on both topics; `data` is byte-identical: `{sku, bin_id, quantity}`. Only the `dataschema` stream differs (`...:events:` vs `...:analytics:`).
