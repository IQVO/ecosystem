## Description
CONSUMED, not produced (ADR 0046, contract R8): type `com.warehouse.wms.product-master.product.ProductPackLevelRetired`. End-dates the level of `gtin` in the PackagingView (`effective_to`); the GTIN remains resolvable so cartons labelled with it still link. Applied when `version` is not older than the stored one; an unknown GTIN is a no-op.
