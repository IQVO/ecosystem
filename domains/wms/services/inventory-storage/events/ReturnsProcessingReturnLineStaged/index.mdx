## Description
CONSUMED, not produced (ADR 0044). Pinned by returns-processing's `apis/asyncapi.yaml`: type `com.warehouse.wms.returns-processing.disposition.ReturnLineStaged`, `source=/warehouse/returns-processing`, subject and Kafka key = the disposition id. `data` is inbound-receiving's ReceiptLineReceived fields plus `rma_id`, `disposition_id` and `site_id`: `{receipt_id, line_no, sku, quantity, condition, received_at, rma_id, disposition_id, site_id}` with `condition` the constant `Good` (only a RESTOCK disposition stages a line). This service books `sku` and `quantity` through the SAME ReceiveStock use case as a receipt line (its own clock stamps the resulting `StockReceived`; the return context is logged, not stored), so the units are staged and not yet usable until stow.
