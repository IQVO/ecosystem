## Description
Raised when a Damaged receipt line (inbound-receiving `ReceiptLineReceived`, condition DAMAGED) is booked as held stock instead of being dropped (ADR 0052). The unit has no usable quantity and can never be reserved. It is raised in the same transaction as the consumed message. Kafka key and `subject` are the held unit id.
> **No consumer by design:** pending: held-stock fact (ADR 0052); no consumer declared in any fleet spec yet
