## Description
Raised by the ReceiveStock use case when inbound goods are booked in against a SKU. The quantity is *staged* — it is not yet in a bin and is therefore not usable; it becomes usable only once ItemStowed records the bin it landed in.

Published to `warehouse.inventory.analytics` only (subject = SKU, Kafka key = SKU). Analytics `data`: `{sku, quantity}`.
