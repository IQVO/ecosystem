## Overview
Moves a `PLANNED` load to `CANCELLED` and publishes `LoadCancelled`.
Only a `PLANNED` load can be cancelled — a load already `LOADING`
must be resolved instead (short-ship and close, or reopen later): the
refusal is `409 load-state` (`ErrInvalidTransition`). A
`SHIP_CONFIRMED` load refuses with `409 load-confirmed`.





## POST `(/loads/{loadId}/cancellations)`

### Parameters
- **loadId** (path) (required): The outbound load id.
- **Idempotency-Key** (header) (required): Caller-minted key (fleet guideline R3-R5). First use executes; a
replay returns the stored response with `Idempotency-Replayed: true`;
a key reused with a different body is `409 idempotency-key-reused`.
