## Overview
Read-only analytical view (projector-fed, not the OLTP store): per
site and cutoff, how many loads closed before their cutoff, how many
packages missed, and the adherence percentage. A report view, so it
is pagination-exempt (R7 `report`).





## GET `(/reports/load-adherence)`

### Parameters
- **site_id** (query): Filter by facility-layout site code.
- **operating_date** (query): Filter by operating date (YYYY-MM-DD, UTC).
