## Overview
Every package assigned to the load with its state, so the dock
supervisor can see expected vs staged vs loaded before closing
(`ErrPackagesOutstanding` is the refusal when this list is not all
LOADED/SHORT_SHIPPED). Keyset pagination (R7).





## GET `(/loads/{loadId}/packages)`

### Parameters
- **loadId** (path) (required): The outbound load id.
- **state** (query): Filter by package state.
- **limit** (query): Page size (R7); default 50, max 200.
- **cursor** (query): Opaque keyset cursor from the previous page's nextCursor (R7).
