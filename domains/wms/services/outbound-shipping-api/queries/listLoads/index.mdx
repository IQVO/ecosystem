## Overview
Loads newest-first by creation, filtered by `site_id`, `state` and
`operating_date`. Keyset pagination (fleet guideline R7): pass the
`nextCursor` of the previous page; `limit` defaults to 50 and is
capped at 200.





## GET `(/loads)`

### Parameters
- **site_id** (query): Filter by facility-layout site code.
- **state** (query): Filter by load state.
- **operating_date** (query): Filter by operating date (YYYY-MM-DD, UTC).
- **limit** (query): Page size (R7); default 50, max 200.
- **cursor** (query): Opaque keyset cursor from the previous page's nextCursor (R7).
