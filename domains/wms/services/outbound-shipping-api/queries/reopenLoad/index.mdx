## Overview
Moves a `CLOSED` load back to `LOADING` and publishes `LoadReopened`
so yard-management reopens the door work. A `SHIP_CONFIRMED` load
never changes: `409 load-confirmed` (`ErrLoadConfirmed`).





## POST `(/loads/{loadId}/reopenings)`

### Parameters
- **loadId** (path) (required): The outbound load id.
- **Idempotency-Key** (header) (required): Caller-minted key (fleet guideline R3-R5). First use executes; a
replay returns the stored response with `Idempotency-Replayed: true`;
a key reused with a different body is `409 idempotency-key-reused`.
