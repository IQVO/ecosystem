## Overview
Cron-driven (the scheduler calls it at each cutoff): every `EXPECTED`
or `STAGED` package whose cutoff has passed raises `PackageMissedLoad`
exactly once — a re-run sweep publishes nothing new (the flagged fact
is remembered on the package). Idempotent per key like every POST.





## POST `(/missed-load-sweeps)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-minted key (fleet guideline R3-R5). First use executes; a
replay returns the stored response with `Idempotency-Replayed: true`;
a key reused with a different body is `409 idempotency-key-reused`.
