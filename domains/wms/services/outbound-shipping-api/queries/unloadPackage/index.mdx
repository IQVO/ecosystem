## Overview
Moves a `LOADED` package back to `STAGED` and publishes
`PackageUnloaded` with the operator's reason. Unloading is only
possible before the load is ship-confirmed: once the package is
`SHIPPED` it refuses with `409 already-shipped`
(`ErrAlreadyShipped`) — the truck has left.





## POST `(/packages/{packageId}/unloadings)`

### Parameters
- **packageId** (path) (required): The manifested package id (fulfillment-execution's package id).
- **Idempotency-Key** (header) (required): Caller-minted key (fleet guideline R3-R5). First use executes; a
replay returns the stored response with `Idempotency-Replayed: true`;
a key reused with a different body is `409 idempotency-key-reused`.
