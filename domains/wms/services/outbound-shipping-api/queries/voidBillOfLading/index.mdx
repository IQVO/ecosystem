## Overview
Moves an `ISSUED` bill of lading to `VOIDED` and publishes
`BillOfLadingVoided` with the reason. The document of a departed
load is voided only by a supervisor decision (e.g. a re-issued
document); the shipment itself is not undone.





## POST `(/bills-of-lading/{bolNumber}/voids)`

### Parameters
- **bolNumber** (path) (required): The bill of lading number.
- **Idempotency-Key** (header) (required): Caller-minted key (fleet guideline R3-R5). First use executes; a
replay returns the stored response with `Idempotency-Replayed: true`;
a key reused with a different body is `409 idempotency-key-reused`.
