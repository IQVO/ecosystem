## Description
`type` =
`com.warehouse.wms.outbound-shipping.billoflading.BillOfLadingIssued`;
subject and key = the BOL number. Issued exactly once per
SHIP_CONFIRMED load (`ErrBolAlreadyIssued`) with the seal the
departure carried (`ErrSealMissing` without one).

> **No consumer by design:** No integration consumer by design: the ADR 0005 type catalogue lists this type as analytics only; the service's own projector folds it from the analytics stream.
