## Description
`type` = `com.warehouse.wms.outbound-shipping.outboundload.LoadPlanned`;
subject and key = the load id. Raised automatically when the first
package of a (site, cpt, date, ship method) manifests and no open
load exists for that key (PlanLoadFromCutoff policy).
