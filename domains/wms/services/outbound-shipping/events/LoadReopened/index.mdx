## Description
`type` =
`com.warehouse.wms.outbound-shipping.outboundload.LoadReopened`;
subject and key = the load id. A SHIP_CONFIRMED load is never
reopened (`ErrLoadConfirmed`). yard-management reopens the door work
on it.

> **No consumer by design:** pending: ADR 0005 names yard-management as the integration consumer, but yard-management declares no such consumer and has no handler for it on develop.
