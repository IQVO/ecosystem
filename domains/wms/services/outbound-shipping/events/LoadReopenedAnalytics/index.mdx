## Description
`type` =
`com.warehouse.wms.outbound-shipping.outboundload.LoadReopened`;
subject and key = the load id. A SHIP_CONFIRMED load is never
reopened (`ErrLoadConfirmed`). yard-management reopens the door work
on it.
