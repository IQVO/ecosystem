## Description
`type` =
`com.warehouse.wms.outbound-shipping.shippingpackage.PackageMissedLoad`;
subject and key = the package id. Raised at most ONCE per package and
load (the flagged fact is remembered: a re-run sweep or a repeated
departure publishes nothing new). `source_order_id` is omitted when
the manifest carried none (ADR 0003). exception-management opens a
case; order-management re-promises.
