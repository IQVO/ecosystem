## Description
`type` =
`com.warehouse.wms.outbound-shipping.shippingpackage.PackageUnloaded`;
subject and key = the package id. `reason` is the operator's reason,
omitted when none was given. Impossible after ship-confirm
(`ErrAlreadyShipped`).

> **No consumer by design:** No integration consumer by design: the ADR 0005 type catalogue lists this type as analytics only; the service's own projector folds it from the analytics stream.
