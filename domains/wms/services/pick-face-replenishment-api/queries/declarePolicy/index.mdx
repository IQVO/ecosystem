## Overview
Declares the `MIN_MAX` policy of a site and SKU. Without `If-Match` it
creates the policy at version 1 and answers 409 `policy-already-exists`
when one exists. With `If-Match: <version>` it replaces the policy only
when that is the current version (the new version is current + 1); a stale
value is a 409 `concurrent-modification`. The values must satisfy
`0 <= minQty < maxQty` and `multiple >= 1` (`multiple` defaults to 1). A
request quantity is always rounded down to a multiple of `multiple`.
Publishes `ReplenishmentPolicyDeclared` on the analytics topic. The
response carries the new version as `ETag`.





## PUT `(/policies/{siteId}/{sku})`

### Parameters
- **siteId** (path) (required): The site id (the facility site code).
- **sku** (path) (required): The SKU.
- **If-Match** (header): The policy version the caller read (the `ETag` of a previous response, with
or without the double quotes). Omit it to create a policy; send it to
replace or remove one. A value that is not the current version is a 409
`concurrent-modification`.
