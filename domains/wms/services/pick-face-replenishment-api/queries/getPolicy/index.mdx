## Overview
Returns the declared policy of a site and SKU, with its current version also as `ETag`.




## GET `(/policies/{siteId}/{sku})`

### Parameters
- **siteId** (path) (required): The site id (the facility site code).
- **sku** (path) (required): The SKU.
