## Overview
Returns the request with its state and timestamps, including how many units the relocation moved once it is `Completed`.




## GET `(/replenishments/{requestId})`

### Parameters
- **requestId** (path) (required): The request id (`repl-` followed by a unique suffix, at most 64 characters).
