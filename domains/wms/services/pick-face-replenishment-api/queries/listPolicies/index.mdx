## Overview
Lists the declared policies ordered by site and SKU, a page at a time.
`cursor` is the opaque `nextCursor` of the previous page; a response
without `nextCursor` is the last page. `siteId` and `sku` narrow the list.





## GET `(/policies)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100).
- **cursor** (query): The `nextCursor` value from the previous page.
- **siteId** (query): Only policies of this site.
- **sku** (query): Only policies of this SKU.
