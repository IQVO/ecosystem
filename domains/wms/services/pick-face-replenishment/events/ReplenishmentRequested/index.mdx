## Description
`type` = `com.warehouse.wms.pick-face-replenishment.replenishment.ReplenishmentRequested`;
subject and key = the request id. `priority` is `URGENT` when the pick face
had nothing available (`on_hand - reserved <= 0`) at detection, else
`NORMAL`. `policy_min` and `policy_max` are the policy values the request
was sized with.
