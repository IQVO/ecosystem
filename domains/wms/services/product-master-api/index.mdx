The WMS-tier source of truth for SKU-level product master data in the
warehouse-systems platform (ADR 0001): what a SKU *is* for handling
purposes (its classification) and physically (declared and measured unit
dimensions and weight, ADR 0002). It answers no "where" or "how many"
question; stock lives in inventory-storage.

Every write is an idempotent `PUT`: repeating a request with the same body
changes nothing, bumps no version and publishes no event. Accepted changes
are published as CloudEvents on `warehouse.product-master.events` through a
transactional outbox (see `apis/asyncapi.yaml`); sibling contexts keep a
local copy from those events and never call this API at request time.

Errors are RFC 7807 problem documents with
`type = https://errors.product-master.warehouse-systems.dev/<slug>`.
There is no authentication layer (fleet decision 2026-09-11).
