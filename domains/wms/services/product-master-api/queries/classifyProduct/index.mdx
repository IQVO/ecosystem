## Overview
Sets (201) or replaces (200) the handling classification of a
registered product. The request body is the same as inventory-storage's
former `PUT /products/{sku}/classification` (ADR 0003). `handlingTags`
is a non-empty, duplicate-free set from the closed enum;
`temperatureClass` is required if and only if `TemperatureSensitive` is
present; `dotHazardClass` is optional and only allowed with `Hazmat`.
An identical classification returns 200 and changes nothing.





## PUT `(/products/{sku}/classification)`

### Parameters
- **sku** (path) (required): The SKU (1..64 characters, no whitespace, control characters or `/`).
