## Overview
Records the latest measured unit dimensions and weight (a cubiscan
reading or a manual measurement, ADR 0002). The measured values become
the effective ones. A measurement older than the current one is
rejected with 409 `stale-measurement`; `measuredAt` in the future is a
400. Repeating the current measurement changes nothing.
