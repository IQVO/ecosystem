## Overview
End-dates the ACTIVE definition at `level` (`effectiveTo` = now). The
definition and its GTIN are kept: the GTIN still resolves, inactive,
and is never assigned again. The body is optional; `reason` (1 to 200
characters, no control characters) defaults to `retired`. Retiring a
level that is already retired returns 200 with that level and changes
nothing; a level the product never had is 404 `pack-level-not-found`.
Levels above the retired one are not retired by this call.





## POST `(/products/{sku}/pack-levels/{level}:retire)`

### Parameters
- **sku** (path) (required): The SKU (1..64 characters, no whitespace, control characters or `/`).
- **level** (path) (required): The packaging level, upper case.
