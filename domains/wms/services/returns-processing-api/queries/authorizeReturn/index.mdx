## Overview
Authorizes returning `quantity` units of one SKU of an order line.
The line must be **allocated** (order-management's local copy) and
**manifested** (a work unit `{order_id}-line-{line_no}` in the
fulfillment-execution local copy), and now must be inside the policy's
return window (409 `return-not-authorizable` with rejection code
`LINE_NOT_MANIFESTED`, `RETURN_WINDOW_EXPIRED` or
`QUANTITY_EXCEEDS_POLICY` otherwise). At most ONE open RMA may exist
per (orderRef, lineNo) (409 `open-rma-exists`). `quantity` must be in
`[1, policy.maxUnitsPerLine]`; the shipped-quantity check is planned,
not built (ADR 0003). Publishes `ReturnAuthorized` (or
`ReturnAuthorizationRejected` for a decided rejection) through the
outbox. Requires an `Idempotency-Key`; replaying the same key and body
returns the original response.





## POST `(/returns)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. The service always runs on Postgres, so it is
required on every deployment and answered with 400
`idempotency-key-required` when absent; a replay with the same key and
the same body returns the original response, while the same key with a
different body is 409 `idempotency-key-reused`.
