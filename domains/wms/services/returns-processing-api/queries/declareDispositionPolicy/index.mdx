## Overview
Declares policy version `version` (a positive integer; it must be
current + 1, 409 `concurrent-modification` otherwise). The table maps
(grade, productClass) to an outcome; the entry `productClass: "*"` is
the required default per grade, which makes `Decide` total. Also
carries the return window days, the max units per line and the
`vetoOutcome` a guardrail demotion falls back to (default DISPOSE).
Policy versions are append-only; an old version is never rewritten.
Requires an `Idempotency-Key`.





## PUT `(/disposition-policies/{version})`

### Parameters
- **version** (path) (required): The policy version to declare (current + 1).
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. The service always runs on Postgres, so it is
required on every deployment and answered with 400
`idempotency-key-required` when absent; a replay with the same key and
the same body returns the original response, while the same key with a
different body is 409 `idempotency-key-reused`.
