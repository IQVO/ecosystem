## Overview
Whole-window aggregate of how many lines and units each outcome got per
policy version, over `from`/`to` (a decision counts in the day its
`DispositionDecided` event time falls in). Omitted bounds default to
the 30 days ending now; the window is at most 366 days. A bounded
report, not a collection: it does not page.





## GET `(/reports/disposition-mix)`

### Parameters
- **from** (query): Inclusive start of the window, RFC 3339 (default `to` minus 30 days).
- **to** (query): Exclusive end of the window, RFC 3339 (default now). `to` minus `from` is at most 366 days.
- **siteId** (query): Restrict the report to one site.
