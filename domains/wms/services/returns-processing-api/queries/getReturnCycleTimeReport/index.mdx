## Overview
The p50/p95 latency from receipt to the staged milestone per UTC day
over `from`/`to`. Omitted bounds default to the 30 days ending now; the
window is at most 366 days. A bounded report: it does not page.





## GET `(/reports/return-cycle-time)`

### Parameters
- **from** (query): Inclusive start of the window, RFC 3339 (default `to` minus 30 days).
- **to** (query): Exclusive end of the window, RFC 3339 (default now). `to` minus `from` is at most 366 days.
- **siteId** (query): Restrict the report to one site.
- **granularity** (query): Bucket size; `day` is the only value.
