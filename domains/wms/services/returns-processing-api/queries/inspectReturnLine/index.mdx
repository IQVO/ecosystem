## Overview
Records the inspection grade of one receipt line and runs
`DecideDisposition` in the same transaction. The inspected quantity
must be in `[1, received quantity]` and a line is inspected exactly
once (409 `line-already-inspected`). Publishes `ReturnLineInspected`
and `DispositionDecided`; a RESTOCK outcome additionally publishes
`ReturnLineStaged`. Requires an `Idempotency-Key`.





## POST `(/receipts/{receiptId}/lines/{lineNo}/inspect)`

### Parameters
- **receiptId** (path) (required): The receipt id (`rcpt-` followed by a unique suffix, at most 64 characters).
- **lineNo** (path) (required): The receipt line number (1-based).
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit) that makes a
retried request safe. The service always runs on Postgres, so it is
required on every deployment and answered with 400
`idempotency-key-required` when absent; a replay with the same key and
the same body returns the original response, while the same key with a
different body is 409 `idempotency-key-reused`.
