## Overview
200 when the service can serve traffic. 503 while draining for
shutdown (`{"status":"not_ready"}`) or while Postgres or the Kafka
broker is unreachable (problem `dependency-unavailable`). Kafka
readiness is reachability only (a broker answers a metadata request
with an empty topic list); a missing topic never makes the service
unready.
