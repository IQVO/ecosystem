## Description
`type` = `com.warehouse.wms.returns-processing.disposition.DispositionDecided`;
subject and key = the dispositionId. The decision is the pure function
`Decide(grade, classification, policy)` and records the
`policy_version` it used. An operator override is a NEW Disposition
whose `supersedes` names the original and whose `reason` is mandatory;
both fields are null on a policy decision.

> **No consumer by design:** returns ledger fact; analytics mirror planned, not built (ADR 0004); consumed on demand
