## Description
`type` = `com.warehouse.wms.returns-processing.returnauthorization.ReturnAuthorized`;
subject and key = the rmaId. `window_ends_at` is the policy window's
end (authorized_at + return window days); the goods must arrive before
it. `quantity` is capped by `DispositionPolicy.max_units_per_line`
(the shipped-quantity check is planned, ADR 0003).

> **No consumer by design:** returns ledger fact; analytics mirror planned, not built (ADR 0004); consumed on demand
