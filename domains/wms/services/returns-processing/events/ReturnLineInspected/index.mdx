## Description
`type` = `com.warehouse.wms.returns-processing.returnreceipt.ReturnLineInspected`;
subject and key = the receiptId. `quantity` is the inspected quantity,
never more than the received quantity of the line; a line is inspected
exactly once. The disposition is decided in the same transaction and
raises its own `DispositionDecided`.

> **No consumer by design:** returns ledger fact; analytics mirror planned, not built (ADR 0004); consumed on demand
