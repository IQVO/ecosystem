## Description
`type` = `com.warehouse.wms.returns-processing.disposition.ReturnLineStaged`;
subject and key = the dispositionId. `data` is inbound-receiving's
`ReceiptLineReceived` shape (`receipt_id`, `line_no`, `sku`,
`quantity`, `condition`, `received_at`) plus `rma_id`,
`disposition_id` and `site_id`; inventory-storage consumes it into its
staged-receipt use case and the stow stays an RF action there. Raised
exactly once per RESTOCK disposition (idempotent on `disposition_id`);
no other outcome touches any sibling.
