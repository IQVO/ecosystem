## Description
`type` = `com.warehouse.wms.returns-processing.returnreceipt.ReturnReceiptOpened`;
subject and key = the receiptId. `rma_id` is null when the whole
parcel was unexpected. Every line carries its own nullable `rma_id`: a
non-null value is a matched line, null means the line is UNEXPECTED
(there is no silent third state). UNEXPECTED lines additionally raise
`UnexpectedReturnReceived` for exception-management.

> **No consumer by design:** returns ledger fact; analytics mirror planned, not built (ADR 0004); consumed on demand
