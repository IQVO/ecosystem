## Overview
Moves a `Draft` plan to `Approved` and publishes `SlotPlanApproved` with
the full assignment map and the moves. The site's previously Approved
plan, if any, becomes `Superseded` in the same transaction. Approving a
plan that is not a `Draft` is a 409 `plan-not-draft`; losing a race to
another approval of the same site is a 409 `approved-plan-conflict`.





## POST `(/slot-plans/{planId}/approve)`

### Parameters
- **planId** (path) (required): The plan id (`plan-` followed by a unique suffix, at most 64 characters).
