## Overview
The freshness lag of the projection the report reads: `as_of` is the
CloudEvents time of the newest event the projector has applied and
`lag_seconds` is now minus `as_of` (never negative). Both are null
until the first event is applied. A growing lag means the projector
is down or behind, not that the report is wrong: it catches up when
the projector does.
