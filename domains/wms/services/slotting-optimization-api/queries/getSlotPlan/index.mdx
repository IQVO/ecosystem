## Overview
Returns the full plan, with its assignments, moves, unassigned SKUs and
reasons, state and timestamps, plus `execution`: how far the floor has
executed its moves (ADR 0010), derived from the relocations
inventory-storage recorded (`StockRelocated`). Only this operation
carries `execution`; proposals are not gated on it.
