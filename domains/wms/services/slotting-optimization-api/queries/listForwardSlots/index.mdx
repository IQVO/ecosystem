## Overview
The assignment map of the site's currently Approved plan, in SKU order.
Returns an empty `assignments` list and no `planId` while the site has no
Approved plan.





## GET `(/forward-slots)`

### Parameters
- **siteId** (query): The site; defaults to the configured default site.
