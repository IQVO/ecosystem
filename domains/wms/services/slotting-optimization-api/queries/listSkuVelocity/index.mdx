## Overview
The demand the planner works from: per SKU, the number of ACTIVE demand
lines (`picks`) and their units over the last `windowDays` days, ordered
by picks, then units (descending) and SKU (ascending). Read from the
local demand copy (ADR 0003).





## GET `(/sku-velocity)`

### Parameters
- **limit** (query): Number of SKUs to return, 1 to 500 (default 100).
- **windowDays** (query): Lookback window in days, 1 to 365 (default 28).
- **siteId** (query): The site; defaults to the configured default site.
