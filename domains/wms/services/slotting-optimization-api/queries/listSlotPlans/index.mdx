## Overview
Lists plans newest first, a page at a time. `cursor` is the opaque
`nextCursor` of the previous page; a response without `nextCursor` is the
last page. Optional filters narrow by site and state.





## GET `(/slot-plans)`

### Parameters
- **limit** (query): Page size, 1 to 500 (default 100).
- **cursor** (query): The `nextCursor` value from the previous page.
- **siteId** (query): Only plans of this site.
- **state** (query): Only plans in this state.
