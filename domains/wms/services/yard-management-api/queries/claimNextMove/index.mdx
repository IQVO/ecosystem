## Overview
Pull dispatch: the system, never the caller, picks the REQUESTED HOSTLER move of the site with the lowest priority band, then the earliest dueBy, then the oldest request, and leases it to the hostler for the site's `leaseSeconds`. The trailer leaves its place (StartMoving). A hostler holds at most one CLAIMED move (409 `hostler-busy`). 404 `no-claimable-move` when nothing waits.




## POST `(/moves/claims)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit, 1-128 printable ASCII characters) that makes a retried request safe. Required on every POST and PUT (400 `idempotency-key-required`; `idempotency-key-invalid` when malformed). A replay with the same key, method, path and body returns the original response with `Idempotency-Replayed: true`; the same key with a different method, path or body is 409 `idempotency-key-reused`.
