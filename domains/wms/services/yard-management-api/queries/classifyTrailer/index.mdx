## Overview
Sets the hazard class, the UN number and the temperature-control need of a trailer that is on site (ADR 0014): a full replacement, so a field left out is cleared and `{}` declares nothing. The same facts again change nothing and answer 200. Classifying a parked trailer does not move it; the placement rules judge the next placement (`POST /moves`, check-in, and the spot where a move is completed). An unknown hazard class is 422 `invalid-hazmat-class`, a malformed UN number 422 `invalid-un-number`, a UN number without a class 422 `validation`; a departed trailer is 409 `illegal-transition`.




## POST `(/trailers/{trailerId}/classifications)`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit, 1-128 printable ASCII characters) that makes a retried request safe. Required on every POST and PUT (400 `idempotency-key-required`; `idempotency-key-invalid` when malformed). A replay with the same key, method, path and body returns the original response with `Idempotency-Replayed: true`; the same key with a different method, path or body is 409 `idempotency-key-reused`.
- **trailerId** (path) (required): The trailer id.
