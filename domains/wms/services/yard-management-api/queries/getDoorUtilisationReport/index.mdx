## Overview
Read-only analytics over the analytical database (ADR 0006). The API answers the contract shape from the analytics read-side port; until the analytics read side is wired the report has no rows. `from` and `to` are required RFC 3339 instants (to after from, at most 92 days).




## GET `(/reports/door-utilisation)`

### Parameters
- **from** (query) (required): Start of the report window (RFC 3339).
- **to** (query) (required): End of the report window (RFC 3339), after `from`, at most 92 days later.
- **siteId** (query): Only this site.
