## Overview
Lists the LATEST version of every template, by id, one keyset page at a time: the built-in ones (`tractor-trailer-17-point`, `empty-container-7-point`, `reefer-pre-cool-and-sanitation`, read-only, `builtIn` true) and the ones a site published (ADR 0015).




## GET `(/inspection-templates)`

### Parameters
- **limit** (query): Page size, 1-500, default 100.
- **cursor** (query): The opaque `nextCursor` of the previous page.
