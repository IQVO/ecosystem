## Overview
Lists moves oldest first, one keyset page at a time. Filters: `siteId`, `state`, `trailerId`, `hostlerRef` (the moves a hostler holds or held).




## GET `(/moves)`

### Parameters
- **siteId** (query): Only moves of this site.
- **state** (query): REQUESTED, CLAIMED, COMPLETED or CANCELLED.
- **trailerId** (query): Only moves of this trailer.
- **hostlerRef** (query): Only moves leased to this hostler.
- **limit** (query): Page size, 1-500, default 100.
- **cursor** (query): The opaque `nextCursor` of the previous page.
