## Overview
Lists the inspections of one trailer, newest first, one keyset page at a time (ADR 0015). 404 `trailer-not-found` for an unknown trailer.




## GET `(/trailers/{trailerId}/inspections)`

### Parameters
- **trailerId** (path) (required): The trailer id.
- **limit** (query): Page size, 1-500, default 100.
- **cursor** (query): The opaque `nextCursor` of the previous page.
