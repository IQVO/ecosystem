## Overview
Lists trailers by arrival, one keyset page at a time. Filters: `siteId`, `state` (default: not DEPARTED), `kind`, `locationCode`, `unitNumber`, `visitId` (the visit the trailer is attached to: the one that brought it, until a later visit takes it).




## GET `(/trailers)`

### Parameters
- **siteId** (query): Only trailers of this site.
- **state** (query): PARKED, IN_MOVE, DOCKED or DEPARTED.
- **kind** (query): Trailer kind.
- **locationCode** (query): Where it is now.
- **unitNumber** (query): Unit number.
- **visitId** (query): Only the trailers attached to this visit.
- **limit** (query): Page size, 1-500, default 100.
- **cursor** (query): The opaque `nextCursor` of the previous page.
