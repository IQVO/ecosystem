## Overview
Lists visits newest first, one keyset page at a time (`limit` 1-500, default 100; `cursor` is the opaque `nextCursor` of the previous page). Filters: `siteId`, `state`, `tractorPlate`.




## GET `(/visits)`

### Parameters
- **siteId** (query): Only visits of this site.
- **state** (query): CHECKED_IN, CHECKED_OUT or REJECTED.
- **tractorPlate** (query): Only visits of this plate.
- **limit** (query): Page size, 1-500, default 100.
- **cursor** (query): The opaque `nextCursor` of the previous page.
