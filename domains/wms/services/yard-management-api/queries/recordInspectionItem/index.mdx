## Overview
Records what the inspector found at one item of an OPEN inspection: `PASS`, `FAIL` or `NOT_APPLICABLE` (only where the template item has `allowNotApplicable`, else 422 `not-applicable-not-allowed`), with an optional note (500 characters) and opaque evidence references (strings that point at photos or documents held elsewhere; at most 20, each at most 256 characters, no binary). Recording again replaces the earlier result. A completed inspection is final: 409 `inspection-closed`; an item the snapshot does not have is 422 `unknown-item`. Raises nothing.




## PUT `(/inspections/{inspectionId}/items/{itemCode})`

### Parameters
- **Idempotency-Key** (header) (required): Caller-generated unique key (a UUID per logical submit, 1-128 printable ASCII characters) that makes a retried request safe. Required on every POST and PUT (400 `idempotency-key-required`; `idempotency-key-invalid` when malformed). A replay with the same key, method, path and body returns the original response with `Idempotency-Replayed: true`; the same key with a different method, path or body is 409 `idempotency-key-reused`.
- **inspectionId** (path) (required): The inspection id.
- **itemCode** (path) (required): The item code of the template snapshot.
