## Overview
Raises TrailerDwellExceeded once per trailer and threshold crossing (the trailer remembers the highest threshold alerted). Naturally idempotent; run by a CronJob.




## POST `(/dwell-sweeps)`

### Parameters
- **Idempotency-Key** (header): Optional on the sweeps, which are naturally idempotent (a repeat finds nothing new to do). When sent it behaves as on every other POST: a replay with the same key, method, path and body returns the stored answer with `Idempotency-Replayed: true`, and the same key with a different request is 409 `idempotency-key-reused`.
