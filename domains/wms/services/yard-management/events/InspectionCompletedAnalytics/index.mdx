## Description
`type` = `com.warehouse.wms.yard-management.inspection.InspectionCompleted`; subject and key = `inspection_id`; dataschema `urn:warehouse:yard-management:analytics:InspectionCompleted:v1`. Raised by CompleteInspection (ADR 0015); the inspection is final once completed, so the payload carries no version. A template is versioned and an inspection keeps the version it was opened from (template_version). Byte-identical payload to the integration topic.
